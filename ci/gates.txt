# The one list of CI gates (07-G4, owner decision D47). Read by scripts/ci/run_gates.py.
# Columns are TAB-separated:
#   name  command  baseline  kind  lower-command  job
# kind:
#   ratchet        baseline is a file holding one integer; lower-command prints the measured
#                  integer on stdout (and nothing else) and exits 0. The bot lowers the file
#                  when measured < baseline and never raises it.
#   ratchet-set    baseline is a file holding a set of identifiers; lower-command is a
#                  lower-only prune that rewrites it. The bot verifies the result is a subset.
#   ratchet-const  baseline is a Go constant; the bot never edits Go source. lower-command is
#                  "-" and the bot reports the test's "NOTE ... lower" line in its PR body.
#   check          pass/fail, no baseline.
# job: where CI executes the gate (scripts/tests/test_run_gates.py verifies it):
#   own-job   a ci.yml or extraction-gates.yml job runs the command (directly or
#             through a make target);
#   go-suite  a Go test in the sharded short-race suite runs it (the test exists
#             and does not skip under -short).
#   core-job  .github/workflows/core-ci.yml runs it: core's own gates, and the
#             root-side checks that compare core with the root (03 §3.2 item 4).
# baseline / lower-command are "-" when not applicable. Ratchets fail only on a rise.
#
# Classification (09 §9.4 R1's CI classification table). A gate is root, core, or
# per module; the per-module ones have one row per module with its own baseline.
#   errcheck, interface-width          root module (./... from the root never reaches core/)
#   core-errcheck, core-interface-width  core module: core/.errcheck-baseline and
#                                      core/.interface-width-baseline, scripts under
#                                      core/scripts/ci/, run by `make -C core ci`
#   deadcode-ratchet                   root, as two deadcode runs in their own module contexts:
#                                      ABO's mains from the root (root-plus-core-internal filter)
#                                      and, once it exists, hello's mains from core/ (core
#                                      internal+kernel filter); dead only if every run that
#                                      loads a package reports it; one baseline, no core baseline
#   core-pprof, core-mocks, core-coverage-floor  core halves of the root's pprof-check,
#                                      mocks-check and coverage-check-short; "not applicable"
#                                      or "no floor yet" lines until their subject exists
#   embed-context                      root: scripts/ci/check_embed_context.py judges every
#                                      //go:embed input of both modules against .dockerignore
#                                      and compares scripts/ci/embed_build_outputs.txt with the
#                                      Dockerfiles; core's half (`make -C core embed-check`,
#                                      core's own list, no image) is a step of core's ci target
#   store-width, store-references      root, until the split deletes database.Store
#   layering, appconfig-reads, slog-guard  root (Go tests in the sharded short suite)
#   core-layering                      core only
# Not rows here (no baseline, no command this manifest can run; each is a whole CI
# job or workflow, classified once):
#   per module   codeql.yml (go build in every module), core-ci.yml (core's pprof-check,
#                errcheck ratchet and mocks-check, via `make -C core ci`),
#                nightly.yml (core-nightly job: core's non-short tests), ratchet-lower.yml
#                (both modules' baselines)
#   root         memory-leak-scan.yml (web/src; core/web does not exist yet), fixture-tests,
#                Woodpecker test-native-taglib (no core package carries the tag)
#   root + core  go-test-short-shards: the root's packages in the numbered shards plus
#                one core shard (scripts/ci/short_test_shards.py)
# Blank lines and lines starting with # are ignored.
