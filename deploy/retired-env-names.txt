# The env names the rename table retires (05-config §1.3.6), generated from it by
# internal/books/cutover/retired_env_list_test.go. scripts/deploy_env_check.py reads
# this file and refuses a deploy whose deploy/local.conf sets one of them: a binary
# that has the flip never reads it (verdict warn: ignored with a warning) or refuses
# to boot on it (verdict refuse).
# A name with a `*` is a pattern (one or more characters): the refused operator
# settings of RefusedOperatorPaths, whose canonical env names a host may still set.
# A name's <NAME>_FILE form is the name: core reads any env name from the file a
# <NAME>_FILE variable names (core/config/env.go), so the refused operator settings
# are refused in both spellings (the books boot refusal and config check), and
# scripts/deploy_env_check.py and the F3-07 rehearsal read NAME_FILE as NAME for
# every row. Core's own retired list is exact-name, so for the other rows this
# errs toward refusing a deploy file that sets a form no binary reads. Names are
# matched in capitals only, as core reads them.
# Regenerate: go test ./internal/books/cutover -run TestRetiredEnvList -update
#
# enforced says whether the app hands these names to core (F3-07). While it is
# false the binary still reads them and the check only reports; it is derived from
# the source, never edited by hand.
# enforced: true
