- [ ] **Purge round-11 notes (PR 4165)** (1) The hard-delete path and "Purge now" still run the library-root check under the global merge lock (bounded by the 10 s stat timeout, but a hung mount holds the lock that long); move their check before the lock the way "Discard progress and purge" does (`preLockRoot`). (2) A stat that hangs past `rootStatTimeout` leaves its goroutine blocked in the syscall until the mount answers; each refused check leaks up to 51 of them, so a long outage with frequent checks (boot replay every two minutes, nightly purge) accumulates them. Bound it with a small shared pool or a per-root in-flight marker so a check does not start while the previous one is still hung. (3) The sampler skips books with `LibraryState == "deleted"` and trashed books but not rows whose `Missing` flag is set (deliberate: a file the scanner already flagged missing is still evidence of a lost mount); revisit if a genuinely deleted-by-hand library keeps refusing.
