### Changed

- Fifteen more maintenance operations (review-status index repair, unknown-author audit, version-group primary report, reports prune, title backfill, title repair, bulk write-back, user merge, tag backfill, repoint of unrecorded renames, series phantom repair, version-group primary repair, path-prefix rewrite, repoint of missing files to folder audio, and the merge of series that carry a book number) now also exist as native task kinds under `books.maintenance.*`. Nothing registers them yet, so no behaviour changes: the existing operations run exactly as before, through the same shared bodies. Each body now reads and writes only through the store and writer it is handed, which is what lets the later task switch run it as a native task. The series-number merge's final delete of an emptied series now goes through that writer too, as the other writes already did.
