### Fixed

- core/outbox: two intermittent test failures of `Go Tests (short, race) shard core/4` are removed, and neither needed a production change. `TestOutbox_StatusSurvivesAnUnreadableRowAndNamesIt` planted a corrupt or newer-build message row by staging a valid one and overwriting it while the rig's relay was running; the relay could deliver the valid row in between, the cursor then passed it, and `Status` (which reads above the cursor only) rightly found nothing unreadable to name (`Stopped = []`). The test now stops the relay first (`rig.stopRelay`), so the planted row is the only thing the status read can meet. `TestOutbox_RelayRestartsAfterCancel` timed out after ten seconds when a redelivered message reached the new relay's third delivery between two polls of its `== 2` wait, which hid the duplicate behind a relay that looked as if it never restarted; the duplicate itself was the lost ack fixed by the settle-past-cancel change, and the test now waits for at least two deliveries and checks the delivered sequence, so a regression names the duplicate.
