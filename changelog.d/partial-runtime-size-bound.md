### Fixed

- A book whose files are only partly measured (some durations never probed) no longer gets an unpenalised, applicable metadata candidate that is far longer than the files could hold. The Review page offered a 14h42m Audible candidate (score 2.82) for a two-file book of about 8 MB with one 8-minute file measured. A partial runtime is now extended with an estimate from the measured files' bytes-per-second applied to the total size of all the book's files, with 3x headroom for variable bitrate. A candidate beyond that bound is scored with the same x0.50 runtime penalty as a complete runtime that is more than 100% off, and the apply gate refuses it as a runtime mismatch, naming the estimate (the "How this score was reached" runtime step shows it). A candidate within the bound is untouched, so a 10 h book with only two chapters measured still accepts its 10 h candidate, and a book with a missing file size behaves exactly as before. Runtime-less ASIN answers are now looked up in that case too, so the penalty can apply to them.
