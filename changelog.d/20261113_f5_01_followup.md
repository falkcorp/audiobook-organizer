### Changed

- maintenance: the native maintenance kinds got the review follow-ups of F5-01. `repoint-version-primary` has one switch natively: a live run applies, a preview does not, and an `apply` key in params is refused, so a live run can no longer end as a silent preview. A job's params check (`ParamsValidator`) now runs first thing in the native run, before it is handed a store. The five jobs HEAD restarts without ever checkpointing (`bulk-deluge-import`, `cleanup-empty-folders`, `refetch-missing-authors`, `retention-and-hygiene`, `scan-composer-tags`) declare `ResumeFromZero`, which is what a restart does for them. The log line for a failed run's dropped result now carries its size, not its content. `bulk-deluge-import` now declares that it writes files (it copies into the library).
- metadata: `WriteSingleTag` and `WriteSingleTagContext` are removed; `WriteSingleTagContextVia` is the single-tag writer and records the new hash through the store the caller names.

### Added

- maintenance: a test derives each maintenance job's write set, and which jobs checkpoint, from the code and compares them with what the native kinds declare.
