### Changed

- The server's log file is now `logs/abo.log` under the state directory (rotated at 100 MiB, seven files kept), instead of a dated `audiobook-organizer-<date>.log` in the directory the server was started from. Lines still go to standard output as well, so the journal is unchanged.
- `log_level` (and the `--log-level` flag) now sets the level the server logs at. It was read but never applied to the server's logger, which always logged at info. A level the server does not know falls back to info and prints a warning at startup.
- The `scan` and `organize` commands no longer open a debug-level log file in the working directory; they log to standard output like any other command.

### Fixed

- A log file that cannot be opened under the state directory now stops `serve` with an error naming the path, instead of being skipped with a warning.
