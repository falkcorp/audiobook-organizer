### Added

#### purge-empty-authors now samples the held-back "zero books, has files" authors

`maintenance.purge-empty-authors` previously reported the authors held back by `require_zero_files` only as a count, so a reviewer deciding whether that flag could ever be flipped had no names to look at. The report now carries a `HeldBackSample` (author ID, name and file count, capped at the same 50-entry limit as the eligible sample) and logs it on its own line whenever any author is held back. The counter itself stays uncapped. This is report-only: the eligible set, the delete path and the `require_zero_files` default are unchanged. No separate `book_authors` back-reference check was added, because every held-back author has already passed the unfiltered reference guard, which counts junction-only co-author credits.
