- New Repairs fixer **Split books** (`dedup.split-books`) in `/review?lane=repairs`, replacing the old Split Books tab: one row per cluster the split-book detector finds (one book stored as several numbered chapter books in one folder), with its books listed and the suggested keep marked. Applying a row merges exactly that cluster through the same merge core the split-book route and bulk op use: every file row moves onto the keep (none is deleted), progress and external ids follow, the other books are retired. A cluster with an iTunes book is skipped with the reason "iTunes". The apply operation's changes record the decision and the merge's undo journal id; the merge is undone from that journal, not by reverting the apply. Membership that changed since the plan is refused as changed since plan. The split-book routes, the `merge-split-books` CLI and the split-book ops are unchanged.
