Added the F5-18 commit 2 core half. Modules can now call `Registrar.Lanes`, `Registrar.ChangeSink` and `Registrar.Health`, declare `Manifest.TaskStarts`, and use `Deps.Tasks` and `Deps.Health`; a module acts as its own system actor through `Deps.Tasks` outside a request. `app.Options.TasksBoot` registers core's own task kinds (`core.storage.compact`, `core.storage.census`, `core.tasks.prune`, `core.log.journal.prune`, one `core.window.<name>` per configured window) and starts the executor and scheduler over them; `app.Options.InterimBackends` adds `core.integrations.release-holds`, `core.ai.batch-poll` and `core.diagnostics.export` when their backend is set. With `TasksBoot` off (the default) nothing changes: the hello example and today's ABO boot register no core kind.
