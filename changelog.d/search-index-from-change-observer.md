- Search indexing is now driven by one mechanism, the store's change observer, instead of two. The `indexedStore` decorator that wrapped the server's store and intercepted five book-write methods is gone, so the server's store is the raw store and capability lookups no longer walk a decorator for it. Every write the store commits that can change a search document (book rows, author and narrator credits, tags, aggregate recomputes, author and series renames) now asks the index for a refresh, including credit-only edits that previously reached the index only if the caller also saved the book. Credit resolution gets the authority lists through `authorcredit.SetAuthorityProvider` (registered at server construction, released at shutdown) instead of a method on the decorator. The index queue no longer carries a delete flag: the worker already decided delete versus upsert from the stored row. The admin debug API's post-edit "reindex" nudge (a skipped `ModifyBook`) is removed because the store's aggregate recompute reports the change itself. The `database.Store` reference ratchet drops from 31 to 28.
