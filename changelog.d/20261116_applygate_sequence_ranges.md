### Fixed

- The bulk-apply gate no longer refuses a correct metadata match because of a leading list number or a collected edition. A leading ordinal in a title or a track number in a file name ("08 - Title", "02 Chapter 1.m4b") is a weak volume reading: it is set aside whenever a stronger source (a stored series position, a "Book N" marker, a trailing number) exists on the same side, and still counts, so the match is still refused, when nothing stronger does. A volume range ("Books 1-3", "Vols 1 to 3", "Books 1, 2 & 3") is one number with a span (`seqnum.Number.Last`, `IsRange`): a range equals only the same range, never one of its volumes and never a different range, and a stored series position equal to an end of the range in the book's own title is the importer's reading of that range, so an empty and a set position get one verdict. A single volume is never given a box set's metadata and a box set is never given one volume's.
- The compilation penalty (`metadata_scoring.compilation_penalty`) is not applied when the book is itself a collected edition and the candidate is the same one (`metafetch.SameCollectedEdition`): the same stated range, or neither numbered with the same word-boundary wording class and any pack number equal. A single-volume book, an unnumbered candidate against a numbered book, a different range and a missing book title all keep the penalty. `ApplyNonBaseAdjustments*`, `ScoreOneResult*` and `pickBestMatchFromScored` take the stored book title, and the calibrate harness mirror applies the same condition through the same helper. Cached candidate scores keep their old value until the book is re-scored.
- Partial-book detection reads spans through the shared range reader, so "Book 1-3" and "Books 1-3" are both spans. A book titled with a singular span against a candidate with no span is now held for review, where before only the plural form was.
- `catalog.ParseSequence` reads the spans the shared reader knows ("1 & 2", "Books 1 and 2") and treats a list that skips a volume ("1, 3") as no position, never as a series gap.
