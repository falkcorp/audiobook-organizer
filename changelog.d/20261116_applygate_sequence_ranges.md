### Fixed

- The bulk-apply gate no longer refuses some correct metadata matches whose only fault was a leading list number or a collected edition's wording, and it asks for more evidence before it removes any refusal. The gate's refusals are not lifted wherever a stored series position or an unknown runtime is all that is left: those cases are refused or sent to review.
- A leading ordinal or a chapter/track/disc number ("08 - Title", "02 Chapter 1.m4b") is a weak volume reading, set aside only when it IS the number the reader parsed (a tag number elsewhere in the text says nothing about a volume number read from a different place) and a stronger source exists on the same side. Bundle words (omnibus, pack, box set, collection) are never tag words. When the only stronger sources are fields an earlier apply can have written (the stored series position, the stored title, an unmarked file name: together ONE source), the apply additionally needs the runtime check to be known and agree, the title check to agree, the stored title not to be just the series name, and every word of the stored title that is not a series word, stop word or the set-aside number to appear in the candidate title or subtitle (`sequence_unconfirmed`); otherwise it stays refused or goes to review. Only a "Book N" marker in a file or folder name sets the weak number aside without corroboration.
- A volume range ("Books 1-3", "Vols 1 to 3", "Books 1, 2 & 3") is one number with a span (`seqnum.Number.Last`, `IsRange`). A range equals only the same range, and a range with a tail ("Books 1-3 & 5") is a different list. A second end is read only when it is digits, or a roman numeral or number word directly after a range keyword (so "Book 2 - Three Jokers" and "Book 1 and Two-Face" are single volumes). A stored series position equal to an end of the range in the book's own title is set aside.
- Partial-book detection compares the ranges themselves: equal ranges pass, a range on one side only or two different ranges are held for review. The same range under different edition wording ("Books 1-3" and "Omnibus: Books 1-3") is not a `partial_book`; the collected-edition runtime rule decides, and an owner review can lift it.
- The compilation penalty (`metadata_scoring.compilation_penalty`) is not applied when the book is itself a collected edition and the candidate is the same one (`metafetch.SameCollectedEdition`): the normalized titles are equal once number and range spelling is set aside, and the same stated range, or the same wording class with no number or an equal one. The Candidates view scores through the same helper. Cached candidate scores keep their old value until the book is re-scored.
- Any collected edition on either side (read by word-boundary wording or a stated range, never a substring, and never from a folder name alone) now needs a known, agreeing runtime to apply unattended, otherwise the apply is refused as `collected_edition_runtime_unconfirmed` and goes to review. This is stricter than before for a same-range collected edition, which previously needed only two agreeing signals. How many of the measured collected-edition false refusals this still unblocks is not known without a re-run of the measurement.
- `catalog.ParseSequence` stores the same sequence bounds as before for every text its dash-range pattern does not match (`seqnum.ParsePositionNoRange`).
- Both new reasons are always listed on an owner override record when they would fire, whichever earlier check refused first (`Verdict.Unconfirmed`), and neither is lifted by the hashless unseen-review marker. A candidate that states a range in its title or subtitle and a position equal to an end of it is read as the range stated twice, as on the book side. A digit list needs a terminator ("Batman, Book 2, 10 Nights of the Beast" is volume 2).
- New refusals compared with before this change that remain: a collected edition with an unknown or only roughly agreeing runtime goes to review even for the same range; two identical unnumbered collected-edition titles apply on an agreeing runtime (a known, accepted limit).
