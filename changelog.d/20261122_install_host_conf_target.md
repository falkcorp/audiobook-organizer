### Added

- `make install-host-conf` installs the unit's `host.conf` drop-in from `deploy/host.conf` (gitignored; `deploy/host.conf.example` is the template), so a rebuilt host can be set up the same way every time instead of with a one-off script. It is `install_helpers.py --host-conf`: a dry run by default that checks the file with the rollback helper's own rule code (`_read_root_conf`, `_check_rules`, so the two cannot drift), prints create / replace / fix / unchanged and the diff against the installed file, and changes nothing. `APPLY=1` exports HEAD to a fresh root-made directory like `install-rollback-helpers`, installs root:root 0644 atomically, runs `systemctl daemon-reload`, runs the helper's own `_check_host_conf` on what it wrote and prints the unit's `DropInPaths`. It never restarts the service and adds no sudoers line. A refusal names the file and line, never the text. `deploy/local.conf.example` now points at `deploy/host.conf.example` instead of carrying a second copy of the block.
