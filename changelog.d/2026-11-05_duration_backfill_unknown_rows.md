### Added

- "Backfill book durations" has a row-level mode, `mode=unknownRows`, that measures the files nobody has measured, in any book, copies and `books/itunes` rows included (read-only on disk: the file is only read and the change is a database update). It first lends a file the length of another row at the same path with the same size, then uses the length fingerprinting already stored, and only then runs ffprobe — once per file, even when several rows point at it — several files at a time (`workers`, default 4, at most 16). A file ffprobe cannot read gets a counted attempt; a missing ffprobe, absent file or dropped mount records nothing; a file already at the three-attempt ceiling is left alone unless it got there through timeouts. Each book's totals are recalculated once, after the run, and only if a length was set. Narrow it with `fileIds` / `bookIds`; the default is a dry run that reports per book what it would borrow, promote and probe without running ffprobe. It runs on demand only and is on no schedule.
