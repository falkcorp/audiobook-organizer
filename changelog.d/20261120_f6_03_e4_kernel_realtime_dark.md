### Added

#### Kernel realtime hub, dark (F6-03 slice E4)

`core/kernel/realtime.go` builds the App's one realtime hub the way the events flip will wire it, but nothing calls it yet, so no runtime behaviour changes. It maps the `core.realtime.*` settings onto the hub, with a floor of 4096 on the resume ring so the journal's live tail cannot crowd every other topic out of the `Last-Event-ID` window. It returns the hub's bus subscriptions as a core boot problem when the two control topics (`core.principal.invalidated.v1`, `core.rbac.changed.v1`) are not declared, rather than letting a revocation wait for the next heartbeat. It supplies the hub's required rights refresh: a session is rebuilt from the user's stored roles, a core API key from the stored key's own scopes (never its owner's roles), the auth-off principal passes through, and a module compat principal is refused, because auth does not expose which key it came from. It also adds the run and shutdown hooks. A new `core/internal/httpmw` test pins that a per-write deadline and `Flush` reach the connection through every writer of the perimeter chain, over HTTP/1.1 and HTTP/2 with gzip negotiated, and that a deadline set that way is enforced.
