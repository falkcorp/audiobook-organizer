### Added

- core: minimal owner registrations of the three late-owner task kinds (dark). `core/integrations/providerhttp` declares `ReleaseHoldsTask`, `core/integrations/ai` declares `BatchPollTask` and `core/health/diagnostics` declares `ExportTask`: each returns the kind's final `tasks.Definition` (`core.integrations.release-holds`, `core.ai.batch-poll` scheduled live from `core.ai.schedules.batch_poll`, and `core.diagnostics.export`) over a one-method interim backend interface (`InterimHolds`, `InterimPoll`, `InterimExport`) whose method has exactly the kind's `Run` signature. The params and result types of each kind are declared with it. Nothing registers the kinds yet: the kernel does at P6 from F5, only when the app supplies the matching backend, and a nil backend is a constructor problem so registration fails closed.
