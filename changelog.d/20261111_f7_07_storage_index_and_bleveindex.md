### Added

- core: the full-text index contract and its bleve engine, both dark (nothing registers or opens an index until F7-09). `core/storage/derived.go` adds the storage generation of 05-storage section 5S.3.9: `storage.Derived` (one handle per index a module declares in the new `Spec.Derived` field of `core/storage/spec.go`), whose `Touch` blind-writes a fresh value from one shared `Sequence` into `c/storage/gen/<module>/<name>` in the same batch as the source write, and whose `Current` returns the store generation (`c/storage/epoch`) followed by the last touch value, so an artifact taken at another store generation (a restore, a relocation) never equals the current token even when the touch values coincide. `StampArtifact` and `ArtifactAccepted` are the two helpers a warm-start Snapshot and Load hook use: the stamp is read before the export and written by temp file, fsync and rename, and an absent, malformed or zero stamp, a zero current, or any other generation is a rejection (rebuild), never an error. `core/storage/index` is the engine-neutral contract (`Spec`, `Field`, `Index`, `Opener`, query constructors read through `Describe`) plus the durable dirty set under `c/index/<module>/<name>/dirty/<id>`: `Mark` joins the entity's batch and touches the generation, and `Clear` is a compare-and-delete on the mark's token, so a re-mark that commits while the reconciler is indexing is never lost; the price is that a concurrent mark of the same id can fail the entity batch's `Commit` with `storage.ErrConflict`, which callers retry with `storage.RetryOnConflict`. `core/internal/bleveindex` is the implementation: a closed mapping built from the `Spec` (standard and keyword analyzers only), an open failure that leaves the index Degraded instead of failing the module, a mapping-version change that drops and recreates, a reconciler (`Run` and `Stop`) that drains the dirty set through a bounded worker pool, a rebuild task `core.index.rebuild` (start permission `core:system.manage`) that fills a fresh index in `tasks.RunSeq` chunks, a `CopyTo` that stamps the generation read before the copy, and `Engine.Stats` for the three index gauges F7-09 registers. A page is refused (`ErrInvalidQuery`) when `From` or `Size` is negative or past a 10000 window, each value bounded before they are added so that a `From` near `MaxInt` cannot wrap the sum past the cap, and a facet size past the same window is refused. The only package-level variable is the mutex around bleve's process-wide scorch async-error-callback registry, and `core/app/noglobals_test.go` now bans every other use of that registry. `core/go.mod` gains `github.com/blevesearch/bleve/v2` and its dependencies, with `roaring/v2`, `bitset` and `bbolt` raised to the root's versions so module skew stays at none; the root module is unchanged. `core/archtest/thirdparty_allow.txt` admits bleve and `golang.org/x/sync/errgroup` (for `internal/bleveindex` only in practice), and the tasklint constructor allowlist lists `Engine.RebuildTask`, which is deleted with its directive when F7-09 registers the kind.
- core: review hardening of the full-text index (still dark). `Engine.CopyTo` now holds the index's writer lock for the whole copy, refuses an index that is not Ready (`ErrNotReady`), reads the generation first and refuses while any dirty mark is pending (`ErrNotQuiescent`), because the generation moves when a mark is written and not when the reconciler indexes it, so a stamp taken with a mark pending would later be accepted for an artifact missing that document. Every Search, Count and Facets call carries bleve's term-searcher cap (`Options.MaxTermSearchers`, default 1024) and, when its context has no deadline, a default timeout (`Options.SearchTimeout`, 30s); a query tree is bounded in nodes, depth and text size, a query string refuses regular expressions and wildcards that start with `*` or `?`, and a sort key must name a field of the Spec. An index is published to the reconciler only after its open finished (it was a data race), a Degraded index is rebuilt by the rebuild task and listed by `PendingRebuilds`, and an open that fails with the rebuilding marker present recreates the directory instead of degrading for good. The `.rebuilding` and `.mapping` markers and the artifact stamp are written with the new `storage.WriteFileDurable` (temp file, fsync, rename, directory fsync); the mapping marker also carries a fingerprint of the field declarations, so a `Fields` change that forgot the version bump recreates the index. The reconciler applies a failed chunk one document at a time so a poison mark cannot hold its neighbours, treats a panic in a module's `Document` or `Rebuild` callback as a failed load, stops one index's pass after `Options.PassBudget` so a large backlog cannot starve the others, and refuses a dirty-set cursor that does not advance. The seams the next rows build on are in `docs/agent-tasks/platform-core/seams.d/F7-07.md`.
