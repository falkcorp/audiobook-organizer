### Fixed

- core: the stage 8 Basic gate's review fixes (F3-05 follow-up, still dark). Build now records the gate's route facts on the very ServeMux it serves, inside its own registration loops, and only a successful Build counts (a failed one records none and still refuses later registrations). A route ending in a rest wildcard or a "/" no longer exempts its slashless spelling, and the dispatcher answers `GET /x` before a `/x/{rest...}` pattern as the miss it is instead of leaking ServeMux's 307. BasicExempt is decided per manifest entry, as OwnAuth is, so `HEAD /api/health` and a path only a generalised BasicExempt pattern matches are gated. Only `checkPosture` reports health, under a lock, so a request that read the old password can no longer flip the posture back. Credentials are compared as SHA-256 digests in constant time, so a length difference leaks nothing. The challenge realm is a `Realm` option with a neutral "Restricted" default.
