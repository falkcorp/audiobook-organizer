### Added

- `internal/books/roots`, books' native roots over core's `library` module, as a dark slice of the F7-09 integrations flip (T7): nothing calls it yet, so nothing changes at runtime until the fold. It holds the root reader over `library.Scope` (the books library root and the `import-<n>` import roots, with `RootDir()` as the single accessor the roughly 142 `AppConfig.RootDir` readers move to), the writer for books' `rootscan:<root ID>` rows (field-level updates under a per-root lock, so a scan recording its count and the UI switching a root off no longer overwrite each other), the watcher that keeps one `library.Scope.Watch` running per enabled import root and re-reads the set every five minutes, and the `.jabexclude` marker helpers with the `Scope.Resolve` path gate that books keeps from the old file browser.
