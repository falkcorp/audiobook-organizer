### Added

- core: the outbound HTTP gate and the metadata contract, dark (nothing in ABO uses them until the integrations wiring row). `core/integrations/providerhttp` now has the per-App `Registry`: one transport per instance carrying a persisted, reason-aware hold, a circuit breaker with an expiring probe lease, a token bucket shared per scope, a daily quota with background and interactive tiers and a zone-aware day (a counter it cannot read refuses the attempt), bounded retry that honours and clamps `Retry-After`, a response size limit and secret redaction, and `core/integrations/providerhttp/providerhttptest` for the gate-store conformance suite. The gate lives in the `*http.Client` that `Client()` returns, so an SDK that copies it and sets its own redirect policy keeps every control. `core/integrations/metadata` adds `Provider[Q, R]`, a hold-aware `Chain` with bounded fan-out, and a read-through answer `Cache` with positive and negative lifetimes and single-flight; `coretest.FakeProvider` and `coretest.ProviderHTTP` are its fakes (F7-02).

### Changed

- core: `internal/security/safehttp` moved into `core/integrations/providerhttp` as the egress guard, now the SSRF boundary for every adapter: the dial checks the resolved address, a hostname that resolves to a private address, a DNS-rebinding answer and a redirect into a private range are all refused, private ranges are reachable only on the instance's own admin-set origins and the operator's `lan_allow` list, and link-local addresses (cloud metadata) never. The cover downloaders import the new location and behave as before (F7-02).

### Security

- core: the outbound gate no longer leaks credentials. A redirect to another host drops every credential header (not only Authorization and Cookie) and a redirect from https to http is refused; error text, logs and response excerpts are scrubbed by name rule (token, key, secret, password, session, signature, Authorization with its scheme, quoted and unquoted forms, userinfo, bot-token path segments) in one linear pass bounded for a 16 MiB body; an unparseable URL prints only its scheme and host; an adapter can hand the outbound layer a query credential that never appears in any URL the caller holds. The guard blocks more metadata and translation ranges, a refusal no longer names the address it resolved, a base transport cannot turn TLS verification off, and private reach comes from the instance's Trust only.
- core: holds and retries. A hold is found by reference after a restart even on a custom or shared scope; a stalled store write blocks only its own scope; a failed boot read of holds is retried; a request that sent nothing refunds its quota and bucket token; a non-idempotent request is resent only when nothing was written or the server asked for it; the metadata cache keeps calls with different gate flags apart and can key answers by instance configuration.
- core: an indexer's download link reaches the indexer's own configured host or a public address, never another host the operator allowed for a different instance; a redirect from https to http on the same host and port is refused; Referer is dropped with the credential headers when a redirect leaves its host; an error body that echoes a query credential no longer carries it into the error detail; deleting an instance drops its gate state (hold, quota, scope mapping) so a re-created instance starts clean; the retry of a failed boot read no longer makes a request wait for the store.
