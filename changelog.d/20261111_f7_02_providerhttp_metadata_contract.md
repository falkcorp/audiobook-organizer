### Added

- core: the outbound HTTP gate and the metadata contract, dark (nothing in ABO uses them until the integrations wiring row). `core/integrations/providerhttp` now has the per-App `Registry`: one transport per instance carrying a persisted, reason-aware hold, a circuit breaker with an expiring probe lease, a token bucket shared per scope, a daily quota with background and interactive tiers and a zone-aware day (a counter it cannot read refuses the attempt), bounded retry that honours and clamps `Retry-After`, a response size limit and secret redaction, and `core/integrations/providerhttp/providerhttptest` for the gate-store conformance suite. The gate lives in the `*http.Client` that `Client()` returns, so an SDK that copies it and sets its own redirect policy keeps every control. `core/integrations/metadata` adds `Provider[Q, R]`, a hold-aware `Chain` with bounded fan-out, and a read-through answer `Cache` with positive and negative lifetimes and single-flight; `coretest.FakeProvider` and `coretest.ProviderHTTP` are its fakes (F7-02).

### Changed

- core: `internal/security/safehttp` moved into `core/integrations/providerhttp` as the egress guard, now the SSRF boundary for every adapter: the dial checks the resolved address, a hostname that resolves to a private address, a DNS-rebinding answer and a redirect into a private range are all refused, private ranges are reachable only on the instance's own admin-set origins and the operator's `lan_allow` list, and link-local addresses (cloud metadata) never. The cover downloaders import the new location and behave as before (F7-02).
