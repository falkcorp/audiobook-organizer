### Fixed

- Follow-up to #3325. On the Pebble path (`UseMemDB=false`), `ListBookIDs` stopped its key scan at `book:;`, which dropped every book whose ID starts with a letter. It now scans to `book:~`, like `GetAllBooksFullFrom`. The ISBN enrichment sweep no longer warns that its cursor book may have been deleted when the first page is empty. Since #3325 an absent cursor resumes at the next book ID, so an empty first page only means the cursor is at or past the last book, and that is now logged at info level as an ordinary wrap. `transcribe-book-intros` resumes at the next book ID when its checkpointed book was merged or deleted, where it used to restart from the first book. `GetAllBooksFullFrom`'s interface doc now states the two paging guarantees its callers rely on. New tests lock byte-order ID listing with mixed-case IDs on both store paths, and the 409 response to a concurrent deep signal-coverage request.
