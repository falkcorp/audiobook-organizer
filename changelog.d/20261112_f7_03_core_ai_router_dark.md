### Added

- core: the AI router, built dark (05-ai). `core/integrations/ai` holds the capability catalog (default-deny: an endpoint serves only the capabilities it ticks, a wildcard is refused), the router (priority and spill to a free slot, bounded failover on the classes that mean the endpoint is the problem, a cooldown bench with capped steps, embeddings pinned to one model, a local-only floor that refuses anything not provably local, `core.integrations.disabled` refusing every endpoint), structured output with a repair turn and a typed `QualityError`, and durable batch jobs. A batch job's row is written before any remote call, every write to it is a compare-and-set so a cancel is never reverted and a completed job is never applied twice, the poll never calls a module handler, and a module's apply run is staged in the same commit that moves the job. Eleven `mediacore_ai_*` metric families are pinned by a golden file. Nothing registers the router or reaches ABO until the kernel wiring (F7-09).
- core: the `core.openai_compat` adapter (`core/integrations/ai/openai`), the client half of HEAD's `OpenAIParser` and `EmbeddingClient`: chat, embeddings, transcription, model discovery and batches over `providerhttp`, for OpenAI and for the local servers that copy its wire. A private or loopback server is reachable only through an instance's `Local` grant, which only an interactive admin may set. The SDK's errors never leave the adapter: a 2xx answer that is not the API's JSON (a url that points at a web page, a body cut off) is reported as such, an empty or unknown audio MIME type is uploaded with a valid content type, and a query or credential in the `url` setting is refused instead of being stored and silently ignored.
- core: `aitest.JobStoreSuite` and `aitest.Conformance` (the store and adapter conformance suites), `coretest.FakeAI`, and the `NoAISDKOutsideAdapters` archtest: only the adapter imports `openai-go`.

### Changed

- core: the endpoint settings key HEAD called `host_roots` is `root_paths` (the Registry refuses a settings key that names a destination), and the endpoint locality is the string `auto`, `local` or `cloud`.
