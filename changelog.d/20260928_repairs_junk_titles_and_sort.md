- Repairs lane: a "Junk titles" fixer replaces the `maintenance.repair-junk-titles` op, which matched only five exact strings and was never applied. The old op id stays in the op-ID ledger as retired, and a timeline filter on it still finds the old op's rows. A new classifier (`metadata.ClassifyJunkTitle`) finds chapter positions ("01", "Chapter 12", "Disc 2", "Part IV", "Chapter One"), bare narrator credits ("read by narrator", "Narrated by the author"), a credit that names the book's own narrator, track tags ("Opening", "Intro", "Big Finish Ident"), placeholders ("Unknown Title", "Untitled"), bare roman numerals of two letters or more, and titles behind a track-number or punctuation prefix ("01 - Eldest", "01-Eldest", "07_Dune"). Real titles are left alone, among them "1984", "11/22/63", "Book 3", "I, Robot", "l'Étranger", "V for Vendetta", "'Salem's Lot", "10-Minute Toughness", "1-2-3 Magic", "9-11", "3_Body", "1. John", "2 - Kings", "Read by Moonlight", "X", "MIX" and "DIV". Each row proposes a title and names its source. Sources are tried in this order: the intro transcription, the title without its prefix, the highest-scoring cached metadata candidate with the same author, a score of at least 0.5 and no runtime mismatch, the folder or filename, then the series and number. For a title with a prefix or a chapter position, a candidate counts only when it agrees with the stripped title or the folder, so "01 - Eldest" never becomes "Eragon". For every kind, a transcription or candidate that disagrees with the folder or filename ranks below it, so "Audible Studios presents" never beats the folder "Excession" and a "Dune" candidate never beats "Dune Messiah". A folder reached by climbing past a chapter folder that sits directly under a library or import root may be the author, so without a matching transcription or candidate the book needs manual review. A folder or filename proposal is refused when it carries a format, edition or disc marker ("Unabridged", "MP3", "Tape 3", "CD01-02"), an ASIN or ISBN, a generic name ("merged", "output", "Book"), a person's name, or when it is a library or path root. A book another book owns a file of is listed as a fragment for the consolidation fixer. A book that only looks like one is listed as a possible fragment: a chapter-titled single file, a folder shared with other books, an author named like the folder, or a proposal that duplicates an existing or co-proposed title of the same author. A bare number such as "13" or "300" is listed as needs manual, including one filed in a folder named after itself ("13/13.m4b"); only unpadded numbers side by side in one folder ("1" to "20") are possible fragments. Books with a provider-supplied title are skipped, and so are books whose proposed title marks Doctor Who / Big Finish / Torchwood. Other skipped rows are listed as needs manual, user-locked, iTunes, or Doctor Who / Big Finish / Torchwood. Apply writes the title only. It records history so "undo last apply" restores the title, and an undone row can be applied again. It refuses a title that changed or became user-locked since the trial, and it passes over rows already written when an interrupted apply is re-run.
