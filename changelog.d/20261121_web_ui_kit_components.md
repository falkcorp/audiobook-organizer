### Added

- `@mediacore/ui-kit` gains the presentational pieces the shell's pages share (F9-05, dark: the running SPA still imports its own `web/src/components` copies): `FilterTagBar`, `BulkConfirmDialog`, `ErrorBoundary` (`returnHref` and `returnLabel` props), `KeyboardShortcutsDialog` (takes the shortcut table as a prop and names no route), `AnnouncementBanner` (takes the announcements, a storage key and an `onNavigate` callback; the host does the fetching), `useConfigurableTable` with `ResizableHeaderCell` and `ColumnPicker` (the storage key is used as given), and `ServerFileBrowser` with `{ browse, include?, exclude? }` props and its own `BrowseEntry` / `BrowseResult` types, so it imports no API client. Its folder context menu exists only when the host supplies the matching `include` / `exclude`.
- ui-kit's `ServerFileBrowser` reads `onSelect` and `browse` through refs: a parent that passed either inline used to make the directory reload on every render of the parent.
