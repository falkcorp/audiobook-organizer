### Added

- core: `core/library` completed and built dark (05-library). It adds the roots registry with identity-checked sentinels (every mutation is refused while a share is not the mounted volume it names), the transfer engine (Move, Copy, Hardlink, Reflink, Symlink and Auto; a copy goes to a temp name and is published with a hard link so it never overwrites; Replace is a compare-and-swap; every step is journalled so a crash at any point is completed or rolled back, never loses the source, and removes the source only after the destination is verified), quarantine and release, single-descriptor hashing with a byte-rate limit, a watcher with a poll fallback, the per-owner `Scope`, the `core.library.transfer-recover` task, the metrics families of 5L.8 pinned by a golden file, and live apply of the `core.library.*` keys. `core/internal/libfs` holds the byte-level primitives (no-replace rename, clone, chunked copy, directory fsync, and the descriptor walk the guarded view uses). Moving a directory is refused while a registered protection oracle cannot answer for a subtree, protected paths are tested in both directions (a source under one and one under the source), and a root's AppDir and Quarantine area belong to core: no other caller can name them, a symlink into one is refused wherever it is read or created, and a directory read for a person is decided from the open descriptor and its ancestry, never from a name looked up a second time. `core/internal/libraryhttp` adds one route, `GET /api/core/v1/library/browse`, a directory picker over the registered roots that lists directories only, hides dot directories and the reserved areas, follows no symlink, and reads in chunks so a directory of millions of entries costs a bounded amount of work. Nothing registers the task, mounts the route or builds the manager until the kernel wiring (F2-16, F7). Refusals are counted for Transfer, Quarantine, Release and Hash, and a path that is absolute or starts with `..` counts as an escape.
