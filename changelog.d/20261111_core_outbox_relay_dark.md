### Added

- core/outbox: the core outbox relay (F6-01), built dark. A producer stages a message into its own write batch (`outbox.Stage`), so the message and the producer's change commit together or not at all; the relay turns staged messages into per-topic, per-partition sequences in commit order, then delivers each to its consumers at least once, with bounded retry and backoff, dead letters an operator can retry or discard, and a retained backlog for a disabled module's consumers. Module consumers are task runs (`ConsumeIntoTask`), staged in the same batch as the cursor advance; plain, transactional and raw handlers are core's alone, refused for a module at registration and by a new archtest (`OutboxModuleConsumersAreTasks`). Delivery stops, loudly and without skipping, on a record written by a newer build. The package has no caller yet: the storage owner, `Manifest.OutboxConsumers` and `Deps.Outbox` arrive with F6-03, so a boot is unchanged. Adds `events.TopicSpec.PayloadType()`.
