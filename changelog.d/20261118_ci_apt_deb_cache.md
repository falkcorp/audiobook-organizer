### Fixed

- The `Repo Guards` job's system-package step (libtag1-dev and ffmpeg for the Whisper worker tests, now one cached install) and the `Fixture Tests` job's "Install system dependencies" step no longer depend on a live apt mirror when the cache is warm. The downloaded `.deb` files are cached (keyed on the runner image version and the package list), checked against a sha256 manifest and installed with `dpkg -i` on a hit; a miss still goes to the mirror, through the existing retrying `apt_install.sh`, so the mirror dependency is removed only on a cache hit. Caches saved on a PR ref are visible only to that PR: a new PR hits only entries saved from main. A failed part-way `dpkg -i` now falls back to apt with fix-broken enabled, and a run that cannot write the manifest saves no cache. The install also finishes an interrupted dpkg first (`E: dpkg was interrupted`). New script: `scripts/ci/apt_cached_install.sh`.
