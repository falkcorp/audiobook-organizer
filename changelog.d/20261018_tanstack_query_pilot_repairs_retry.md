The Repairs review lane loads, polls and applies through TanStack Query (`@tanstack/react-query` 5.104.1) on this branch. It is a measured pilot for decision D48, recorded in a draft PR and not merged. The fixer list, owner status and plan rows are queries. Trial and apply starts are mutations. Trial and apply polls are queries keyed by operation id, so leaving the lane or closing the page stops them. The lane no longer has any effects, refs or abort controllers of its own. One behaviour changes: an apply that is running while the reviewer switches to another lane now pauses its polling and picks it up again on return. On main it kept polling in the background. The app gets one shared query client (`web/src/lib/queryClient.ts`), which the event stream invalidates on `books.changed` and `operation.status`. Signing out clears that client's cache.
