### Added

- maintenance: the books module's own dependency values for the converted maintenance groups 2, 3, 4 and 6 (the boot passes and index repairs; the activity, temp-file and credits backfills; the book-file, transcribe, dedup-triage and index kinds; the merged-user-state, iTunes heal and activity compaction kinds), and for the maintenance jobs' store, built dark (F5-18c). Each store answers the reads from the library store and resolves the optional capabilities through the decorator chain; every write is one gated `internal/books/writer` call stamped with the method's whole row from the shared table, so a preview, a fenced run or a write outside the declared effects refuses it before the store is reached, and a read-only run, which has no writer, refuses every write. A missing dependency leaves the dependent field unset, so each group's own refusal (a nil stats sink, no queue, no library root) fires instead of a later nil dereference. The jobs store has no `Unwrap` and no embedded store; its raw key writes take their row from the key's family and an unclassified key is refused. The jobs store implements every capability the jobs and the merge package assert on their store, proven by a test that walks every job's assertions against the wrapper; writes that have no row in the shared table are refused. Nothing calls any of it yet, so behaviour is unchanged.

### Changed

- books: the metadata-fetch gated store embeds the inner store through an unexported alias, so a caller can no longer reach it as a field, and the no-hand-back test now checks fields as well as methods.
- maintenance: `sweep-pebble-metrics-ttl` takes a narrow sweeper capability from its store and falls back to the Pebble metrics store only when the store has none, so it works on a wrapped store (F5-18c).
- books: `MetafetchApplyRows` no longer declares the authors resource on the book-write row, matching the narrowed shared `ModifyBook` row (F5-18c, with F5-18j).
