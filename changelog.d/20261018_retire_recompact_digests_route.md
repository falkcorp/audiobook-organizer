Three operator routes are retired: `POST /api/v1/admin/recompact-digests`, `POST /api/v1/cache/invalidate` and `POST /api/v1/activity/clamp-summaries`. Nothing in the web app, scripts or the AudioBooth client called them. They now answer 410 Gone for one release, behind the same admin or settings permission checks as before, so an unauthenticated caller still gets 401 and a caller without permission 403. Digest recompaction has a replacement: start the "Recompact activity digests" background operation with `POST /api/v1/operations/v2` and `{"def_id":"maintenance.recompact-activity-digests"}`, which the old route only did on your behalf. The other two have no replacement: flushing the in-memory caches now takes a restart, and shrinking oversized old activity summaries has no tool. Both gaps are filed as TODO items. Their handlers and tests are deleted, along with the code only they reached: the cache flush helpers, the activity service's clamp call, the SQLite store's clamp pass and its `VacuumActivity` entry point. The WAL truncate that the activity checkpointer shares stays (its file is renamed `sql_activity_wal_truncate.go`), and no `database.Store` methods were removed, because all of this lived on the activity store.
