`POST /api/v1/admin/recompact-digests` is retired. Nothing in the web app, scripts or the AudioBooth client called it, and it only ever started the "Recompact activity digests" background operation, which `POST /api/v1/operations/v2` with `{"def_id":"maintenance.recompact-activity-digests"}` starts just as well. It now answers 410 Gone for one release, with that replacement named in the message; an unauthenticated caller still gets 401 and a non-admin 403. Its handler and tests are deleted; no store methods went with it, because the operation itself still calls the activity store's digest recompaction. `POST /api/v1/cache/invalidate` and `POST /api/v1/activity/clamp-summaries` were also on the retirement list but are kept for now: each is the only way to run its job (clearing a stale in-memory cache without a restart, and shrinking oversized historical activity summaries), so removing them waits on an owner decision.
