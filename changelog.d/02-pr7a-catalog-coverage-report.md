Added `catalog.coverage-report`, a read-only op that measures how many unidentified primary books (`ident:unasked` or `ident:asked_empty`) have a credited author with a harvested catalog block, how many have none, and which 50 unharvested credits would cover the most books. It writes nothing and makes no network call. Backed by two new exact-key catalog reads, `HasAuthorKey` and `CountAuthorNameBlocks`.

The covered count is an upper bound: `cat_author:name:` keys also exist for co-authors of harvested titles, so an author can have a block without ever having been harvested themselves. A catalog read error fails the run; books whose own rows cannot be read are counted as considered with unknown scope (`books_unreadable`, first 20 ids logged at warn). The op does not start while `catalog.harvest-authors` is running. The Library default-view predicate is now one exported function, `database.InLibraryDefaultView`, shared by the ident index counters and this op.
