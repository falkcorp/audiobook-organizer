### Fixed

- `itunes.regroup` skipped almost every iTunes book linked to a library copy. Any group whose files touched a book in a version group with a non-primary member was skipped, and every iTunes copy linked to a library copy is non-primary. It now skips only moves that would change a version group's editions: files leaving a group member (or emptying one), or files added to a group's primary copy, to a group with no identifiable primary, or to an edition that already holds another book's tracks. A non-primary iTunes edition may now receive its own album's ungrouped fragments. Primary flags follow the shared incumbent rule (an unset flag is primary when it is the group's only unset member), where before an unset flag always read as not primary. A book row with no creation time no longer crashes the snapshot. The dry run (still the default) reports how many groups the rule change unblocks and newly blocks, and breaks skips down by reason. The op writes database rows only: no file on disk, tag, or iTunes library file is touched.
