### Changed

- `Frontend CI` no longer runs the Go and frontend tests inside the shared `reusable-ci.yml` (`skip-tests: true` in `frontend-ci.yml`). Its `Go CI` job ran the whole non-short suite in one unsharded `go test -race` and took 40-57 minutes of the job's hard-coded 60 minute cap; 6 of the last 18 runs that reached a verdict were cancelled at the cap (the main push run 44262876677 among them). `ci.yml` already runs the same code on every Go change (`Go Tests (short, race)` in four shards plus the core shard, `Coverage Floor (PR gate)`, `Full-Size Tests (applygate, seqnum)`) and the same frontend tests and lint (`Frontend Unit Tests`, `Frontend Lint & Build`). The `Go CI` job still builds the module (`go build ./...`, about 4 minutes) and the job names are unchanged. What is given up: the tests `-short` skips no longer run on a PR that touches both `web/` and Go; `nightly.yml` still runs them. The inputs that only the removed tests used (`go-test-timeout`, `coverage-threshold`, `free-runner-disk`, `fetch-base-branch-tip`) are removed from `frontend-ci.yml`, and a comment there lists them for the day the tests are turned back on.
