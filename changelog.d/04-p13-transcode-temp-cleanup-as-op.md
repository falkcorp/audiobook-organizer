### Changed

- The hourly sweep of stale transcode temp files under each import path is now a visible scheduled operation, `maintenance.transcode-temp-cleanup`, run from the new `transcode_temp_cleanup` task, instead of invisible goroutines started once at boot. Same rule (temp files older than 2 hours) and cadence, but every run now has an operation row, and an import path added while the server is running is swept without a restart. A missing import path is logged and skipped. It is its own operation, with no schedule of its own, so it cannot swallow or be swallowed by the daily library-root `maintenance.temp-file-cleanup` sweep (which is unchanged); the two share a concurrency key and run one at a time.
