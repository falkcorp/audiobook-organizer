### Added

- core: `core/internal/authz` (dark), the implementation of `rbac.Checker`: `authz.Compile`, the compiled checker the kernel will inject as `rbac.Deps.Compile` (wildcards, implication, a key's checker as role ∩ key with the admin flag only when the key names `core:admin`, Sensitive scopes refused to non-interactive principals before admin, confinement decided on the effective set); `authz.AuthDisabled`, the auth-off principal (no `core:admin`, no `AuthRequired` or `Sensitive` scope, and the auth-off rule that drops `AuthRequired` members from an `AllOf`); and `authz.ForSystem`, the background-task principal holding exactly its scopes. Every checker fails closed: an undeclared scope is held by no one, admin included; a missing catalog, or a system scope set naming `core:admin`, a wildcard or a restricted core scope, yields a checker that holds nothing. A new guard, `archtest.NoSystemPrincipalOutsideKernel`, lets only `auth`, the tasks executor and `kernel` name the two privileged constructors and keeps `rbac` from importing `authz`. The shared matching vectors live in `core/rbac/testdata/match_vectors.json` (F4-09; nothing calls `authz` until F4-08).
