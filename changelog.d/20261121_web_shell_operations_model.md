### Added

- `@mediacore/shell` gains the operations model behind the operations indicator and the Activity page (F9-05, dark: nothing the running SPA imports changes): `createOperationsStore` and `useOperationsStore` over core's task-run wire shape (`TaskRunWire`, the payload of `/api/core/v1/tasks/runs` and `core.task.run-changed.v1`), the run-state helpers (`isTerminalRunState`, `isInterruptedRunState`, `isLiveRunState`, `isAwaitingDecision`, with core's own terminal set including `timed_out` and `interrupted_dropped`), and `operationGrouping`, the read-time folding of consecutive same-kind runs, typed over a structural row so a host's own row type passes through. The store takes its fetcher from the host, keeps the previous rows and sets `loadError` when a refresh fails, and lets only the newest load apply.
- Empty entry files for the shell's `layout/` and `pages/` and for ui-kit's `hooks/` and `components/`, re-exported from the package roots, so the layout, pages and presentational-piece rows each add a line instead of editing a package root.
