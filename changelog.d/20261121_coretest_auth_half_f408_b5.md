### Added

- `coretest`'s authentication half works: a harness whose App has a storage-declaring module boots with the identity boot on, `WithUser(name, perms...)` stores a real core auth user whose one custom role holds exactly those permissions (none means no role; never `core:admin`, nothing implied), `As(user)` returns a `Client` that carries the interactive session cookie core auth issued for that user, so stage 12 binds it as a sign-in and an `Interactive` or `Session` guard admits it, and `AssertPermission(t, h, method, path, perm)` checks that a signed-in user lacking `perm` gets 403 (a 401 fails the check) and a user holding exactly `perm` gets neither 401 nor 403. `Anonymous()` still carries no credential. The "needs core authentication" failure path is gone. `kernel.Kernel.IdentityServices` hands the harness the two services; only the harness reaches it, through the boot seam.
- `core/examples/hello`'s `TestSpecGoBlocksCompile/06-app-sdk` builds and boots every block of 06's hello and pins the waiting set empty.
