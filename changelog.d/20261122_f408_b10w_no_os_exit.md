### Fixed

- The server library no longer ends the whole program from inside its start-up code. Twenty-two places that stopped the process on a bad setting (an Audiobookshelf block with no signing secret, a storage backend missing one of the keyspaces that surface needs, an incomplete sign-in wiring, a service that would not build) now return an error that names the cause, and the program releases what it had begun to build and reports it. Nothing changes when start-up succeeds. A new check fails the build if one of these exits is added back, and tests exercise four of the former exits and confirm the program survives them.
