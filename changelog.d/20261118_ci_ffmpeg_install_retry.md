### Fixed

- The ffmpeg install steps in CI no longer block the merge queue on a flaky package source. The Windows Whisper trial ran a bare `choco install ffmpeg`, which failed on one HTTP error from the Chocolatey community feed and then failed `test_ci_has_ffmpeg_when_it_says_it_does`; it now runs `scripts/ci/install_ffmpeg_windows.ps1` (3 Chocolatey attempts, each killed after 150 s, with backoff, then a checksum-verified download of the pinned ffmpeg 9.0.2 release zip, failing with the reason if neither works). The two Linux steps that install ffmpeg through `scripts/ci/apt_install.sh` (the Repo Guards Whisper step, which hung about 15 minutes until cancelled, and the system-dependencies step of the test job) now have a 9 minute step timeout and a 60 s cap per apt call (`APT_INSTALL_CALL_TIMEOUT`, default still 600).
