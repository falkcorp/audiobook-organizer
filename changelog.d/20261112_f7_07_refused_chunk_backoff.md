### Fixed

- core: a document the full-text index refuses now backs off even when its whole chunk is refused (the index is still dark). The reconciler used to read a chunk in which every document failed as "the index is failing" and record no backoff, so a lone refused mark whose first window had passed was retried, and failed the pass with an error, on every pass. When a chunk's batch fails the reconciler now first asks the index whether it takes a write at all, with a probe batch that deletes an internal key that does not exist and touches no document. If the probe fails, the index is failing: the pass returns the error as before, no mark is blamed, and the documents are not retried one by one against a dead index. If it goes in, every document that then fails alone is refused, whether it is one of several or the only one: its mark stays pending, is counted and logged, backs off keyed on its token (a new write retries it at once), and does not fail the pass. The decision is the index's own answer to a write, not a count of how many documents failed.
