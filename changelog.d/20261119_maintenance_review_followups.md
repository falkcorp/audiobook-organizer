### Fixed

- `refetch-missing-authors` writes a book's primary author and its co-author credits in ONE commit (`ModifyBookCreditsRespectingLocks`), with the user's lock read inside it. Before, the primary was committed first and the co-authors second, so a crash or error between them left a book with a primary and no co-authors that no later run would repair (the book no longer looked authorless). A failed commit now leaves the book authorless with no credits, and a rerun finds it again. The old `partial` outcome is gone. A store that cannot make the one commit is refused once, before the first author row is created. One window stays open and is tracked in TODO.md: the author-resolve step can still create one author row before the commit, which stays uncredited if the commit is then held, skipped or fails.
- The author split refuses once up front, before it takes the library scan stand-down or creates any part author, when the store cannot commit a book's credits and row together. Before, it created every composite's parts and then failed each book with a warning, finishing without an error and leaving author rows nothing credited. A dry run is unaffected.
- The strip-merge report-only run reads its merge and delete plans on a bounded worker pool (`max(NumCPU, 4)`) instead of one plan at a time. Each plan is one unit with its own result slot and the dry runs write nothing; the results are folded into the report serially in plan order, so the counts and log lines are the sequential run's. The apply is unchanged and stays sequential.
- The merge-cleanup fixer reads a retired version's holder from the version's rows, not from the version record alone, and re-reads it when a version moves between two reads. A book that holds no rows of a retired version is no longer taken for its holder, so a lone same-work holder can now be offered as a repoint only when it really holds rows. Its hold reasons name the source book and version group each live book was reached through, which can belong to a co-loser rather than the dead book.
- Tests: a dead end entered through a book merged into the loser is a source (Y to loser to D), the loser with a version but no rows is not a source, and the stale comment about the trashed mate in the round-3 test is corrected. The author split fixtures use Batman characters.
