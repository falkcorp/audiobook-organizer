### Added

- core: the native identity, role, audit, settings, reset, module and ui routes (dark: nothing imports them until F4-08, and `Router.Build` refuses non-Public native routes until stage 13 lands). `core/internal/authhttp` registers every row of 05-authn 4.13: sign-in and sign-out, setup and bootstrap, the provider list, the OIDC start and callback (both `RateAuth`, with the native-app hand-off and HEAD's two fixed paths), the caller's own profile, password, sessions and API keys, every user's keys and sessions, the user list and account actions, invites and temp-login links. One-time credentials are shown once by the call that creates them, a sign-in sets the cookie and returns no token, and no submitted secret is echoed or logged. `core/internal/rbachttp` serves role CRUD with `If-Match` versions and accept-seed; `core/internal/audithttp` the audit list and NDJSON export; `core/internal/confighttp` the settings schema, read and `PATCH`; `core/internal/storagehttp` the factory reset, audited before it is staged; `core/internal/modulehttp` the module manifest and the OpenAPI documents; `core/internal/uihttp` the UI diagnostics and CSP report routes with their metric families.
- core/httpapi: `HandleRaw` and `RawDoc` for routes that set a cookie, redirect, stream or serve their own bytes, with `WriteError`, `DecodeJSON`, `Throttled` and `Error.WithRetryAfter`; the served OpenAPI schema now composes `config.Overrides()`, so durations render as in the settings schema.

### Fixed

- core/audit: audit visibility is default-deny. `audit.VisibilityOf` classifies every action of the action table as visible to every audit viewer or as user-scoped, and the audit routes show a viewer without `core:users.manage` only the former; credential and identity actions under any prefix (session, apikey, templogin, identity, invite, bootstrap, permission.deny) and any action core does not list are withheld. Before, only `core.auth.*` and `core.user.*` rows were.
