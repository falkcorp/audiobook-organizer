### Changed

- The `folder-books` Repairs fixer no longer reads a file with no measured duration as a short one. A new-book group with a member still unmeasured after the sibling borrow is held `skipped_unprobed` ("N file(s) have no measured duration; run Backfill book durations (unknown rows) for book(s) ..."), or `skipped_unreadable_audio` when a probe ran and failed (a timeout alone never counts as unreadable), instead of `skipped_fragmentary`; fragmentary is judged only on groups whose files are all measured. Both holds are hard (no owner click), carry the file ids, and offer a "Probe these files" action that starts `maintenance.duration-backfill` with `mode=unknownRows`; Plan itself still probes nothing. A group whose known files already cleared the chapter threshold is now also held while one member is unmeasured. `RowHold` gains optional `file_ids` and `action` (`RowHoldAction.params` is the op's params as raw JSON, like `PlanParams.params`). A group is split per member: a failed file and a never-probed file in the same group are held under both kinds. The action names only the files the backfill will act on (one shared rule, `unknownRowActionable`); a file it declines (flagged missing although on disk, excluded from scanning, a size that changed since the last scan, or failed to the attempt ceiling) stays in `file_ids` and the hold's Why says what settles it. The row's `unmeasured_majority_shelf_files` readout counts the majority shelf's rows the hours leave out.
