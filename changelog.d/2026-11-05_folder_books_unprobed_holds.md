### Changed

- The `folder-books` Repairs fixer no longer reads a file with no measured duration as a short one. A new-book group with a member still unmeasured after the sibling borrow is held `skipped_unprobed` ("N file(s) have no measured duration; run Backfill book durations (unknown rows) for book(s) ..."), or `skipped_unreadable_audio` when a probe ran and failed (a timeout alone never counts as unreadable), instead of `skipped_fragmentary`; fragmentary is judged only on groups whose files are all measured. Both holds are hard (no owner click), carry the file ids, and offer a "Probe these files" action that starts `maintenance.duration-backfill` with `mode=unknownRows`; Plan itself still probes nothing. A group whose known files already cleared the chapter threshold is now also held while one member is unmeasured. `RowHold` gains optional `file_ids` and `action`.
