### Added

- core: `core/integrations` (dark), the one integration-instance registry of 05-metadata M1. It declares the kind-neutral contract (`Ref`, `Meta`, `Descriptor` built only through `NewDescriptor`, `InstanceConfig`, `Env`, `Limits`, `Health`, the error taxonomy with `ClassOf` and its done-parent rule, and an `Error` whose string never carries the remote body excerpt). The `Registry` registers adapters under their module prefix, loads the native rows of `c/integrations/instances/<kind>/<id>` (`NativeInstanceStore`, over the new `core/internal/instancestore`), and overlays the operator's `integrations.<kind>.<instance>.<field>` values in memory without persisting them: an overlaid field is locked, and an operator-only instance is served under the ID its paths name. `Put` writes the row, its secrets and its audit records in one batch, needs `core:integrations.manage`, needs `core:admin` from an interactive principal to set `Local`, clears every secret on a destination change (the scheme, host or port of a URL field or of the host-and-port pair, read from the effective view with the operator overlay applied) unless it is re-supplied, never counts an echoed or masked value as a re-supply, binds an operator secret to the destination an operator or an admin chose, and releases the instance's auth hold when new credentials arrive. A stored secret is served only to the effective destinations it was written for (a row that never recorded them serves none). While an operator value moves the destination it is withheld but kept: a Save that moves no destination and writes no secret keeps it, removing the operator value serves it again, and health names it `integration_secret_withheld_destination_moved` (misconfigured for a required field, degraded for an optional one). An admin Save while the operator supplies the whole URL keeps the operator-secret approval an earlier admin Save recorded for the stored URL. A draining instance never reads a secret written after the instance moved, and an instance force-closed before its first build is never built. `Register` refuses an adapter whose settings would hide a destination from these rules: a destination-named field (`url`, `host`, `proxy`, `address`, `port` and the like) that is neither a `format=uri` string nor part of a host-and-port pair, or a secret or destination field below the top level. `Test` probes an unsaved config, persists nothing and returns only OK, the class and a status. A store that cannot be read serves no stored instance and refuses every write; `core.integrations.disabled` makes no outbound call at all. Swapped-out instances are closed only after their leases drain or the drain timeout passes. `NativeImporter` gives an app's cutover step a create-only, audited import into its own batch. `integrationstest` holds the instance-store conformance suite and shared fakes. A new guard, `archtest.IntegrationsDescriptorCallers`, lets only the kind packages call `NewDescriptor`. The four metric families of M1.8 are pinned by `core/integrations/testdata/series.golden`. Nothing builds a `Registry` until the integrations flip (F7-01).
