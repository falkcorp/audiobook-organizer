Added a read-only "retired-versions" preview to the Repairs lane in /review. It looks at every book in the trash and sorts it into one category, naming the live book it would be retired onto (the end of its merged-into chain, or the version group's single primary; either needs the group to have a live member). Books that would be retired: `would_retire`, and `would_retire_same_path` (a file record shares its path with a live book's record; both records are kept). Books that stay put, each with its own count and clickable rows: `itunes_needs_owner_approval`, `too_recent` (trashed less than 14 days ago; `{"min_age_days":N}` changes that), `age_unknown`, `has_listening_state`, `listening_state_unknown`, `user_deleted`, `no_book_files`, `target_ambiguous`, and the books with no live target, split into `no_target_files_missing` and `no_target_files_present`. Nothing is written: the preview changes no book or file record, and Apply refuses with "not implemented until PR 7". The scan runs on every CPU core and fails rather than guess if the ownership lookup is not ready.
