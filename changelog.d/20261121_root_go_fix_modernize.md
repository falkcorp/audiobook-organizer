### Changed

- The root module's Go code is brought up to date with what `go fix` proposes (414 files): `new(expr)` in place of one-line pointer helpers, `for range n` loops, `sync.WaitGroup.Go`, `errors.AsType`, `slices.Contains`, `maps.Copy`, `strings.SplitSeq`, `reflect.TypeFor` and similar. `go fix -diff ./...` at the root now prints nothing. Pointer helpers that `go fix` inlined everywhere but left defined (marked `//go:fix inline`, with no callers left) are deleted, so staticcheck reports no unused function. Nothing gates it in CI: by design only `core/` runs `fix-check`. The rewrites keep behaviour the same. One source guard noticed a change of shape: the cutover's hidden-permission-check pin now sees the guest-key "admins get no first phone-app key" check, because it is written as `slices.Contains` now. That check tests the target user's roles, not the caller's, so it is listed as an exclusion with that reason.
