### Added

- The core-route half of the auth-off reach oracle (F4-08, test only, no behaviour change): `core/kernel` boots the identity kernel with `core.auth.mode` disabled loopback-only, remote-reachable and behind a trusted proxy, probes every core route the router lists as the auth-disabled principal, and holds each answer (status and problem code) to an expected table written from 05-authn 4.11 and 05-rbac 4.11 with a spec clause per row. A core route with no row, a refusal from the wrong layer, an Interactive, Session or Owner route that admits the principal, a verdict that differs between postures, and a route wider than HEAD's recorded `authoff` verdict each fail by name; the start-up refusal (`ErrAuthDisabledRemote`) and the `DisabledRemote` posture are pinned for non-loopback listeners and trusted proxies.
