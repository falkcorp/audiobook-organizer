- Review page "Find all duplicates" now starts one server-side operation, `dedup.run-all`, instead of chaining the steps from the browser. It runs similarity data, audio fingerprints, find and score, AI review and a no-write score preview as child operations, checkpoints the step it is on, resumes there after a restart, and shows its progress in Operations. Closing the tab no longer stops it. The confirmation prompt when automatic merge is on is unchanged.
- Review page "Force full rescan" now runs `dedup.full-scan`, the scan that fills the Dupes tab's queue, and opens the Dupes tab when it finishes. It used to run `dedup.book-scan`, whose groups were kept only in a 30-minute server cache and shown on the /dedup page. It now asks first when automatic merge of identical copies is on.
