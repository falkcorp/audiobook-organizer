### Fixed

- The apt install of `libtag1-dev`, `ffmpeg` and `libchromaprint-tools` no longer fails all three attempts on one slow mirror (queue run 44400288911, `Fixture Tests` and `Repo Guards`). This is #4729 again after its revert (#4734), with its two real defects fixed. (1) The mirror rewrite never rotated: the hosted ubuntu-26.04 runner's archive source is the deb822 line `URIs: mirror+file:/etc/apt/apt-mirrors.txt` in `/etc/apt/sources.list.d/ubuntu.sources`, with the real host only in that list file, and #4729 only knew `http://...archive.ubuntu.com` URIs, so all three attempts hit `us-east-2.ec2.archive.ubuntu.com`, which was delivering the ffmpeg set at about 108 kB/s. `scripts/ci/apt_install.sh` now also replaces `mirror+file:`, `mirror+http(s):` and `mirror:` URIs (deb822 and classic lines), never touches comments or `security.ubuntu.com`, and is tested against byte-for-byte copies of the runner image's files in `scripts/testdata/apt/`. (2) The throughput floor in `scripts/ci/apt_watchdog.py` was correct about where apt writes (`<archives>/partial/`, renamed into `<archives>/`, summed recursively) and about the slow mirror, but its kills were logged without the measured rate, so they looked like false kills; it now logs the rate on a kill, a progress line every 30 s and a summary on exit, keeps its size reading monotone across the partial-to-archive rename, and is tested against that layout. The cached `.deb` set from #4715 now saves right after the install and falls back to a set saved on another runner image, because actions/cache's end-of-job save never ran for cancelled main pushes.
