### Fixed

- The apt install of `libtag1-dev`, `ffmpeg` and `libchromaprint-tools` no longer fails all three attempts on one slow mirror (queue run 44400288911, `Fixture Tests` and `Repo Guards`). Two causes. First, the cached `.deb` set from #4715 was never warm where it mattered: the cache was saved by actions/cache's end-of-job step, pushes to main cancel each other, so main never saved it, and PRs and merge-queue runs can read only main's caches (the one `apt-debs` entry that existed sat on a merge-queue ref nobody else can read). The jobs now restore and save in separate steps, saving right after the install, and fall back to a set saved on another runner image. Second, a miss still retried the same mirror. `scripts/ci/apt_install.sh` now switches the Ubuntu archive host to `azure.archive.ubuntu.com`, then `archive.ubuntu.com`, on attempts 2 and 3, keeps partial downloads between attempts (apt resumes them), and kills a download-only step on a throughput floor (under 400 KiB/s over 20 s) instead of waiting out the wall-clock cap; the last attempt has only the cap. The floor logic is `scripts/ci/apt_watchdog.py`, tested with the rotation in `scripts/test_apt_install.py`.
