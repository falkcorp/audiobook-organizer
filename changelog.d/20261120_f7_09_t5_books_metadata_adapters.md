### Added

- Dark slice of F7-09 T5: `internal/books/adapters/metadata`, the six metadata sources (Audible, Audnexus, Google Books, Hardcover, Open Library, Wikipedia) as `books.<id>` adapters over core's metadata contract, with HEAD's budgets, a per-request credential read from the secret store, a chain constructor, and Audible's author listing as an optional interface; plus additive `internal/metadata` constructors that take the HTTP client, base URL and credential instead of reading process globals. Nothing registers the adapters until the integrations flip, so runtime behaviour is unchanged. Core's settings schema cannot declare the dotted `credentials.<k>` settings the M6 cutover writes, so such an instance reads misconfigured; this is pinned by a test and tracked in `todo.d`.
