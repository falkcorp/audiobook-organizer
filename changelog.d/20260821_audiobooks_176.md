### Added

#### Read-only census tool for ungrouped-but-explicitly-non-primary books

`tools/cmd/orphan-nonprimary-census` counts books that have no version group
(`VersionGroupID` nil/empty) **and** are explicitly marked non-primary
(`IsPrimaryVersion` set to `false`, not merely unset). This is a distinct,
much smaller anomaly (sampled at ~41 books) from the ~5,731 books with no
`IsPrimaryVersion` flag at all — the codebase's own convention treats a nil
flag as primary/visible, so the tool deliberately excludes nil rather than
counting it as non-primary, which would have inflated the census roughly
140x. The tool is strictly read-only: it fetches the book list from the API
and writes a CSV report (with `CreatedAt`/`UpdatedAt` for correlating the
anomaly against known job runs); it performs no database writes, no file
moves, and no mutating API calls.
