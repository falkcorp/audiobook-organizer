# The third-party import paths core may use (03 R1(b), TestCoreImportsOnlyCore).
# One import-path prefix per line; a prefix also admits its sub-packages
# (github.com/x/y admits github.com/x/y/z, never github.com/x/yz). A line
# starting with = admits that one path and none of its sub-packages. Blank
# lines and lines starting with # are ignored.
#
# Empty at R1's first core PR: core imports only the standard library and its
# own packages. R1-10 and R1-12 add the modules they pin (13 §13.5.2), each
# with a one-line reason.

# R1-12: internal/jsonschemax, the one JSON Schema reflector (13 §13.5.2, pinned
# at v0.4.3 by check_module_skew.py --pin and a Dependabot ignore).
github.com/google/jsonschema-go

# R1-10: metrics, the provider construction (05-metrics §3, §13 item 1). The
# OTel API and SDK the Provider builds (meter, tracer, propagator, resource,
# semantic conventions), each a module at the root's version
# (check_module_skew.py).
go.opentelemetry.io/otel/attribute
go.opentelemetry.io/otel/metric
go.opentelemetry.io/otel/propagation
go.opentelemetry.io/otel/sdk
go.opentelemetry.io/otel/semconv
go.opentelemetry.io/otel/trace
# R1-17: httpapi stage 2 (internal/httpmw) marks a server span failed with
# span.SetStatus, whose code type lives here; same otel root module.
go.opentelemetry.io/otel/codes
# R1-10: the Prometheus exporter, pinned at v0.69.0 (13 §13.5.2) by
# check_module_skew.py --pin and a Dependabot ignore: its translation of OTel
# names into served family names is what every dashboard reads.
go.opentelemetry.io/otel/exporters/prometheus
# R1-10: the optional OTLP/gRPC metric push and trace export, and the gRPC
# transport credentials their endpoint options pin (the OTLP tests also run
# real gRPC collectors).
go.opentelemetry.io/otel/exporters/otlp/otlpmetric/otlpmetricgrpc
go.opentelemetry.io/otel/exporters/otlp/otlptrace/otlptracegrpc
google.golang.org/grpc
# R1-10: the Provider's private registry, its Go and process collectors and
# its handler; the exposition model the family-owner check and metricstest
# read; the name translator that check uses (the exporter's own, so a family
# name is computed exactly as the exporter serves it).
github.com/prometheus/client_golang
github.com/prometheus/client_model
github.com/prometheus/otlptranslator
# R1-10, tests only: the pinned-translation test reads model's validation

github.com/prometheus/common/model
go.opentelemetry.io/proto/otlp
# R1-20: storage/codec's Zstd codec (05-storage §5S.3.3: "tag 'z' when
# compressed (klauspost/compress)"), at the root's version
# (check_module_skew.py; 13 §13.5.2 keeps it in core).
github.com/klauspost/compress/zstd
# R1-20: the storage engine (05-storage §5S.3; 13 §13.5.2), imported only by
# internal/pebble and storage, at the root's version (check_module_skew.py).
# Its vfs package is the filesystem seam of the engine, the sidecars and the
# checkpoint (tests use vfs.NewMem and vfs.NewCrashableMem, §5S.6).
github.com/cockroachdb/pebble/v2
# R1-20, tests only (13 §13.5.2 "tests only"): the compaction progress
# reporter's tests, moved with it from ABO's internal/compactprogress, at the
# root's version.
github.com/stretchr/testify
# R1-15: app.InstallProcessDefaults, the one function that sets the OTel
# globals (05-logging §3, L3): the otel root package only (its sub-packages
# stay listed one by one above), and logr for the value-dropping SDK sink
# (05-logging L6) with stdr, the SDK's default logger that its restore puts
# back.
=go.opentelemetry.io/otel
github.com/go-logr/logr
github.com/go-logr/stdr
# F2-17, test-support only (03 §3.5 R4; 13 §13.5.2): archtest/tasklint is a
# go/analysis analyzer (05-tasks §5T.8.4; 06 §6.11.4 row H: an explicit
# analysis.Analyzer flag set), and archtest/guards loads packages with
# go/packages. Only those two packages import it: archtest and coretest, which
# every module's tests link, do not, and no non-test core package does
# (TestTasklint_TestSupportOnly). At the root's version (check_module_skew.py).
golang.org/x/tools
# F4-02: auth/password, the one password hasher (13 §13.5.2 "golang.org/x/crypto
# ... auth: password hashing"): argon2id for new hashes and bcrypt to verify
# the hashes HEAD stored, at the root's version. Only those two packages.
=golang.org/x/crypto/argon2
=golang.org/x/crypto/bcrypt
# F4-02: auth.NormalizeEmail (moved from ABO's internal/util/email.go): NFKC
# before lower-casing, so two spellings of one address fold together (13
# §13.5.2 golang.org/x/text). Only the norm package.
=golang.org/x/text/unicode/norm

# F4-03: auth/oidc, the generic OIDC and OAuth2 sign-in (05-authn §4.7): discovery
# and id_token verification through go-oidc, the code exchange and PKCE through
# oauth2 (and its github endpoint), at the root's versions
# (check_module_skew.py). go-jose is imported directly only by auth/oidc's tests,
# where it signs the id_tokens of the fake providers, and is otherwise a
# dependency of go-oidc. The allow line is not test-scoped: it admits go-jose
# for any core package, so a new direct import in non-test code needs its own
# review.
github.com/coreos/go-oidc/v3
github.com/go-jose/go-jose/v4
golang.org/x/oauth2
