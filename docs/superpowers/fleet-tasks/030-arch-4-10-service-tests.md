# Task 030: 4.10 — Service-layer unit tests with mock stores

**Depends on:** none
**Estimated effort:** L
**Wave:** 9 (architecture)

## Goal

Add unit tests for `AudiobookService`, `OrganizeService`, `MetadataFetchService`, and
`MergeService` using MockStore — testing error paths, edge cases, and business logic in
isolation without HTTP or real DB.

## Context

- Services: `internal/audiobooks/service.go`, `internal/organizer/`, `internal/metafetch/service*.go`,
  and merge service (find by searching for `MergeService` or `MergeBooks`)
- MockStore: `internal/database/mocks/MockStore.go` — generated by mockery
- DI: these services accept the store as an interface, making them testable with the mock
- Test pattern: `testify/mock` — look at existing tests in `internal/server/*_test.go` for examples
- DO NOT use `t.Skip` — write real tests

## Files to create/modify

- `internal/audiobooks/service_test.go` (new)
- `internal/organizer/service_test.go` (new, or add to existing)
- `internal/metafetch/service_test.go` (new, or add to existing)
- Merge service test (new)

## Instructions

### Pattern to follow

```go
func TestAudiobookService_GetBook_NotFound(t *testing.T) {
    mockStore := new(mocks.MockStore)
    svc := audiobooks.NewService(mockStore)

    mockStore.On("GetBookByID", mock.Anything, "nonexistent").Return(nil, database.ErrNotFound)

    _, err := svc.GetBook(context.Background(), "nonexistent")
    assert.ErrorIs(t, err, database.ErrNotFound)
    mockStore.AssertExpectations(t)
}
```

### Test coverage targets

For each service, write tests covering:
1. **Happy path**: normal input returns expected output
2. **Not found**: store returns ErrNotFound → service returns appropriate error
3. **Store error**: store returns generic error → service propagates or wraps it
4. **Invalid input**: empty ID, nil params → service returns validation error
5. **Idempotency**: where relevant, calling twice is safe

### `AudiobookService` test cases

- `GetBook(id)` — found, not found, store error
- `UpdateBook(book)` — success, store error, protected path rejection
- `DeleteBook(id)` — success, not found, has-files error
- `ListBooks(filter)` — empty result, paginated result, filter applied

### `MetadataFetchService` test cases

- `FetchCandidates(bookID)` — cache hit, cache miss → fetch, rate limit error
- `ApplyCandidate(bookID, candidateID)` — success, book not found, candidate not found
- `RejectCandidate(bookID, candidateID)` — success, store error

### `OrganizeService` test cases

- `OrganizeBook(bookID)` — success, protected path blocked, missing metadata
- Organize with dry_run=true — no writes made

### `MergeService` test cases

- `MergeBooks(keepID, mergeID)` — success, same-book merge rejected, store error
