# Spec review round 3: Go modules, dependencies and build (MOD3)

Reviewer stance: antagonistic. This round has two jobs: (A) re-check every round-1 and round-2 MOD
BLOCKER and MAJOR, and (B) find defects that the revision introduced. Focus files: 03 v1.5.1
(normative), 04 v1.2.1, 09, 12, 13, plus 05-http-api, 05-metrics and 06 where they decide build order.
The round-1 and round-2 resolutions (cross-cutting 1–12, R2-1…R2-8) are treated as binding.

Evidence commit for code: `748fd787a` (the spec branch changes only `docs/` and one `todo.d/`
fragment). Code anchors are repo-relative. Every experiment ran either read-only against the checkout
(`go list`, `go mod tidy -diff`, `go fix -diff`; `git status` stayed clean) or in a scratch directory,
using go1.27.0 through `GOTOOLCHAIN=auto` and the warm module cache.
