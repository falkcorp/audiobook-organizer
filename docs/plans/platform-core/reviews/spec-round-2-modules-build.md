Reviewer stance: antagonistic. This round re-checks every round-1 MOD BLOCKER and MAJOR, then looks
for new defects, mostly cross-file contradictions introduced by the revision. Focus files: 03 v1.4.0
(normative), 04 v1.1.0, 09 v1.1.1, 12 v1.1.0, 13 v1.2.0, with 06/07 where they touch build wiring.

Code anchors are repo-relative. All experiments ran in a scratch directory, never in the repo, using
the warm module cache and go1.27.0.
