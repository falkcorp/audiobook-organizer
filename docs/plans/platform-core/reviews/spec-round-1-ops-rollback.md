# Spec review round 1: ops, rollback and incremental delivery (lens OPS)

Reviewer lens: can ABO ship, deploy and roll back after **every** stage S0–S11 of
[09](../../../specs/platform-core/09-abo-on-core.md)? Code anchors are at `748fd787a` (the spec commits on
top of it change no code). Spec anchors are `file §section (line)`. Counts: **5 BLOCKER, 18 MAJOR,
4 MINOR** (27 findings).

Deployment facts checked against the repo before writing:

- `make rollback` is the only committed rollback (`Makefile:892-917`): storage-format guard
  (`scripts/storage_format_guard.py`), unit-type match, `.prev` swap, `deploy-wait-ready.sh … 300`.
  `make deploy` is **not** committed. It exists only in `Makefile.local.example:88-110`, which copies
  `$(DEPLOY_BIN)` to `.prev` on every deploy, with no guard.
- Committed unit `deploy/audiobook-organizer.service`: `Type=notify`, `TimeoutStartSec=300` (:87),
  **no `TimeoutStopSec`** (so the systemd default applies), `Restart=on-failure` (:111),
  `StartLimitBurst=5`/`StartLimitIntervalSec=60` (:81-82), `ExecStart … serve --host 0.0.0.0 --port 8484`
  with **no `--db`** (:92), and the DB path comes only from `Environment="DATABASE_PATH=…"` (:98).
- Docker: `Dockerfile:54-55` runs `COPY go.mod go.sum ./` then `go mod download` before `COPY . .`
  (same in `Dockerfile.build-cgo:52-53`). `docker-compose.yml:20-22` sets `BASIC_AUTH_*` env names
  and has no `stop_grace_period`. Prereleases skip Docker (`prerelease.yml:48`). The production release
  builds it (`release-prod.yml:53`). No PR or main CI job builds the image.
- Updater at HEAD: it downloads `releases/latest` (`internal/updater/updater.go:295`), deletes `.old`
  right after the swap (`:278`), and restarts with `os.Exit(0)` (`:331-334`). Under
  `Restart=on-failure`, systemd does not restart a process that exits 0.
- Prometheus: "nothing in this repo scrapes it or alerts on it" (`deploy/prometheus/README.md:9-10`).
  `/metrics` needs an API key.
