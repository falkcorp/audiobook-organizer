across two modules, Makefile/`make ci` gates, the go1.27.3 bump, and the measurability of the 12 split
criteria. Focus files: 03 (v1.2.0, normative), 04, 09, 12, 13.

Evidence commit `748fd787a`. Code anchors are repo-relative. "Verified" means I ran it in a scratch
directory (never in the repo). Experiments used the warm module cache and go1.27.0 via `GOTOOLCHAIN=auto`.

## Notes on claims that held up

- E1/E7/E8/E9/E10 reasoning is correct for the experiments actually run. Root-cause attribution to
  `cockroachdb/errors@v1.14.0` and the pruning explanation are sound. The gaps are scope (MOD-3, MOD-4), not logic.
- `go mod tidy` in `core/` with pebble behaves like the root (pruned; exit 0; no monolithic genproto
