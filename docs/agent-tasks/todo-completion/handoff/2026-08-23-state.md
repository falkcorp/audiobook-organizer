### Two findings from #2805 worth carrying forward

- **`omitempty` made a tri-state field look binary.** `is_primary_version` is
  `*bool` with `json:"...,omitempty"`, so nil omitted the key rather than
  emitting `null`. Every downstream reader — the UI, `TODO.md:3882`, and this
  handoff's first draft — described the symptom as the field "saying false".
  It never said anything. **When a Go pointer field looks like it serializes a
  third state, check for `omitempty` before describing the wire format.**
- **A surviving mutant was DISCLOSED, not papered over.** #2805's matrix killed
  5 of 6; M2 (`CountAudiobooksFiltered`'s nil-is-false fallback) survives —
  neutralizing it leaves the package green, confirming #2786's own claim that
  the branch is unreachable. Reported as a known coverage gap instead of
  manufacturing a third test to make the table look complete.

### #2785 detail — a real contract change, not just a default

Removing the hardcoded `192.168.0.20` default exposed a latent path:
`EffectiveLLMMode()` fell through to `openai` whenever an API key was present
and any LLM consumer was enabled, and `enable_ai_parsing` defaults to **true**.
That is the shape of the 2026-08-16 incident documented in that function's own
comment (a blank config silently chose a paid service and ran a library scan
until `credit_balance_exhausted`, 77 batches failed, the watchdog killed it).

Measured before/after:

```
BEFORE -> EffectiveLLMMode() = "local"
AFTER  -> EffectiveLLMMode() = "openai"
```

The hardcoded address had been keeping the local-preference guard permanently
armed. Derivation now stops at `disabled`; `ai_backend.llm_mode = "openai"` is
the explicit opt-in. **Three pre-existing tests asserted the old fallback** (two
in `internal/config/aibackend_test.go`, one in `internal/ai/register_test.go`)
and were updated — so the fallback was deliberate and documented, merely
unreachable in practice. `EffectiveEmbeddingMode` has the same bare-key shape but
reads `embedding.base_url`, which already defaulted to empty; untouched and
flagged as pre-existing.
