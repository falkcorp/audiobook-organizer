## Decisions commit 2 must make

- The four old dedup addresses (`/dedup`, `/dedup/labels`, `/authors/dedup`, `/books/dedup`) are redirects into a Review lane today (`DedupRedirect` in `App.tsx`). They are former paths, so D13 makes them `NotFound`; the table says so. Confirm, then delete `DedupRedirect`. `/books/dedup` in particular must not stay a redirect, because `/books/` is books' prefix after the flip.
- The mediacore preset's boot script has no branch for a saved `system` colour mode (HEAD's inline script followed `prefers-color-scheme`). Nothing in ABO or the shell writes `system` to `app-theme-mode` (both theme toggles call `setMode('light' | 'dark')`), so it is reachable only by editing storage by hand. The fix, if wanted, is in core's `themeBootScript`, not in ABO.

## Where the draft PR stands

Commit 1 (vite preset, no inline theme script), the e2e mock for `/api/core/v1` (`web/tests/e2e/utils/mockCoreApi.ts`) and the spec set that holds across commit 1 are in. Commit 2 (main.tsx on `createShell`, the books module, `/books/` routes, re-export deletion, the status-literal mapping, the e2e switch from `paths` to `shellPaths`) and commit 3 (Go: `UIBundle`, `ServesSPA`, gin SPA deletion) are not.
