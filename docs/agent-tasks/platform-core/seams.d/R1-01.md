# R1-01 seams and coined names

Names the first core PR added that later rows may rely on (implementation plan §(n) rule 5).

## Core packages (`github.com/falkcorp/mediacore/...`)

| Name | Where | What it is |
|---|---|---|
| `buildid.Binary(version) (string, error)`, `buildid.Commit() string` | `core/buildid` | The brief's contract. `Binary` hashes `os.Executable()` on every call; there is no cache (R5 forbids package state), so callers compute it once per process. |
