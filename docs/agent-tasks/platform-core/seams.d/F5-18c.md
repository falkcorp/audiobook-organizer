# F5-18c seams and coined names

F5-18c builds the books module's dependency values for the converted maintenance groups, dark: nothing calls a builder until F5-18 hands its result to a group's Kinds function. Obligations: O1 (wiring half), O2, O15, O16, O21, O29.

## What was built

- `internal/plugins/maintenance/deps_gate.go`: the shared pieces of every group builder. `booksGate` wraps one `writer.Gate`; a nil run writer (a ReadOnly kind) becomes `noRunWriter`, which refuses every gated write wrapped in `ErrOutsideEffects`; `reportPathOver` is the confining report-path resolver (`library.ReportPathNotify`) for a library root.
- `internal/plugins/maintenance/deps_t6g2.go`: `newT6G2Deps(src, host, rootDir)`. `booksT6G2Store` serves the group's reads and resolves the optional capabilities with `database.AsCapability` on every call; `booksT6G2Writer` makes every write one gated call stamped with the method's whole row from `resources.Table()` through `t6WriterView`.
- `metafetchgate.Store` embeds the inner store through the unexported alias `innerStore` (the #4772 r4 minor); the no-hand-back test covers fields.

- Deadcode: the builders, the gate helpers and the store and writer methods are reachable from tests only until F5-18 calls them; the 43 group-2 and 56 group-3 identifiers are baselined in `scripts/deadcode-baseline.txt`, as F5-09, F5-11, F5-13 and F5-18b did. F5-18 deletes the lines as it wires them.

## Decisions

- Context. The `t6gNDeps.NewWriter(w)` factory carries no run context, and several writer methods take none. Those methods gate on `context.Background()` (`runless()`). The executor's writer refuses on the attempt's own stop, fence and hold, not on the context it is handed, so the stopped-run refusal does not depend on it. Threading `rc.Context()` into `NewWriter` would re-sign the factory of five groups and every test that builds one; it was not done.
- Error-less methods. A write method with no error result cannot return a refusal. the builder logs the refusal (error for a write outside the declared effects, warning otherwise) and the method returns the zero value. Group 2 has none, so no helper for it exists yet; groups 3 and 6 do (`ActivityFlushOp`, `CleanupOrphanedTempFiles`, `CleanupStaleTempFiles`, `InvalidateAuthorsCache`) and add it with their builders.
- Empty-row methods stay unfenced (`Gate.Do` runs fn with no `Do`) and the caller owns the mode check; each group decides this when its builder lands. Group 2 has no empty-row method (`TestBooksT6G2Writer_CoversEveryMethodOfTheInterface`).
- O29, "embed or `Unwrap`": F5-18b settled it as no `Unwrap` (it is a bypass, and `TestNoMethodHandsBackTheInnerStore` pins it). The jobs `NewStore` wrapper follows that.
