# F2-12 seams and coined names

Names this task added that later rows may rely on (implementation plan §(n) rule 5).

## Rules later rows inherit

- R0 seeds a system user at first boot, so `POST /api/v1/auth/setup` answers 409 on a fresh store. The first
  admin (`admin`) comes from the bootstrap exchange; its password is then changed through
  `PUT /api/v1/auth/me/password` to the fixture password.
- The R0 binary must be the linux/amd64 release asset (`audiobook-organizer_Linux_x86_64`; the brief's
  `*linux*amd64*` pattern matches no asset name). The manifest's `r0_binary_sha256` is that file's hash; the
  recorder refuses any other binary.
- Families R0's API cannot write (F2-13): `oauthid:` (SSO only), `inviteallow:` (written only when an
  emailed invite is consumed), `aijob*` (OpenAI Batch API only), and runs in `running` or `stopping` at a
  clean stop (Registry.Shutdown cancels running ops with ErrShutdown). A `queued` run is written: a
  `library.scan` enqueued during the scan stand-down's re-queue grace (case `runs.standdown`).
- R0's library scan never takes the scan stand-down; a maintenance op does. The corpus' stand-down is
  `maintenance.metadata-refresh` quiescing a running `library.scan` (row `interrupted_quiesced`, setting
  `registry.scan_standdown` cleared to an empty value). Both of that case's scans target
  `/tmp/r2corpus/gotham-sewers` (64,000 empty directories, outside `stage1/`, never committed).
- Every boot of the corpus dispatches its queued `library.scan`, which also rescans the import root: books'
  `updated_at` and `last_scan_mtime` change at every boot. A replay waits for the boot-time runs to settle
  (no queued or running run in `GET /api/v3/ops/runs`) before it compares answers, and copies `stage1/`
  with fresh file mtimes, as a checkout has them.
- Fixture API keys get R0's maximum life (365 days) and invites ten years; the bootstrap exchange's key is
  revoked by the writer. Neither the writer nor the recorder runs between 01:00 and 06:00 UTC (the corpus'
  maintenance window is 02:00-05:00 UTC).
- The leak scan reads Pebble's plaintext (`scripts/r2corpus/pebble_bytes.py`: Snappy SST blocks and the
  reassembled WAL), and fails on a store file it cannot decode.
