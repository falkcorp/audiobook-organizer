# F2-12 seams and coined names

Names this task added that later rows may rely on (implementation plan §(n) rule 5).

| Name | Where | What it is |
|---|---|---|
| `manifest.json` format | `internal/books/testdata/r2corpus/manifest.json` | `{"_header", "r0_tag", "r0_binary_sha256", "written_at", "credentials", "boot", "stage1": [{"case", "family", "step", "how", "store"}], "not_writable_by_r0_api": [{"family", "step", "why"}], "overlay": [], "blockers": [], "stores": {"<store>": [{"path", "size", "sha256"}]}, "answers": [{"name", "file", "what"}]}`. `boot` is the writer's boot spec (work directory, cwd, argv with the binary elided, env, operator files). `not_writable_by_r0_api` lists the families the coverage table asks for that R0's API cannot write: F2-13's input. | stage-1 layout | `internal/books/testdata/r2corpus/stage1/` | Self-contained: `db/` is the store directory and R0's working directory (`audiobooks.pebble`, the gap-fill `config.yaml`, `library.bleve`, `logs/`, ...), `state/` is `ABK_STATE_DIR` (`.encryption_key`), `import/` the import root, `library/` `root_dir`, `playlists/` the playlist directory. Every absolute path R0 stored is under `/tmp/r2corpus/stage1/`; a replay copies `stage1/` to that path. `import/` and `library/` are siblings of `db/` because R0's sweeps never descend into the database's directory. |

## Rules later rows inherit

- R0 seeds a system user at first boot, so `POST /api/v1/auth/setup` answers 409 on a fresh store. The first
  admin (`admin`) comes from the bootstrap exchange; its password is then changed through
  `PUT /api/v1/auth/me/password` to the fixture password.
- The R0 binary must be the linux/amd64 release asset (`audiobook-organizer_Linux_x86_64`; the brief's
  `*linux*amd64*` pattern matches no asset name). The manifest's `r0_binary_sha256` is that file's hash; the
  recorder refuses any other binary.
- Families R0's API cannot write (F2-13): `oauthid:` (SSO only), `inviteallow:` (written only when an
  emailed invite is consumed), `aijob*` (OpenAI Batch API only), and runs in `running`, `stopping` or
  `queued` at a clean stop.
