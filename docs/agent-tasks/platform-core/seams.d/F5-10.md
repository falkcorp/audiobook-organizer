# F5-10 seams and coined names

What the dark conversion of maintenance file group 5 (14 definitions in `itunes_clone_into_library.go`, `itunes_playlist_import.go`, `itunes_regroup.go`, `library_state_repair.go`, `mark_missing_files.go`, `merge_same_path_dupes.go`, `metadata.go`, `metadata_cache_reap.go`, `missing_file_audit.go`, `missing_file_repair.go`, `missing_file_repoint.go`, `move_book_file_rows.go`, `narrator_purge_empty.go`, `narrator_split_joined.go`) added beyond 05-tasks and the F5-10 brief, the readings it took where they say nothing, and what F5-18 must do with them. Everything not listed follows the brief as written, and the layout copies F5-08's (`kinds_t6_g3.go`).

## Names beyond the spec

| Name | Where | What it is |
|---|---|---|
| `t6g5Kinds`, `t6g5KindList` | `kinds_t6_g5.go` | The group's list function (file order) and the package-level function that names it, so tasklint's registration-root rule counts the group. F5-18 replaces both with its `Registrar.Tasks` call and deletes `var _ = t6g5KindList`. |
| `t6g5Deps`, `t6g5Writer`, `t6g5Store` | `kinds_t6_g5.go` | The owner-declared dependencies (R10), composed of small embedded interfaces. `NewWriter` builds the writer per run over `rc.Writer()`; `ScanKey` is the library scan's stand-down key. |
| `headT6g5Writer`, `headT6g5Store` | `kinds_t6_g5.go` | The HEAD adapters over `p.deps`; each method calls what HEAD's body called, in the same order. |
| `t6g5Base`, `t6g5ItemsOpts`, `t6g5ItemsFunc`, `t6g5Pool` | `kinds_t6_g5.go` | The env part both shells fill the same way, and the engine-neutral loop (`registry.RunItems` at HEAD, `tasks.RunItems` native). A pool carries HEAD's worker count and the native `Parallelism` it maps to. |
| `t6g5Lease`, `t6g5LeaseFunc` | `kinds_t6_g5.go` | The scan stand-down a live run holds: HEAD's guard, native `rc.StandDown(deps.ScanKey)`. |

## Deviations from the brief

1. **Cores are plain package functions**, not `(p *Plugin)` methods, so R10 is structural. Shells (`(p *Plugin) runX`, `(p *Plugin) xKind`) stay methods, and the HEAD-signature wrappers existing tests call are kept.
2. **Extra files** beyond the brief's list: `kinds_t6_g5_atoms_test.go`, `export_t6g5_test.go` (the settings.manage scopes are copied because `internal/books` imports this package) and this note.
3. **Re-signed internal helpers.** Several helpers (the repoint planner, the move-book-file-rows helpers, the regroup snapshot and apply, `bookAuthorNamesForSplit`) now take a narrow reader or reporter instead of `*Plugin` or the wide store; the existing method forms wrap them unchanged.
4. **Duplicated helpers.** The batch-write, pre-write heartbeat and report-path helpers are re-declared as `t6g5` variants rather than editing the shared files, for a later unification.
5. **Clone `icStore` keeps its field names** (`OpsStore`, `ChapterReader`) because existing tests build it with a keyed literal; forwarding methods carry the rest.
6. **Clone mode.** A native preview clears apply/rollback/repair whatever params say; a live run must name exactly one, else it is refused.
7. **Regroup writer** includes `UserProgress() merge.UserProgressMerger`, the merge store HEAD's apply reaches through; narrowing it is a follow-up.
8. **Dropped schedule.** HEAD's metadata refresh declared `0 6 * * *`; the native kind takes `sched(kind)` and F5-18 decides.

## Readings taken

- **Resource names.** New names for F5-18's table: `metadata_cache`, `narrators`, `operations`, `book_narrators`, `user_playlists`, `chapters`, `user_preferences`, `external_ids`, `user_state` (those already declared by earlier groups are reused).
- **Stand-down.** A live run of a writing kind refuses without a configured scan key ("no scan stand-down key configured") rather than writing unguarded.
- **Concurrency.** Loops with HEAD `Concurrency: n` become `tasks.Fixed(n, reason)`, the missing-file stat sweeps and the clone repair keep their pools; zero stays sequential.

## What F5-18 must wire

- `t6g5Deps.Store`, `NewWriter` (including `InvalidateAuthorsCache` and `UserProgress`) and `ScanKey`.
- Delete `t6g5KindList` and its blank-identifier line.
