# R0-05 — seams and coined names

Early fix 5 (05-authn §11.1 item 5) in HEAD's code: the Basic gate refuses an empty effective password, with the
in-memory `BASIC_AUTH_PASSWORD` recovery, the health token and the startup log line.

## Exported (package `internal/server/middleware`, file `basicauth.go`)

| Name | Kind | Meaning |
|---|---|---|
| `BasicGateNoPasswordToken` | const `"basic_gate_no_password"` | the `/health` degraded token (05-health §5H.3.1) |
| `BasicGateNoPassword()` | `func() bool` | the gate is enabled and has no effective password: every non-exempt route answers 401 |
| `BasicGateUsesEnvPassword()` | `func() bool` | the gate is enabled, the saved password is empty and `BASIC_AUTH_PASSWORD` supplies it (the recovery) |
| `BasicGateEnvPasswordWarning` | const string | the warn line of the recovery; names `basic_auth_password` and `BASIC_AUTH_PASSWORD`, never the value |

## Unexported

| Name | Where | Meaning |
|---|---|---|
| `basicGatePassword(stored string) (pass string, fromEnv bool)` | `middleware/basicauth.go` | the effective password: the stored `basic_auth_password` when it is not blank (compared exactly as saved), else `strings.TrimSpace(os.Getenv("BASIC_AUTH_PASSWORD"))`; blank counts as unset on both sides; never written |
| `basicGate`, `currentBasicGate()` | `middleware/basicauth.go` | the gate's state for one decision (enabled, username, effective password, fromEnv), read from one `config.Snapshot()` so the gate, `/health` and the startup line never race `PUT /config`; methods `noPassword()`, `usesEnvPassword()` |
| `basicGateEnvWarnOnce` | `middleware/basicauth.go` | `sync.Once` for the gate's once-per-process warn line |
| `basicGateLog` | `middleware/basicauth.go` | `logger.New("http")`; the gate logs through the sanitizing logger, not `slog` (`TestGuard_NoDirectSlogCalls`) |
| `refuseBasicAuth(c)` | `middleware/basicauth.go` | every gate refusal: 401 with HEAD's `WWW-Authenticate` challenge |
| `healthTokenSource` | `server/server_lifecycle.go` | the adapter `startupDegradedSource` returns: startup runner tokens plus `basic_gate_no_password`, which `startupDegradedSource` reads once per probe |
| `logBasicGateAtStartup()` | `server/server_lifecycle.go` | the startup line, called right after `startupStepsFor` in `Start` |
| `basicGateNoPasswordStartupError` | `server/server_lifecycle.go` | the error-level startup line |

## For later rows

- **R1 (the split of the token source):** `healthTokenSource` is the one place the startup tokens and the gate token
  merge; split it there.
- **F3 (stage 8, `TestBasicGate_EmptyPasswordRefuses`):** core's stage 8 replaces `BasicAuth()`; this row's legacy
  test, the recovery and `BasicGateNoPassword` go with it, and `BASIC_AUTH_PASSWORD` becomes a retired name that
  refuses boot (05-config §1.3.6).
- **F8 (making `/health` Basic-exempt):** at this row only `/api/health` and `/api/v1/health` are exempt, so the
  operator reads `basic_gate_no_password` at `/api/v1/health`.
