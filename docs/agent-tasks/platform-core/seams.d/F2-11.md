# F2-11 seams and coined names

The minimal owner registrations of the three late-owner kinds (05-tasks 5T.8.2). Everything not listed here follows the brief and the spec as written.

## Names beyond the spec

| Name | What it is |
|---|---|
| `providerhttp.ReleaseHoldsTask(b InterimHolds)`, `ai.BatchPollTask(b InterimPoll)`, `diagnostics.ExportTask(b InterimExport)` | The constructors, named by the brief. F7 and F8 extend the same function with the native body. |
| `providerhttp.ReleaseHoldsKind`, `ai.BatchPollKind`, `diagnostics.ExportKind` | The kind names as `tasks.Kind` constants. |
| `providerhttp.ReleaseHoldsTimeout`, `ai.BatchPollTimeout`, `diagnostics.ExportTimeout` | The timeouts of the spec's table (1m, 10m, 30m). |
| `ai.BatchPollScheduleKey` | `"core.ai.schedules.batch_poll"`, declared by F2-04 in `core/kernel/core_sections.go`. |
| `providerhttp.ReleaseHoldsParams` (empty), `ai.BatchPollParams` (empty) | Params types. |
| `providerhttp.ReleaseHoldsResult{Listed, Released}` | Counts only. 05-metadata M2.4 says each listed hold is a line of the run's log, so no hold list is in the result. |
| `ai.BatchPollResult{Polled, ApplyStaged, Failed}` | The three counts of 05-ai section 4. |
| `diagnostics.ExportParams{ActorID, Sections}` | Plain data, because the run outlives the request and params are stored as JSON (`Viewer.Can` is a func and cannot travel). `ActorID` is the start-time `Viewer.ActorID`. `Sections` (empty = every section the viewer may read) is the one start option F2 declares: 05-health says "the start request's options" without listing them. F8 may add fields. |
| `diagnostics.ExportResult{File, Redactions}` | `File` is `<run-id>.zip`; `Redactions` maps the layer (`typed`, `pattern`, `permission`) to the manifest's count. |

## Readings

| Topic | Reading |
|---|---|
| nil backend | Each constructor leaves `Run` nil, so `tasks.Problems` reports "Task has no Run" and registration fails closed, instead of a method value on a nil interface that would panic at run time. |
| tasklint | Each constructor carries `//tasklint:constructor` and is on `TestTasklint_Core`'s allowlist (`core/archtest/tasklint/core_test.go`): the kernel, not this package, passes the definitions to `Registrar.Tasks` (F5-18). The F5 PR keeps the entries; the flips that delete an interface keep the constructor. |
| Schedule key protection | `core.ai.schedules.batch_poll` carries no `protect` tag in `core_sections.go` and 05-ai section 7 states none, so this row declares none. A disabled poll stops AI batch results from being applied; the owner may want `protect:"admin"` there. It is a one-line tag change in a file F2-11 may not touch. |

## Seams for later rows

- **F5-18:** set `InterimBackends.Holds`, `.Poll` and `.Export` and register the three definitions at P6 only when the field is non-nil. The books backends take `rc *tasks.RC` and the types above.
- **F7 (holds and poll), F8 (export):** extend the constructor's body, keep the kind, params and result types, and delete the interface in the same PR.
