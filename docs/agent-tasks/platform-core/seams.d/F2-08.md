# F2-08 seams and coined names

Names this task added that later rows may rely on (implementation plan §(n) rule 5).

| Name | Where | What it is |
|---|---|---|
| `rbac.NewCatalog(specs ...PermissionSpec) (*Catalog, error)` | `core/rbac/catalog.go` | Validating constructor F4-01's `Freeze` wraps. Returns every problem joined with `errors.Join`. |
| `rbac.CoreScopes() []PermissionSpec` | `core/rbac/catalog.go` | The fixed list of 19 `core:*` specs, a fresh slice per call. |
| `rbac.ErrForeignNamespace`, `rbac.ErrImpliesCycle` | `core/rbac/catalog.go` | Members of 05-rbac §3.4's error block declared here because `NewCatalog` returns them. F4-01 must not redeclare them. |
| `rbac.ErrUnknownScope` | `core/rbac/catalog.go` | Also §3.4's name. `NewCatalog` returns it for an `Implies` entry no spec declares. F4-01 must not redeclare it. |
| `rbac.ErrDuplicatePermission` | `core/rbac/catalog.go` | Coined. §4.9's "duplicate error" for two specs with one `Name`. |
| `rbac.ErrConfiningImplication` | `core/rbac/catalog.go` | Coined. A `Confining` scope that implies, or is implied by, another scope. |
| `kernel.declareCoreCatalog() (*rbac.Catalog, error)` | `core/kernel/catalog.go` | Builds the core catalog from `rbac.CoreScopes()`. F2-16 calls it once at boot, keeps the catalog and fails boot on the error. Takes no subsystem, so it cannot depend on one. |
| `TestKernel_DeclaresCoreScopesWithNoSubsystemWired` | `core/kernel/catalog_test.go` | The kernel half of 05-rbac §12's "no optional subsystem wired declares every `core:*` scope". F2-16 adds the boot-path assertion. |

## Rules later rows inherit

- `Catalog` is immutable after `NewCatalog`; `Lookup` and `All` hand out copies, `All` and `Namespace` iterate in name order.
- `Expand("<ns>:<action>.*")` includes the bare `<ns>:<action>` when declared (05-rbac §4.2). A concrete scope expands to itself only when declared.
- `httpapi.Router.Build` takes no catalog at this base, so it is unchanged; its `ErrUnknownScope` check lands with F4.
