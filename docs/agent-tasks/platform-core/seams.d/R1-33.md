# R1-33 seams and coined names

| Name | What it is |
|---|---|
| `shutdownBudgetEnv`, `shutdownBudgetFromEnv(lookup)` in `cmd/root.go` | The R1 reading of `ABO_CORE_SHUTDOWN_BUDGET`. Unset or empty gives 0 (core's default); a positive `time.ParseDuration` value is returned; anything else is an error naming the variable. F3 deletes both with `R1Values`. |

## Deviation

R1-15 is not merged at this base, so `app.R1Values` is not built in `cmd/root.go` yet. This PR ships the deploy files and the reading function with its tests. The wire (call `shutdownBudgetFromEnv(os.LookupEnv)` at the start of `serve`'s run function and set `ShutdownBudget` in the `R1Values` value) waits on R1-15.
