# R1-07 seams and coined names

Names the lifecycle/log move added that later rows may rely on (implementation plan §(n) rule 5).

## Packages

| Old path | New path | Notes |
|---|---|---|
| `internal/lifecycle` | `github.com/falkcorp/mediacore/lifecycle` (`core/lifecycle/`) | Package name stays `lifecycle`. |
| `internal/logging` | `github.com/falkcorp/mediacore/log` (`core/log/`) | Package name is now `log`. |

## Conventions

| Name | What it is |
|---|---|
| import alias `logging` | Every ABO file imports the core log package as `logging "github.com/falkcorp/mediacore/log"`. R1-18 and later log work keep the alias, so call sites read `logging.Info(...)` and nothing collides with the standard library `log`. |
| `logging.DefaultLogRetentionDays`, `logging.LogRetentionKeepForever`, `logging.ResolveLogRetentionDays(v int) int` | Moved from `internal/config/log_retention.go` to `core/log/retention.go`; behaviour unchanged. `normalizeLogRetentionDays`, `logRetentionZeroMigratedKey` and `migrateLogRetentionBlob` stay in `internal/config` (an ABO setting key must not enter core). |

## Gaps recorded

`TestGuard_NoDirectSlogCalls` (`internal/logger`) walks `internal/` and `cmd/` only, so the four direct `log/slog` calls in `core/log/structured.go` (ratchet key removed with the move) are no longer guarded. Whether the guard should also walk `core/` is a lead decision.
