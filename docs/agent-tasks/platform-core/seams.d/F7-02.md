# F7-02 seams and coined names

This file lists what the providerhttp and metadata-contract PR (05-metadata M2 and M3) added beyond the Go blocks of the spec: the readings it took where the spec or the brief is silent or contradicts itself, and the seams later rows build on. Everything not listed here follows the spec as written. The whole PR is dark: ABO's `internal/metadata/providerhttp`, `dailyquota`, `throttle*` and `circuitbreaker` are untouched, and `core.integrations.release-holds` is still registered over `InterimHolds` by ABO's wiring.

## Readings and decisions

- **Hand-written token bucket, no new dependency.** `bucket.go` is a reservation token bucket with `SetLimits` in place and a fake-clock-testable wait; `golang.org/x/time` and a direct `golang.org/x/sync` were not added to `core/go.mod` (no go.mod change). The chain's fan-out is a semaphore channel plus `sync.WaitGroup.Go`, not `errgroup`; the bound is the same (`Parallelism.Workers()`).
- **`Options.Base` is a `*http.Transport`**, not the spec's `http.RoundTripper`: it is cloned and its `Proxy`, `DialContext` and `DialTLSContext` are replaced, so the SSRF boundary cannot be left to the caller. A RoundTripper that dials for itself would have no guard.
- **Private reach comes from `Policy.Trust` only** (security review N10): `Policy.Private` is gone; the Registry derives a per-request test from `Trust.PrivateOrigins` (`scheme://host:port`, the scheme stripped, matched on the lower-case `host:port` with the scheme's default port filled in: the origin binding includes the port) and `lan_allow`, so no caller can supply a predicate of its own. `lan_allow` entries are a host (any port), a `host:port`, or a CIDR; a CIDR admits a literal-IP host only (the list is read before the dial, so it cannot judge the address a name resolves to).
- **Spec M2.3 over brief step 5**: no `Expect`, no Serialized range; the per-counter mutex is held across the store commit. `Owner` and `StorageSpec()` are exported for F7-09.
- **`HoldPolicy.Persist` is not consulted**: its zero value cannot mean "default true", so a hold is persisted whenever a store is attached (and with no store, `New` keeps them in memory).
- **Admission once per request.** Hold and breaker are checked once at the start; each retry attempt spends the bucket and the quota; the breaker and the hold learn the FINAL outcome once. A probe ticket never retries, and a request with no `GetBody` is not retried.
- **An attempt that sent nothing refunds its quota unit** (N1, widened from the dial guard to any attempt on which `httptrace` saw neither `GotConn` nor `WroteRequest`: a refused dial, an unreachable host). The spec's quota is "never refunded"; nothing reached the provider, and a data-derived URL to a private host would otherwise burn a provider's daily allowance. A request that was written and then failed still counts. An egress refusal also gives its bucket token back (N2) and, after an earlier attempt's 503, finishes the ticket with that attempt's outcome so the breaker and the hold still learn of it (N3).
- **Rebuilding a scope with new limits resizes in place**: the last `Client()` or `SetLimits` call wins for every client of the scope.
- **Redaction limit, and the way round it.** The raw `*http.Client` from `Client()` builds its own `*url.Error` from the URL the CALLER built, so a secret the caller put in that URL is in the error. `Do` and `GetJSON` redact. The supported way to keep a query credential out of every URL a caller holds (its request, `Response.Request`, the raw client's errors) is `OutboundSpec.QueryCredential` / `Policy.QueryCredential`: the transport adds the parameter to its own clone per attempt, never on a redirect hop to another endpoint, and removes the value from any error text. `integrations.HTTP.Client()` documents that a secret must never go into a URL a caller builds.
- **Chain, FirstHit.** `FirstHit` asks the providers one at a time in priority order and stops at the first with results: a speculative call to a lower-priority provider would spend a request (and a daily quota unit) on an answer that is then discarded. Fan-out (`Parallelism`) applies to `All` and `Stream`. Providers after the hit have no Outcome. `Parallelism` is still validated in `FirstHit`.
- **Chain, outcomes.** "Answered" for the error rule means Answered or Empty. A caller cancellation always wins over the provider's own error (Outcome `Canceled`, `ClassCanceled`) and the returned error carries `ctx.Err()` even if some provider answered, so a partial list is not mistaken for a complete one. A provider the cancellation stopped the chain before reaching is also reported `Canceled`. An instance that is not built as the chain's `Provider[Q, R]` is skipped silently when the instance list is the default (it belongs to another app's chain) and is a `Failed` outcome (`ClassUnsupported`) when the caller named it in `ChainOptions.Instances`.
- **Cache.** The entry JSON member for the cache's version is `ver`, because the codec envelope owns `v`. `Sweep` leaves a row that is not a cache entry alone (the module's keyspace may still hold legacy `pcache:` rows) and removes expired rows and rows of another `Version`. A write is made on `context.WithoutCancel`: an answer already obtained is stored even if the caller went away. A read-only caller and a writing caller do not share a flight. Results shared between concurrent identical questions are the same `R` values: treat them as read-only. `CacheOptions.Log` is added (one warning per provider on a failed write; M3.5 says "logged once per key family").
- **Log lines never carry a scope or a hold Detail as stored.** A `Policy.Scope` is caller-chosen (it can hold a host, a path or a credential's hash) and a persisted hold's `Detail` is another writer's text. The release-holds run logs the owning instance (`instance=<kind>/<id>`) when a `Client` or `GateFor` call named the scope, the Ref itself when the scope is the default form of a valid Ref, and otherwise `scope_digest=` (12 hex characters of a SHA-256: enough to tell two scopes apart in one log, not to recover either). `reason=` is the Detail after the same credential scrub as an error's text, cut to 120 bytes. `TestReleaseHolds_LogCarriesNoScopeOrDetailText` feeds a custom scope that is a URL with userinfo and a Detail echoing a credential and asserts neither reaches the captured log. The other log lines (`warnStore`, the cache's write warning) carry a constant message, a Ref and the store's own error, never a scope; a store error's text is the storage layer's.
- **Provider `Ref` vs the lease.** The chain reports outcomes under the Ref it leased, not the one `Provider.Ref()` returns.

## Security review of #4610 (credential leaks, SSRF boundary held)

- **M1, redirects.** A request that is a redirect hop to another endpoint than the one that redirected carries none of the instance's credentials: every header the scrubber's rules call secret (`X-Api-Key`, `X-Plex-Token`, anything in `Redact`) plus `Authorization`, `Cookie` and `Proxy-Authorization` is dropped in the transport, so a copied client with its own `CheckRedirect` is covered. A hop from https to http is refused (`ErrInsecureRedirect`, reason `egress`) in the transport too, except to an endpoint the instance's Trust (or `lan_allow`) admits for private reach and never for `EgressPublicOnly`. The package-level `CheckRedirect` is unchanged (the cover fetchers use it and have no credentials); the downgrade rule lives where the instance's trust is known.
- **M2, redaction rules.** `redact.go` matches names by rule, not list: a suffix of token, key, pwd, signature, cookie or auth; a prefix of sig; the substrings authoriz, credential, secret, password, passwd, session; exactly auth, pass, pwd, sig, sid; plus `Redact` / `OutboundSpec.Redact`. Case and `- _ .` are ignored. `auth` is deliberately never a prefix or substring (author, authors, authority survive in a book library). An Authorization value is taken whole (scheme and token), as is `Bearer <token>` anywhere and the userinfo of a URL in text. Single-quoted, double-quoted and unquoted values are handled. A URL that does not parse is never printed: only `scheme://host`, or a constant. Path segments shaped like `bot<digits>:<token>` are redacted. **Not covered:** a credential that is a free-form path segment (`/api/<key>/search`) cannot be recognised; an adapter whose provider does that must send the credential in a header or through `QueryCredential`. The scrub is one linear pass judging each name by at most 128 bytes (a longer name by its tail, with the suffix and substring rules only), and an excerpt is cut, scrubbed, cut again, so a 16 MiB body costs what a 1 KiB one does.
- **M3.** See "Redaction limit" above. The query credential is bound twice (second scan): to the instance's configured origins (`integrations.QueryCredential.Origins`, "scheme://host[:port]"; a request is given the parameter only when its own scheme, host and port are listed, under every egress policy; an empty list sends it nowhere), and to the request chain's first endpoint (below).
- **M1, chain, not hop.** Whether a hop "crossed" is decided against every request of its chain back to the first, not the hop before it: once a chain has left its origin it stays crossed, so A to B to B and A to B to A both reach their last hop with no credential header, no query credential and no private reach. `req.Response.Request` is walked; net/http sets `Request.Response` on every hop and the transport sets `Response.Request` to the request it was given.
- **N4, hold locks.** `hmu` guards the map only and is never held across a store call; a per-scope lock (`internal/keyedmutex`) serialises one scope's table-and-store writes (order: scope lock, then `hmu`). A stalled store write blocks that scope's writers and nobody else.
- **N5.** A boot read of holds and scope records that fails is logged and retried lazily, by one caller at a time and at most every 30 seconds, from every path that reads the table; a hold placed meanwhile is kept, and the recovery is logged.
- **N6, N7, N8, cache.** The flight key is a struct including the cache mode, the gate flags (`providerhttp.GateFlags`: interactive tier, hold bypass, counter) and the fingerprint. `CacheOptions.Fingerprint` (optional) is part of the row key: a reconfigured instance never reads answers its old configuration cached. Rows of an old fingerprint are not swept by `Sweep` (it drops expired rows and other Versions); they age out by TTL. Providing the fingerprint (a hash of the non-secret settings that change answers) is the module's job; nothing in F7-01's lease supplies it yet.
- **N9, retry rule (SPEC DEVIATION).** M2.4 retries every Retryable class. A request whose method is not idempotent (not GET, HEAD, OPTIONS, TRACE, PUT, DELETE, and no `Idempotency-Key`) is now resent only when nothing was written (`httptrace`: no `GotConn`, no `WroteRequest`), or when the server says it did not process it (429, or 503 with a Retry-After). `todo.d/` carries a fragment asking for an M2 amendment.
- **N11.** Blocked, in addition: 168.63.129.16/32, fec0::/10, 64:ff9b:1::/48, 2001::/32, 100::/64, `::/96` (all IPv4-compatible, a superset of `::127.0.0.1/128`) and `::ffff:0:0:0/96` (SIIT, not the IPv4-mapped `::ffff:0:0/96`). `fd00:ec2::254` and `100.100.100.200` sit inside ranges a trusted instance may reach and are excluded from the private bypass. `TestIsBlockedIP_Table` covers every one in both columns.
- **N12.** The refusal text says "the destination is not allowed" and names neither the host nor the address; `Dialer.Log` receives a Debug line with both. `Options.Log` now says it receives that Debug line.
- **N13.** The brief that reached this PR's author said only "note it in seams.d" and did not restate the finding; nothing was changed for it. Reviewer: please restate N13 and it will be recorded or fixed here.
- **NITs.** `InsecureSkipVerify` is forced false on both cloned TLS configs (`TestBaseTransport_CannotDisableVerification`); the bucket wait is clamped to 24 hours and never overflows, and a rate below one request a day is raised to that floor (`minRPS`); the blocked prefixes are parsed once per guard (`newGuard`), not per dial. They are NOT a package variable: `TestNoGlobals` (R5) forbids one, so `IsBlockedIP`, the exported check for callers with no Dialer, still parses per call.

## Not built

- The metrics of M2.8 other than three counters (`requests`, `refused`, `retries`): no `request_seconds` or `bucket_wait` histograms and no `hold_active`, `breaker_state` or quota gauges. M3.8's metadata series (`searches_total`, `provider_outcomes_total`, `cache_requests_total`, `singleflight_shared_total`, `provider_seconds`) are not built: `ChainOptions` and `CacheOptions` carry no metrics scope in the spec's Go block.
- `limits.tier` (a multiplier on the daily total) is not modelled: `integrations.Limits` has no field for it.
- `Lookup[R]` is declared and has no chain method (the spec gives none).
- F7-09's wiring (above), the audit action for a hold release, `lan_allow` CIDRs for hostnames, and every ABO adapter.
