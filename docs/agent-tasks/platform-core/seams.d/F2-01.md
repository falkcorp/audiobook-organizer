# F2-01 seams and coined names

This file lists what the `core/tasks` public API PR added beyond the Go blocks of 05-tasks §5T.3.1–§5T.3.13, the readings it took where the spec or the brief is silent, and the seams later rows build on. Everything not listed here follows the spec as written.

## Names beyond the spec

| Name | What it is |
|---|---|
| `tasks.NewRC(h runHost) *RC` | Builds a run context over an unexported `runHost` interface of exported methods (`Context`, `RunID`, `Kind`, `Mode`, `Trigger`, `Actor`, `Log`, `Writer`, `Resumed`, `Deadline`, `ShouldYield`, `Phase`, `Checkpoint`, `Restore`, `ReportProgress`, `Note`, `Touch`, `Enqueue`, `Await`, `StandDown`, `LockRefs`, `Lane`, `CapWorkers`, `AwaitUnpaused`, `AcquireCPU`, `RenewHold`, `ItemsProgress`). F2-03's executor implements it. The host also rides in the RC's context, so `ForEach` and `LockRefs` called with `rc.Context()` join the run. |
| `tasks.Problems(d Definition) []error` | The constructor problem list the kernel reads at registration (brief step 5). |
| `tasks.CommonOf(d)`, `tasks.ParallelismOf(d)` | Read accessors for the kernel and `taskstest`. |
| `Parallelism.Workers()`, `WorkersFor(params)`, `UsesCPUBudget()` | Resolve the declared worker count; `FromParam` resolves against run params. |
| `tasks.MaxFixed` (64) | Clamp for `Fixed` and `FromParam` (the v3 `MaxNetworkWorkers`). |
| `Effects.Declared/IsReadOnly/ReadSet/WriteSet/DeleteSet` | Accessors. `AlsoDeletes` also adds the ref to the write set. Builders copy, never mutate the receiver. |
| `Key.Module()` | The owner segment of an exclusive key. |
| `CancelContract.IsZero/IsUninterruptible/Grace/Budget/Reason`, `DefaultCancelGrace` (30s) | Accessors and the default grace. |
| `DefaultMaxPlanAge` (7 days), `MaxTimeout` (24h), `DefaultChunkSize` (256), `DefaultCheckpointEvery` (64) | Defaults and caps the spec states in prose. |
| `Debounce{Window, MaxWait}`, `DefaultDebounceWindow` (5s), `DefaultDebounceMaxWait` (60s) | The debounce declaration. |
| `Notify` (`NotifyAlert`, `NotifyActivity`) | Notification class. |
| `KindDial{ParallelismCap}` | The per-kind operator dial. F2-09 has a local `tasksKindDial`; it can switch to this type (no row owns the swap). |
| `Schedule.ConfigKey/Interval/RunsOnStart/Open/RunParams/IsLive/IsPreview/OnMissed` | Read accessors for the scheduler (F2-04). |
| `ModeRequest` (`ModeUnset`, `ModeRequestPreview`, `ModeRequestLive`) and `.Mode()` | The start request's mode, unset meaning "the kind's default". |
| `Trigger` consts `TriggerManual/Schedule/Window/OnStart/Outbox/Parent/Resume` | Trigger values. |
| `Actor{UserID, AuthMethod, System}`, `RunRef{ID, Existing}`, `Outcome{State, Result, Err}`, `StartOption` | Client surface records. |
| `Hold`, `Decision` (`DecideResume`, `DecideFinish`, `DecideDrop`), `ApproveRequest{Rows, Reject, Reason}`, `Risk` (`RiskLow/Medium/High`) | Approval and resume-decision records. |
| `Source.Dirty()`, `Row.Fingerprint()` | Dirty-set accessor; canonical row fingerprint (inputs sorted, `Hold` counted, `Retry` not). |
| `RunEvent`, `ItemOutcome`, `LogLine`, `PageKind` (`PageEvents/Intents/Items/Log`), `PageQuery{Page, After, Limit, Outcome}`, `PageEntry`, `Chunk{N, Keys, First, Last, Complete, Done, Failed, Skipped, Counters, At}`, `DebounceBucket{Kind, Bucket, Subjects, Params, First, Last}`, `Strike{Kind, Detail, At}` | Store records for F2-02. |
| `taskstest.FakeRun`, `NewFakeRun`, `ProgressEvent`, `ErrUnsupported`, the `Assert*` constants | The test kit. `FakeRun` implements `runHost` in memory; `Assert*` name each `Conformance` rule so a failure reads as the rule it breaks. |

## Readings

| Topic | Reading |
|---|---|
| Nil run context | `RunItems`/`RunSeq`/`ForEach` with a nil `*RC` return `*ItemsError` wrapping `ErrNoRunContext`; `LockRefs` on a context without a host returns `ErrNoRunContext`. |
| Options | More than one `ItemsOptions` value is refused. |
| `RunSeq` watermark | Needs a `Key`; the keyed watermark `{n, key}` verifies order on resume. |
| Watermark persist error | Stops the loop and is recorded in `Errs` with `FirstIndex` -1; the host decides fatality per `ResumePolicy`. |
| Resumed items | Counted in `Done`. |
| `FromParam` in `RunItems` | Without run params it resolves to its default. |
| Constructor problems | Include a scheduled writer with neither Live nor Preview, and one with both. |
| Left to the kernel (F2-16) | Module prefix of the kind, view-class scope, `Every` outside the relay, `PrioritySystem` on a module kind, undeclared exclusive keys and resources. |
| ABO citations | Doc comments cite HEAD's v2 registry and v3 ops files by file name only, so `grep 'internal/operations\|pkg/ops' core/tasks/` stays 0. |
| `ErrShutdown` | Re-exports `lifecycle.ErrShutdown` under `//archtest:allow-var`. |
| Interface width | `Client`, `Executor`, `RunStore` and `runHost` carry `//nolint:interfacebloat` with the reason: their method sets are the spec's. |

## Seams for later rows

- **F2-03 (executor):** the constructors do not store type-erased runners in the `Definition`. F2-03 must add unexported closures in `Task`, `Batch` and `Fixer` that run the typed spec, and build the `ItemRC` for the Batch runner. The executor-backed tests the brief lists (`TestRunItems_WatermarkResume`, `TestRunItems_CPUBudgetShared`, `TestRunItems_PauseParksBeforeItemClock`, `TestForEach_JoinsRunBudgetWhenCtxFromRC`, `TestExclusiveRefs_*`, `TestLockRefs_*`, `TestParallelismCap_LowersDeclared`) and `Conformance`'s runtime assertions (preview writes nothing, no write after the fence, crash and resume at least once) join there.
- **F2-02:** the store records above are the shapes `NativeStores` persists.
- **F2-09:** `tasksKindDial` can be replaced by `tasks.KindDial`.
- **Spec-block harness (`core/examples/hello/specblocks_test.go`):** once `core/tasks` exists the hello blocks wait on identifiers, not packages. The harness now compiles with `-gcflags=-e`, classifies each error line as a missing core identifier (three patterns: `undefined: pkg.X`, unknown struct-literal field, missing method/field on a core type) or a real error, and pins the exact missing set. The rows that add `config.Handle`, `ui.Bundle`, `module.Manifest.{Permissions,Settings,TaskLedger}`, `module.Registrar.{Resources,Tasks}` and `module.Setting/Settings/SettingsSection` must shrink that pin in their own PR; when it is empty the blocks compile and boot.
