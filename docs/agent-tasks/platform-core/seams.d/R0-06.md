# R0-06 — names and seams coined by the updater hotfix

Later rows (R1-24, R1-25, F8-02, F8-04) read this instead of the PR description.

## `internal/updater` (Go API)

| Name | What it is |
|---|---|
| `RestartExitCode` (= 75) | the exit status `RestartSelf` uses |
| `LocalBuildNote` (= `"local build, not compared"`) | `UpdateInfo.Note` on a local build |
| `IsLocalBuild(version) bool` | the describe-suffix rule: `-[0-9]+-g[0-9a-f]+(-dirty)?$` or a `-dirty` suffix |
| `UpdateInfo.LocalBuild` / `AutoApplyPaused` / `Note` | JSON `local_build`, `auto_apply_paused`, `note` (named by the brief) |
| `(*Updater).CheckUnattended(channel)` | the check both unattended paths (`Scheduler.tick`, maintenance-window step 1) run; records the status with `AutoApplyPaused` set and logs a newer release at info ("update available; apply it from Settings") |
| `(*Updater).PrepareApply(version)` | resolves a manual apply's target and returns a refusal before any network call; `""` means the release the last check offered |
| `(*Updater).DownloadAndReplace(info)` | unchanged name; re-applies the rule to the tag it downloads, fetches the asset from `releases/tags/<tag>` (never `releases/latest`), swaps through `.prev` |
| `ErrNoUpdate`, `ErrLocalBuildNeedsVersion`, `ErrNotNewer`, `ErrUnversioned`, `ErrInvalidVersion`, `ErrReleaseNotFound` | the refusals |
| `Option`, `WithAPIBaseForTest`, `WithHTTPClientForTest`, `WithExecutableForTest`, `WithExitForTest` | `NewUpdater(version, opts...)` options; the test seams a package outside `internal/updater` can use (the R0 fake-server tests and `TestMaintenanceWindowStep1_CheckOnly` use them) |
| unexported `rename` field | the swap's rename, injectable by the package's own tests (second-rename failure) |

`ErrUnversioned` ("running build has no release version: updates are not compared") is the refusal of a
named apply on `dev` or an unparsable version; 05-updater §5U.4 step 1 requires a versioned build.

## HTTP (`internal/server/update_handlers.go`)

`POST /api/v1/update/apply` takes an optional body `{"version": "<tag>"}` (at most 4 KiB). Status per refusal:

| Refusal | Status | Message |
|---|---|---|
| nothing offered and no version (HEAD's) | 400 | `no update available` |
| version not a semantic version tag | 400 | `version is not a release tag` |
| local build, no version | 409 | `local build: name the version to apply` |
| target not newer than a non-local running version | 409 | `release is not newer than the running version` |
| running build unversioned, version named | 409 | `running build has no release version: updates are not compared` |
| named tag has no release | 404 | `release not found: <tag>` |

`GET /api/v1/update/status` and `POST /api/v1/update/check` report `auto_apply_paused` from the live
`auto_update.enabled`, not from the recorded check.
