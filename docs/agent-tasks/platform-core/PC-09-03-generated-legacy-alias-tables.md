## Steps (mechanical; no judgement calls)

1. `tools/cmd/genaliases/main.go` parses, with `go/parser` and `go/ast` only (no `reflect` on a built binary):
   - the three files' `viper.BindEnv(key, NAME...)` calls → map key → []NAME;
   - `Config`'s struct fields (recursively for nested structs only at the top level: a nested sub-key moves with its
     parent, 05-config §1.12.3) → for each top-level field: `mapstructure`/`yaml` tag = **LegacyYAML**, `json` tag =
     **LegacyBlob** (empty when the json tag is `-`);
   - HEAD's typed getter for each key in `config.go` (`viper.GetBool("k")` etc.) → **Decode**: `GetBool` →
     `DecodeBool`; `GetInt`, `GetInt64` → `DecodeInt`; `GetFloat64` → `DecodeFloat`; `GetDuration` → `DecodeDuration`;
     `GetStringSlice` → `DecodeStringSlice`; `GetString` → `DecodeString`; no getter → `DecodeCanonical`;
   - the keys of `envLockedSettings`, `absEnvOnlySettings`, `configFileLockedSettings`, and the keys assigned inside
     `applyEnvAuthoritativeConfig` and `SyncConfigFromEnv` (the `c.<Field>` / `AppConfig.<Field>` assignments) → the
     **not-BelowStored** set.
2. **LegacyEnv** for a key = its `BindEnv` names, plus `strings.ToUpper(key)` (prefix-less `AutomaticEnv`), deduplicated,
   sorted. Never add a name ABO does not read (the unread list of 05-config §1.12.4: `AUDIOBOOK_ROOT_DIR`, `AO_DIR`,
   `AO_DB`, `OLLAMA_BASE_URL`; and `HOME`, `GOMEMLIMIT`, `GOGC`, `TZ`, `NOTIFY_SOCKET`).
3. **Canonical** = the key map's path for the key. **Ledger** = the row ID the key map gives, or, if it gives none,
   `config.<legacy_yaml_key>` for the file key row and `env.<NAME>` for each env name row (one ledger row per
   surface; this naming is the rule of 09 §9.2.9's examples at your base — check `grep -n 'env\.' docs/compat-surfaces.md`
   and use the existing prefix if one exists).
4. **BelowStored** = true iff LegacyBlob != "" and the key is not in the not-BelowStored set (05-config §1.12.4
   "Precedence"). Always false for a FileOnly key (`LegacyYAML != "" && LegacyBlob == ""`) and for a
   `ProtectOperator` key. `ENABLE_AUTH`/`enable_auth` are BelowStored (no exemption). Check: `DATABASE_PATH` false
   (env-authoritative), `FP_PARALLEL_WORKERS` true, `OPENAI_BASE_URL` true.
5. **HEADAuthOffWritable** = true exactly for `enable_auth`, `basic_auth_enabled`, `basic_auth_username`,
   `basic_auth_password`, and the integration-bound blob fields the key map lists (05-config §1.3.1, §1.12.3).
6. **Gate** per env name: permanent iff in 05-config §1.12.4's permanent list — `OTEL_EXPORTER_OTLP_ENDPOINT`,
   `OTEL_EXPORTER_OTLP_METRICS_ENDPOINT`, `OTEL_METRIC_EXPORT_INTERVAL`, `OTEL_EXPORTER_OTLP_METRICS_INSECURE`,
   `OPENAI_API_KEY`, `OPENAI_BASE_URL`, `DATABASE_PATH`, `FP_PARALLEL_WORKERS`, `BASIC_AUTH_ENABLED`,
   `BASIC_AUTH_USERNAME`, `BASIC_AUTH_PASSWORD`, `WHISPER_REMOTE_URL`, `ALLOWED_PEER_CIDRS`, `TUNNEL_CONNECTOR_ADDRS`,
   `LOGIN_SATURATED_RATE`, `LOGIN_SATURATED_BURST` (16 names); every other name is window. The four `OTEL_*` rows
   are core's fragment, not ABO's ledger (05-config §1.3.6 "Where the rows come from"): the generator emits them into
   the alias table but writes no ABO ledger row for them. Also add the two `ABK_*` operational names
   (`ABK_STATE_DIR`, `ABK_ALLOW_ENCRYPTION_KEY_REGEN`) as window rows with the canonical paths the key map gives
   (`core.paths.state_dir`, `core.secrets.allow_key_regen`).
7. **Convert/Revert** are not generated: the generator emits `Convert: nil, Revert: nil` except where the key map names
   a converter, which it references by Go identifier (e.g. the OTel bare-integer milliseconds rule, 05-metrics §10;
   `log_retention_days` 0 means default, 05-logging). A converter the key map names but the tree lacks = STOP.
8. Emit `internal/config/aliases_gen.go`: `var legacyAliases = []config.Alias{...}` sorted by Canonical, plus
   `func LegacyAliases() []config.Alias` and `func LegacyEnvPermanent() []string` (both names coined here; PC-09-07's
   test reads the second). `go generate` directive in `internal/config/doc.go` or the existing generate file:
   `//go:generate go run ../../tools/cmd/genaliases -out aliases_gen.go`.
9. Ledger rows: append the config and env rows to `docs/compat-surfaces.md` in the section and column format PC-07-06
   created (copy an existing row's shape exactly), then regenerate the embedded copy with the target PC-07-06 added
   (`make compat-ledger`; check `grep -n '^compat-ledger:' Makefile`).
10. `internal/config/aliases_gen_test.go`: `TestEveryLegacyConfigKeyHasCanonical` (every top-level `Config` field has
    exactly one alias with a non-empty Canonical; every `BindEnv` name and every upper-cased flat key appears in some
    alias's LegacyEnv); `TestAliasesGenFresh` (name coined here: running the generator into a temp file yields
    byte-identical output). `TestCompatLedgerMatchesCode` (PC-07-06's) must pass with the new config and env rows.
11. `tools/cmd/genaliases/main_test.go`: table tests on a small fixture source file (one BindEnv, one AutomaticEnv-only
    key, one `json:"-"` key, one env-locked key) asserting each flag.
12. Headers (the generated file keeps a header; bump on regeneration), `changelog.d/` fragment.

## Code contract (05-config §1.3.1, copied exactly; defined in `core/config`, not here)

```go
type Alias struct {
	LegacyYAML, LegacyBlob string
	LegacyEnv  []string
	Canonical  Path
	Convert    func(json.RawMessage) (json.RawMessage, error)
	Revert     func(json.RawMessage) (json.RawMessage, error)
	HEADAuthOffWritable bool
	Ledger     string
	BelowStored bool
	Decode     LegacyDecode
}
const ( DecodeCanonical LegacyDecode = iota; DecodeBool; DecodeInt; DecodeFloat; DecodeDuration; DecodeStringSlice; DecodeString )
```
