## Code contract (07 §7.5.2; copy the signatures exactly)

```ts
export type StaleReason = 'header-mismatch' | 'legacy-spa' | 'pre-s0-server';
export function readPageBuildId(): string;
export function checkBuild(response: Response, opts: { buildId: string; shell: boolean }): StaleReason | null;
export function onStaleBuild(listener: (reason: StaleReason) => void): () => void;
export function getStaleReasons(): readonly StaleReason[];
export function createCoreClient(opts: { buildId: string; shell: boolean }): Client;
```

`checkModules` and `createModuleClient` are S9; do not export them yet. Rules (07 §7.5.2, §7.8):

- `checkBuild` is synchronous, reads headers only, decides cases 1 and 3 of §7.5.2 exactly as written there,
  records the reason, notifies `onStaleBuild` listeners, and is never deleted. `buildId` is a runtime argument,
  never a define baked into the library build.
- `readPageBuildId()` is the only reader of `<meta name="mediacore-build">`; `""` when absent.
- `createCoreClient`'s middleware keeps `apiFetch`'s deadline (`ApiTimeoutError`), SSO bounce detection
  (`ApiAuthRedirectError`), `credentials: 'include'`, `X-Request-ID` surfacing and RFC 9457 `Problem` errors.
- Generation: types by `openapi-typescript` **7.13.0**, calls by `openapi-fetch` **0.17.0** (exact versions),
  read from `core/openapi/core.json`; each operation whose `x-mediacore-permission` is `public` is marked
  `skipAuthRedirect`. No fallback generator.
- ESLint in `core/web`: `no-restricted-imports` plus `import/no-relative-packages` reject any specifier that
  resolves outside `core/web` (no `../../web/...`, no `@abo/*`).
