## Steps

0. **Precondition.** `core/rbac/requirement.go` and `core/auth/principal.go` (PC-04-01) must be at your base:
   `httpapi.Route.Perm` is an `rbac.Requirement` and `Registrar.AuthMethod` takes an `auth.MethodSpec`. If they are
   absent, **STOP and report** "PC-04-02 needs PC-04-01's leaf types merged first".
1. **`core/ui/segments.go`** — `ReservedSegments() []string` returns a fresh slice of the shell segments of 07
   §7.4.3; `ModuleManifest`, `UIIDs`, `Redirect` as plain types (07, 06 §6.4.10 last paragraph). Imports nothing.
2. **`core/module`** — exactly the S2 members of 06 §6.4.10's S2 row with the signatures of 06 §6.4.1–§6.4.4:
   `Manifest{ID, Version, DisplayName, MinCoreVersion, DefaultEnabled, Settings, UI, LegacyPrefixes, PublicRoutes}`;
   `Registrar` methods `Context`, `Deps`, `HTTP`, `MountLegacy`, `AuthMethod` (records the `auth.MethodSpec`
   only), `LogPathRules`, `LogOtherUserData` (records), `Hook`, `Worker`, `Err`; `Deps{Module, Log, Metrics,
   ExtendStart}` with `ExtendStart func(step string)`. `ReservedIDs()` = `httpapi.ReservedSegments()` ∪
   `ui.ReservedSegments()` ∪ `{"core", "custom"}` (`rbac.ReservedNamespaces` lands at S4, so keep the two
   names as an unexported list with a comment pointing at 05-rbac). A member listed for a later stage is
   absent, not stubbed (06 §6.4.10). `Settings`'s type comes from core `config` (PC-04-05): if `core/config` is
   not at your base, leave `Settings` out and record it in the PR description; PC-04-05 adds it.
3. **`core/httpapi/router.go`, `problem.go`** — 05-http-api §3.1/§3.3/§3.5 restricted to §3 "Minimum surface per
   stage": `Deps` has only `Log` and `Metrics`; `Build` refuses a native route that is not `Public` or infra with
   `ErrNoAuthService`; `Handle` refuses `rbac.LegacyAtom`/`LegacyCheck`; `Public` native routes must be in their
   module's `Manifest.PublicRoutes` (`ErrPublicNotAllowed`). If PC-04-01's `legacy.go` is at your base and has not
   added `(*Router).MountLegacy`, add it here calling PC-04-01's `registerLegacy` (05-http-api §3.5); if PC-04-01 is
   not at your base, leave `MountLegacy` to PC-04-01. Do not redefine `Guards`, `RateClass` or any legacy type
   (PC-04-01 owns them). No perimeter stage is implemented here (PC-04-03, PC-05-01): `Build` returns the mux with
   the router's own 404/405 problem handling only.
4. **`core/internal/jsonschemax`, `core/internal/openapi`** — `httpapi` → `internal/openapi`, never the reverse;
   `internal/openapi` defines its own operation-description type that `Router.OpenAPI` fills (05-http-api §3).
5. **`core/kernel`** — the S2 boot of 06 §6.5.1 with no storage: P1 (`Manifest()` of every module; module IDs
   against `module.ReservedIDs()`, `Options.ReservedAPINamespaces` and the first segment of every
   `LegacyPrefixes`; `TestReservedIDsIncludeLegacyTopSegments`), P5 (services), P6 (`Register` once per enabled
   module, `Registrar` closed afterwards), P7 (re-check module IDs against every recorded mount's `TopSegments`),
   P8 (root handler from `Router.Build`). Run and stop order exactly as 06 §6.5.2 lists the steps that exist at S2
   (core background services → hooks → workers → listeners → readiness; stop: readiness false → listeners
   `Shutdown` → workers → hooks in reverse → done). Budget slicing of 05-health §5H.4: total 25 s, 8 s when
   `sysinfo.Info.Container` is set and nothing sets the key; HTTP drain `min(10 s, remaining)`; work past the cap is
   abandoned with an ERROR naming it. `Lifecycle.RequestRestart(reason)` runs the stop order and exits with
   `core.lifecycle.restart_exit_code` (default 75). The kernel never imports `internal/startup`-like app code; its
   supervisor step list is its own fixed core list (09 S2 Moves). Keys are read from config once PC-04-05 lands
   it; until then the kernel uses the spec defaults (comment the hand-off). Listener start is a hook point that
   PC-04-07 fills with PC-04-03's listeners; readiness signalling (sdnotify) is PC-04-07's.
6. **`core/app`** — 06 §6.4.5 S2 members: `New`, `Run`, `Handler`, `Modules`, `ExtendStart(step string)`
   (stateless: reads `NOTIFY_SOCKET` per call, never a timer, no package state, failure logged and never
   returned, 05-health §5H.3.4; until `core/internal/sdnotify` exists (PC-04-07) implement the datagram write in an
   unexported helper inside `core/app` and leave a comment that PC-04-07 replaces it with the moved package),
   `Describe` (`Core`, `OpenAPI`). `Options` per the contract below. `app` never calls `slog.SetDefault` or any
   `otel.Set*` (05-logging L3; `InstallProcessDefaults` is PC-06-01's).
7. **`core/examples/hello`** — 06 §6.4.10 "S2 skeleton": module, app, `GET /api/hello/v1/greeting` (name
   `getGreeting`, `Perm: rbac.Public`, declared in `Manifest.PublicRoutes`), no storage, no task. Its
   `cmd/hello` `openapi` subcommand writes `core/openapi/core.json` (05-http-api §7). Commit the output.
8. **`core/coretest/boot.go`** — boots core with zero modules (G7) and with `WithModules(hello.New())`.
9. **Freshness gate** — `make -C core openapi-check` regenerates `core.json` into a temp file and fails on any
   diff; add it to `make -C core ci` and to `core-ci.yml`.
10. **`core/legacy/doc.go`** — package comment from 06 §6.4.11 (L5; imported only by `module`, `kernel` and apps;
    excluded from the API-stability gate) plus the mirror-test rule verbatim from 06 §6.4.11 "Mirror test", so
    every later owner follows one template. No identifiers.

## Code contract

```go
// core/app (06 §6.4.5; S2 fields only, from 06 §6.4.10's S2 row)
type Options struct {
	AppID, MetricPrefix, MetricNamespace, ServiceName string
	MetricViews          map[string][]float64
	ServedMeterProvider  metric.MeterProvider     // S2 r1–r2 only; deleted in the S2 r3 PR (PC-06-02)
	HTTPMetricsScope     httpapi.InstrumentScope
	ReservedAPINamespaces []string
	DisplayName, Version, EnvPrefix, StateDir, ConfigFile string
	Args, Env            []string
	PromRegisterer       *metrics.Shared          // only if metrics.Shared exists at your base; nil until S2 r3
	LegacyAuthGinUntil   module.ID
	Logger               *slog.Logger
	// LegacyConfig *config.Legacy and LegacyConfigStore config.OverrideStore arrive with core/config (PC-04-05).
}
func New(ctx context.Context, opts Options, mods ...module.Module) (*App, error)
func (a *App) Run(ctx context.Context) error
func (a *App) Handler() http.Handler
func (a *App) Modules() []ModuleState
func ExtendStart(step string)
func Describe(ctx context.Context, opts Options, mods ...module.Module) (Description, error)

// core/module (06 §6.4.1)
type ID string
func (id ID) Valid() bool
func ReservedIDs() []string
type Module interface { Manifest() Manifest; Register(r *Registrar) error }
```

## Invariants and STOP conditions

- No ABO import anywhere under `core/` (`TestCoreImportsOnlyCore`); `kernel` is never imported by `app`'s callers
  (`archtest.NoKernelImports`); `examples/hello` imports no `legacy`.
- No package-level mutable state in core (03 R5); `app.ExtendStart` reads the socket per call.
- Core never calls `slog.SetDefault`, `log.SetOutput` or `otel.Set*` (05-logging L3).
- If a spec signature cannot compile because the type it names lands in a later PR of this wave, leave the member
  out and say so in the PR description; never add a placeholder type. If it lands in a later **stage**, STOP: that
  is a spec gap to report.
