## Steps
1. **gofmt.** `gofmt -w internal/database/ops_v2_recent_test.go`. Confirm `gofmt -l . | grep -v '^web/'` prints nothing and `make fmt-check` passes. Change nothing else in that file.
2. **slog guard: fix the code, never the ratchet.** The guard's own message says "Do NOT add to slogRatchet or raise a count". `logger.New("<subsystem>")` (see `internal/logger/standard.go:25`) returns a `*StandardLogger` whose `Info/Warn/Error(msg string, args ...any)` are **printf-style** (`fmt.Sprintf(msg, args...)`, then `sanitizeLogLine`), not key/value like `slog`. So a call such as `slog.Warn("owner action refused", "route", r, "http_method", m)` becomes `ownerGuardLog.Warn("owner action refused: route=%s http_method=%s", r, m)`. Per file:
   - declare one package-level `var <name>Log = logger.New("<subsystem>")` (precedent: `internal/server/middleware/recovery_redact.go:19`, `var recoveryLog = logger.New("http")`); pick a subsystem that matches the file's existing log prefix;
   - convert every direct `slog.*` call in the nine files listed above, except in the two files already on the ratchet (`internal/config/update_service.go`, `internal/server/handlers/metadata_cache.go`), where you convert only the surplus: find the newest calls with `git blame -L` and convert those until the count equals the allowance (config: 2 calls, metadata_cache: 1 call). Do not touch the remaining calls;
   - values that were passed through `logger.SanitizeLogValue(...)` (e.g. `candidate_feedback.go:109,125`) keep that wrapper as an argument; the formatted line is sanitized again, which is harmless;
   - keep the message text a stable prefix; do not change log levels;
   - an `%` inside a message must be `%%`, and every verb must have an argument (`go vet` checks printf-style wrappers only if the method is recognised; run `go vet` on each package anyway).
   Then `SLOG_GUARD_PRINT=1 go test ./internal/logger -run TestGuard_NoDirectSlogCalls -v` prints the current map and `files=N calls=M`.
3. **One-way slog ratchet.** In `internal/logger/slog_guard_test.go` replace the `t.Errorf` in the "Ratchet: entries must track reality downward" block (the `t.Errorf` after `stale = append(...)`, about line 162) with `t.Logf` carrying the same text prefixed `NOTE (not a failure): `.
