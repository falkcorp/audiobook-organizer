## Goal
`Book.FilePath` is stale for many books; the truth is the `book_file` rows. Callers that only want "a path for this book" need one tested helper that reads `book_file`, never `Book.FilePath`. Add it; do not migrate any caller in this PR.

## Verified at HEAD (`93a9b745f`)
- `internal/plugins/maintenance/intro_transcribe.go:1401` `nthAudioFile(store bookFileLister, book database.Book, n int)` is prior art: it sorts by (disc, track, path), filters by extension, and **falls back to `Book.FilePath`** when no rows exist. The new helper must not copy that fallback; that fallback is the bug class.
- `GetBookFilesForIDsCore` is already a method of `database.Store` (`internal/database/iface_bookfile.go:31`; implementation `memdb_reads.go:1208`) and returns `map[string][]BookFileCore` for many ids at once; `BookFileCore.FilePath` is at `internal/database/bookfilecore.go:41`. `BookFile` has a `Missing bool`.
- `Book.FilePath` core field: `internal/database/bookcore.go:33`.

## Design (decided)
A free function, not a Store method (the Store is at its width ceiling; G1 would fail a new method):
```go
// package database
type FileLister interface {
    GetBookFiles(bookID string) ([]BookFile, error)
}
// FirstAudioFile returns the first present audio file of the book by (disc, track, path).
// ok=false means "no usable file row", never an error and never a fallback to Book.FilePath.
func FirstAudioFile(store FileLister, bookID string) (f BookFile, ok bool, err error)
// FirstAudioFiles is the batch form for list pages; one store call for N books.
func FirstAudioFiles(store BookFilesBatcher, bookIDs []string) (map[string]BookFileCore, error)
```
Rules: skip rows with `Missing == true` and rows with an empty path; audio means the extension is in the repo's shared audio-extension set (look for `internal/audioext`; reuse it, do not add a third list); ordering identical to `GetBookFiles` (disc, track, path). `BookFilesBatcher` is a one-method interface on `GetBookFilesForIDsCore`; the method is on `database.Store` itself, so no capability lookup is needed. The extension test is `audioext.DefaultSet().MatchPath(path)` (`internal/audioext/audioext.go:120,149`); take an `audioext.Set` parameter (callers pass `audioext.Resolve(configured)`, line 136) so the helper stays configurable.
