# 02-PR19: Retire the full-index Review mode: delete the index path, return 410 for view=index for one release, delete the flag

## Goal
After `review_metadata_server_query` has been on for a release, the browser-side full-index code is dead weight and a memory trap. This PR deletes the index path from the lane, makes `view=index` answer `410 Gone` for one release (then it is removed in wave 4), and deletes the flag.

## Context the agent must read first
- `web/src/components/review/lanes/useMetadataLane.ts`: the index load (`getCachedReviewResults(0, 0, true, 'reviewable', { view: 'index' })`, ~line 973), the unreviewable full load (~1156), the `useMemo` chain (~1196-1372), and the flag read added by 02-PR18.
- `internal/server/handlers/metadata_cache.go`: `indexView := c.Query("view") == "index"` (~512), `reviewViewLabel`, the `if indexView { cand.Description = "" ... }` branch (~773), the metric `metrics.ObserveReviewIndexRequest`.
- `internal/config/config.go` and `persistence.go`: `review_metadata_server_query` from 02-PR18.
- `web/src/services/api.ts`: `getCachedReviewResults` and its `view` option; callers elsewhere (`grep -rn 'getCachedReviewResults' web/src`).
- The owner's confirmation that the flag has been on in production for one full release (ask; do not assume).

## Steps
1. Create the worktree. Verify the preconditions with the owner's statement and with `git log --oneline -- web/src/components/review/lanes/useMetadataLane.ts` showing 02-PR18 at least one release tag ago (`git tag --contains <sha>`); if not, stop.
2. Delete the index path from the lane and everything only it used (state, effects, helpers). Make page mode the only mode: remove the flag read, so `getConfig()` is no longer needed by this hook if it was only for the flag.
3. Server: replace the `indexView` handling with an early `c.AbortWithStatusJSON(http.StatusGone, ...)` for `view=index`; record it in `ObserveReviewIndexRequest` under a `gone` label so any remaining client shows up in the metric. Leave `view=page` and the default listing untouched.
4. Config: delete the field and its registrations. Add a test that loading a config containing `review_metadata_server_query` does not error (unknown stored keys are ignored; verify how `persistence.go` treats an unknown key before relying on that).
5. Search the whole repo (including `docs/`, `scripts/`, `e2e/` or Playwright specs) for `view=index` and `review_metadata_server_query`; update each user. List them in the PR description.
6. Count lines removed: `git diff --stat origin/main...HEAD`.
