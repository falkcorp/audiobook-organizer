## Goal
`GET .../metadata-cache?view=index` returns every reviewable row with its full first candidate, including the score breakdown, which only the evidence panel reads and which the lane already re-fetches per visible page. After this PR the index rows carry no breakdown, cutting the response from about 103 MB to about 47 MB at 40k rows (measured on synthetic rows in appendix D), with no behaviour change.
