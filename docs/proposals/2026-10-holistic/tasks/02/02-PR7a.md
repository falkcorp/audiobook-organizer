## Goal
Before building the local-catalog matching stage, measure how much it can possibly move: for every primary book that is `ident:unasked` or `ident:asked_empty`, how many have at least one credited author with a harvested catalog block, how many have none, and which 50 unharvested credits cover the most books. The op writes nothing.

See `internal/operations/registry/run_items.go` and `internal/plugins/acoustid/backfill.go` (`backfillWorkers()`).

## Steps
1. Create the worktree. Confirm 02-PR4 is merged (`grep -n 'func (p \*PebbleStore) IdentBookIDs' internal/database/ident_state.go`).
2. DEVIATION FROM THE SPEC'S FILE LIST, to state in the PR description: the spec names `internal/plugins/catalog/coverage_report.go`. No `internal/plugins/catalog` package exists; the catalog ops live in `internal/server`, and a new plugin package would also need a blank import in `internal/plugins/plugins.go` or the op would silently not exist in the binary. Register beside `catalog.harvest-authors` instead.
3. Define the `OperationDef`: id `catalog.coverage-report`, `Plugin: "catalog"`, `Liveness: opsregistry.LivenessRunItems`, no `Writes`, `Permissions: []auth.Permission{auth.PermSettingsManage}` (the charter's D1 rule: never leave permissions undeclared), `Capabilities: CapLibraryRead`, `DefaultPriority: PriorityLow`, `ResumePolicy: ResumeRestart`, a `ConcurrencyKey` of `catalog.coverage-report`, a generous `Timeout`. It does not require `catalog.enabled`, but if the catalog has zero `cat_author:name:` keys it reports that plainly instead of zeros.
4. Selection: `ids := IdentBookIDs(unasked, asked_empty)` intersected with primary, non-quarantined books (use the same effective-primary helper the Library uses; a nil flag is NOT primary). If the ident index reports not-ready, fail with a clear message rather than guessing.
5. Per book: load it, `LiveBookAuthorNames`, fold each credit with `authorjunk.FoldKey(credit)` and call `HasAuthorKey(fold)` for each. Do NOT use `catalog.AuthorNameKey`: it returns `name:<fold>` and the store prepends `name:` again, so every book would read uncovered. `HasAuthorKey` builds the prefix `catAuthorPrefix+"name:"+fold+":"`. Add a test that stores a real catalog entry through the store and expects a hit for its author. A book counts as covered if ANY credit has a block. Run the loop through `registry.RunItems` with `Concurrency: runtime.NumCPU()` set explicitly, `Label` reading only the item (no shared counters), aggregates under one mutex (counts and a `map[credit]int` of unharvested credit book counts).
6. Unharvested-credit table: keep counts for every unharvested credit during the run, then output the top 50 by book count (ties by name). Names appear ONLY in the op's log output (`reporter.Log` with a single JSON line) and never in any file in the repo; the test fixture uses synthetic names.
7. Result: log one JSON line `{"books_considered":N,"books_covered":N,"books_uncovered":N,"books_unreadable":N,"catalog_author_blocks":N,"top_unharvested_credits":[{"credit":"...","books":N}]}` and set the final progress message to `covered X of N (P%)`. A book whose authors cannot be read counts in `books_unreadable`, never as covered or uncovered.
8. Do not call Audible or any network. Do not write to the catalog or to books.
