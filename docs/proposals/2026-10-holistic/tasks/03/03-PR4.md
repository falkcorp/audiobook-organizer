## Steps
1. Settings: in `DedupSettingsSection.tsx` add a labelled field **AcoustID.org API key** (type password, shows the masked value returned by the server, a **Save key** button). Copy the save logic from `DedupAcousticTab.tsx:856-862`. After saving, clear the input and show "AcoustID API key saved." Never log or toast the key.
2. Command **Look up fingerprints online** (scope `library`): `startJob('AcoustID online lookup', api.triggerAcoustIDOnlineLookup)`. Description: "Looks up the stored fingerprints on AcoustID.org to find the matching recordings. Uses the API key in Settings."
3. Command **Reset all audio fingerprints…** (scope `library`, destructive): opens a confirm dialog with this exact text: "This deletes every stored audio fingerprint and then queues a whole-library re-fingerprint. The re-fingerprint runs on the Mac fingerprint workers, not on this server, and takes days, not minutes. Duplicate matching by audio is unavailable until it finishes. Continue?" Buttons **Cancel** and **Delete fingerprints and rescan**. Only on confirm call `api.resetAcoustIDFingerprints()` and toast the two op ids exactly as the old handler did ("Reset queued (op …); rescan will follow (op …). Watch the bell.").
4. Gate the reset: it is shown disabled with the reason "No fingerprint worker has checked in" unless a Mac worker lease is active. Reuse the same indicator `pages/Library.tsx` uses for "Fingerprint Books" after D2; if no such indicator exists at HEAD, stop and report it as BLOCKED instead of inventing one. The server must never decode audio for this command; this PR adds no server code.
5. Compare drawer: add an **Audio match** section with a button **Check audio match** (the drawer already knows both book ids). On click call `api.compareAcoustID(a, b)`; render loading, error and result states; render the result the way `AcousticComparePanel` does at `DedupAcousticTab.tsx:200-276`. No fetch on open.
6. Port/extend tests as listed; failing first.
