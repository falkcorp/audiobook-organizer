## Steps
1. Confirm every dependency PR is merged (`git log origin/main --oneline | grep` for each). If one is missing, STOP and report BLOCKED with its id.
2. Create `DedupRedirect.tsx`. Mapping (copy exactly; keep `book` and `band` verbatim on every row; drop every other param; the default row applies to no `tab` or an unknown value, including the legacy `unified`):
   - `/dedup`, `?tab=books`, `?tab=book-duplicates` -> `/review?lane=dupes&layer=exact`
   - `?tab=embedding` -> `/review?lane=dupes`
   - `?tab=acoustic` -> `/review?lane=dupes&layer=acoustid`
   - `?tab=authors` -> `/review?lane=authors`
   - `?tab=series` -> `/review?lane=authors&view=series`
   - `?tab=ai` -> `/review?lane=authors&view=ai`
   - `?tab=reconcile` -> `/review?lane=repairs&fixer=reconcile.missing-files`
   - `?tab=split-books` -> `/review?lane=repairs&fixer=dedup.split-books`
   - `/dedup/labels` -> `/review?lane=dupes&view=labels`
   - `/authors/dedup`, `/books/dedup` -> same element, same rules as `/dedup` (no tab -> default row)
   - no `?tab=` or unknown `tab` -> `/review?lane=dupes` keeping `book` and `band`.
   Use `replace` so the back button does not bounce.
3. Remove the four old routes in `App.tsx` and add one route set pointing to `DedupRedirect` for the same four paths. Keep `<ErrorBoundary>` wrapping.
4. `initialLaneFrom`/seeds: verify PR 2 (`layer`) and PR 5 (`view` for dupes) landed; add `view` for the authors lane if PRs 7b/8 did not; do not duplicate. `fixer` is new.
5. `useRepairsLane`: seed the selected fixer once from `?fixer=` before falling back to the per-viewer storage key (`REPAIRS_FIXER_STORAGE_KEY`); ignore an unknown id. Never write it back to the URL.
6. Sidebar: delete the "Dedup" and "Gold Labels" items. Update `Sidebar.test.tsx`.
7. Go: change the single `Link` string and extend the test that covers that announcement. If no test covers it, add one.
8. E2E: add the redirect assertions to `review-dupes-lane.spec.ts` (one `test` per mapping row, asserting the final URL and that the lane is visibly selected), and move the Scheduler Tasks block as listed; run `node tests/e2e/check-spec-discovery.mjs`.
9. Do not delete `BookDedup.tsx`, `DedupLabels.tsx`, `components/dedup/*` or any old test: PR 11 does that. Do not edit `api.ts`.
