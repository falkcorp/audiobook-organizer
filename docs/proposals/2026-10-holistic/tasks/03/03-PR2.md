## Steps
1. Baseline: `cd web && npx vitest run src/components/review` and `npx tsc --noEmit`; record pass counts.
2. Add `layer` to `DupesFilters` and to the list request and `bulkFilter` builder in `useDupesLane.ts`. Use the existing `BulkDedupCandidateFilter.layer` type from `api.ts`; do NOT edit `api.ts` (it is not this PR's slot in the R16 order).
3. Seed it: in `ReviewWorkspace.tsx` extend the `dupesUrlFilters` memo with `layer: searchParams.get('layer')`, validated against the known layer values (`exact`, `acoustid`, `embedding`); an unknown value becomes `null`. Do not write it back to the URL.
4. Layer chips in `DupesPanel.tsx`, placed beside the band chips: **All layers**, **Exact**, **Acoustic**, **Embedding**. Each non-All chip shows its pending count, e.g. `Acoustic (12)`, taken from the `stats` the hook already fetches (no new request). Clicking sets the filter; clicking the active chip clears it. Counts are clickable (rule).
5. Add actions `keepAAllFiltered` and `keepBAllFiltered`, each sending `bulkLinkDedupCandidates({...bulkFilter, keep_side: 'a'|'b', expected_total})`. Register both in `reviewActions.ts` and in the `verbs` map in `lanes/dupes.ts` (the compiler enforces totality).
6. Buttons in the Duplicates action area, shown only when status is Pending: **Keep the older record (all N)** and **Keep the newer record (all N)**. A is the older record because the pair is canonicalised with the smaller ULID as A (`embedding_store.go:719`); say so in the confirm dialog text: "Keeps the older record of every one of the N matching pairs and links the other as a version. This cannot be undone." Copy the pending-only refusal and the `expected_total` handling from the merge-all dialog (`DupesPanel.tsx:397-450`). Do NOT rename the existing per-row "Keep A"/"Keep B" buttons.
7. `DupesSpine.tsx` `BookSide`: show a read-only **iTunes** chip when the book has an iTunes path or PID, using the same predicate as `duplicate_copies_fixer.go:41-45` (re-derive it in TypeScript from the fields the candidate payload already carries; if the payload lacks them, stop and report rather than adding a request). Show **partial fp N%** with the tooltip text from `DedupEmbeddingTab.tsx:786-791` when `book_sig_coverage_pct < 100`.
8. Port the tests listed in the Files table. Each ported test must be seen failing against the pre-change code first.
9. Bump headers; add `changelog.d/<date>_dupes_layer_filter.md`.
