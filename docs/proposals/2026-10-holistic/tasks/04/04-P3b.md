## Steps
1. Create the worktree. Verify the ids and files named in this brief against the tree (`grep -n 'ID: *"<id>"'` in the two files). If a line number differs by a few lines that is fine; if a def is missing or the bodies differ from the Files table, stop and report.
2. Confirm 04-P4f is merged (`grep -n 'RegisterCleanupOldBackupsOp' internal/scheduler/extra_ops.go` returns nothing). If not, stop.
3. Move the walk into `internal/sweep/backup_cleanup.go` with the signature above and call it from `cleanup.go`. The predicate stays `strings.Contains(name, ".bak-")` and the age rule stays `age > maxAge`: **this PR does not change which files the scheduled deleter matches.**
4. **Do not widen the scheduled deleter to the job's patterns.** The job's `.backup`/`.bak` suffix regex has no age gate and the survivor runs nightly on a schedule; folding the regex in would start age-deleting every `*.bak` file the library root holds. The job has no recorded prod run (`ops-census.md`). Retire it with `retiredOpIDs` (not an alias: its params and delete-everything semantics differ), say in the PR body that the `.backup`/`.bak` suffix cleanup capability is dropped, and put the open question "should the suffix cleanup come back as an opt-in, age-gated, preview-default param on the survivor?" in a `todo.d/` fragment (headerless) for the owner.
5. Delete the job file; `go build ./...` shows what else named it. The `/maintenance/jobs` listing drops it automatically because `maintenance.All()` no longer contains it.
6. Add (or append to) `internal/server/op_twin_merge_test.go` a second table `retiredMerges` `{old, survivor string; perms []auth.Permission}` with test `TestTwinMerge_RetiredIDsAndSurvivorPermissions`: boot with `bootRegisteredOpIDs(t)`, assert `srv.opRegistry.Def(old)` is not found, assert the survivor def's `Permissions` equal `perms`, and drive `TriggerOperationV2` with a caller holding only `auth.PermScanTrigger` expecting 403 and no `EnqueueOp` (see `internal/server/handlers/operations_v2_permissions_test.go` for the helpers `withCallerPerms` and `newOpsV2Ctx`; copy them if they are not importable).
7. Add the `retiredOpIDs` entry, then run the Tests.
