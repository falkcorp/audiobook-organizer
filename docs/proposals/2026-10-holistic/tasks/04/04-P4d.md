## Goal
Merge `scheduler.resolve-production-authors` into `maintenance.resolve-production-authors`. The `scheduler.*` def and its body are deleted, the task retargets to the survivor, the loser ID becomes a `FormerIDs` alias on the survivor, and the survivor now declares `Permissions: settings.manage` and the larger of the two timeouts, so the merge neither widens who can run a deleting op nor shortens a budget prod runs were sized against.

## Steps
1. Create the worktree. Verify the ids and files named in this brief against the tree (`grep -n 'ID: *"<id>"'` in the two files). If a line number differs by a few lines that is fine; if a def is missing or the bodies differ from the Files table, stop and report.
2. Diff the two inline bodies (about 100 lines each). Before deleting anything, diff the two `Run` bodies side by side. Anything the loser does that the survivor does not (an activity flush, a progress call, a guard, a config read) is ported to the survivor in this PR and listed in the PR body. If they are identical apart from plumbing, say so. The survivor's body stays; the loser's is deleted after the diff is clean. Pay attention to: how each resolves the real author (any `ModifyBook` call must be the safe writer on both), how each paginates, and whether the loser threads `legacy_op_id` into the activity log (`activityOpID`, extra_ops.go:1111): the survivor must emit under `ctxOpID(ctx)`.
3. **Preview stays preview.** Both ops default to preview through `opmode.ParseDryRun`; the scheduled task sends no `dry_run`, so scheduled runs are previews today and must remain so. The loser passes its own ID string into `ParseDryRun`; the survivor passes its own. Test it (Tests).
4. **Resume policy.** Loser `ResumeDrop`, survivor `ResumeRequeue`. Requeue declares idempotence. A re-run after an interrupted APPLY must not double-apply; verify the body is a pure function of current store state (it should skip authors already resolved). Justify in the PR body or set the survivor to `ResumeDrop`.
5. **Capability.** Loser `network.openai`, survivor `network.generic`: keep `CapNetworkOpenAI` if the body calls an AI service, else generic; record which.
6. On the survivor def: add `Permissions: []auth.Permission{auth.PermSettingsManage}` (import `internal/auth`), raise `Timeout` (and `ProgressTimeout` where the loser sets one and the survivor uses `LivenessNone`) to the larger of the two values listed in the Files table, and add `FormerIDs: []string{"<loser id>"}`.
