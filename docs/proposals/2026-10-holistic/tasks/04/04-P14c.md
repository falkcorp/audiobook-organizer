## Goal
The nightly `maintenance.reconcile-scan` is deleted and becomes a `FormerIDs` alias on the UI-facing `reconcile.scan`; the `reconcile_scan` task retargets. The "latest scan" endpoint keeps finding nightly runs and old rows by resolving def IDs through the registry instead of matching one literal ID, and the survivor keeps the larger timeout and the file-read capability the loser declared.

## Steps
1. Create the worktree. Verify the ids and files named in this brief against the tree (`grep -n 'ID: *"<id>"'` in the two files). If a line number differs by a few lines that is fine; if a def is missing or the bodies differ from the Files table, stop and report.
2. **Payload equivalence.** The endpoint decodes `ResultData` as `reconcile.ReconcilePreviewResult`. Confirm `reconcile.RunReconcileScan` saves that same type via `saveResult` (read it). The census said the survivor "must save results too": at HEAD it already does; the point of this step is to prove the payload shape matches what the loser saved, so nightly and manual rows decode identically.
3. **Behaviour port.** Compare `BuildReconcilePreviewWithProgress` (loser) with `RunReconcileScan` (survivor): progress reporting, cancellation points, any file reads. Port what the loser did that the survivor does not (notably file access: the loser declared `CapFilesRead`).
4. Fix `recentReconcileScans` to canonicalize def IDs (Files table). Without this, rows from the retired ID are invisible to the endpoint, and after the alias exists a literal compare would silently keep hiding them.
5. Retarget the task, delete the loser, add the alias and the survivor changes.
6. Add (or, if an earlier 04 PR already created it, append a row to) the table-driven test `internal/server/op_twin_merge_test.go`, package `server`. Row type: `{loser, survivor string; perms []auth.Permission; minTimeout time.Duration}`. Test `TestTwinMerge_AliasPermissionAndTimeout` boots with `bootRegisteredOpIDs(t)` (`internal/server/op_id_aliases_test.go`) and, per row, asserts: (a) `srv.opRegistry.Def(loser)` returns the survivor's def (ID == survivor); (b) `Def(survivor).Permissions` equals `perms`; (c) `Def(survivor).Timeout >= minTimeout`; (d) drives `handlers.NewOperationsV2Handler(nil, <registry>, nil, true).TriggerOperationV2` for both IDs with a caller holding only `auth.PermScanTrigger` (helpers `withCallerPerms`/`newOpsV2Ctx` are in `internal/server/handlers/operations_v2_permissions_test.go`; if they are not importable from package `server`, copy the 10-line helper into the new test file) and expects HTTP 403 with no `EnqueueOp` call.
