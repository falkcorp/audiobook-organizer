## Goal
The hourly, invisible `transcode.StartCleanupTicker` goroutines (one per import path, started once at boot) are replaced by a scheduled run of the visible op `maintenance.temp-file-cleanup` that reads the import paths each time it runs. Same predicate (transcode temp files older than 2 h), same hourly cadence, now with an operation row and path changes picked up without a restart.

## Context the agent must read first
- `internal/server/server_lifecycle.go:255-270` (the loop over `GetAllImportPaths` and `transcode.StartCleanupTicker(p.Path, appdirs.Current(), 1*time.Hour, 2*time.Hour)`; note a path added after boot never gets a ticker).
- `internal/transcode/transcode.go:440-506` (`CleanupStaleTempFiles(rootDir, app, maxAge)` and the ticker).
- `internal/plugins/maintenance/cleanup.go:100-140` (`maintenance.temp-file-cleanup`: calls `sweep.CleanupOrphanedTempFiles`; after 04-P4a it also carries `FormerIDs scheduler.temp-file-cleanup`, `settings.manage`, 1h).

- `internal/scheduler/tasks.go` task `temp_file_cleanup` (~900-925; interval) and `maintenance.go` `taskV2DefIDs`.
