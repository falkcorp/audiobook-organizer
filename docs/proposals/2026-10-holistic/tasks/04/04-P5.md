## Steps
1. Create the worktree. Confirm both bodies are the same function: `grep -n 'executeSeriesPrune\|executeSeriesNormalizeCore' internal/plugins/maintenance/series.go internal/server/duplicates_ops.go`. If the maintenance bodies do something the `dedup.*` ones do not, stop and report the diff (census says there is none).
2. Decide params compatibility: the losers' Run funcs take a raw JSON; check they read no param the survivors lack (`grep -n 'json.Unmarshal' internal/plugins/maintenance/series.go`). If one does, port it to the survivor in this PR and say so.
3. Delete the loser defs and registrations; add `FormerIDs` to the survivors. The survivors register in the server (`duplicates_ops.go`), while the `dedup` plugin defs list is separate: confirm via `bootRegisteredOpIDs` that the alias lands in `srv.opRegistry.Aliases()`.
4. Add (or, if an earlier 04 PR already created it, append a row to) the table-driven test `internal/server/op_twin_merge_test.go`, package `server`. Row type: `{loser, survivor string; perms []auth.Permission; minTimeout time.Duration}`. Test `TestTwinMerge_AliasPermissionAndTimeout` boots with `bootRegisteredOpIDs(t)` (`internal/server/op_id_aliases_test.go`) and, per row, asserts: (a) `srv.opRegistry.Def(loser)` returns the survivor's def (ID == survivor); (b) `Def(survivor).Permissions` equals `perms`; (c) `Def(survivor).Timeout >= minTimeout`; (d) drives `handlers.NewOperationsV2Handler(nil, <registry>, nil, true).TriggerOperationV2` for both IDs with a caller holding only `auth.PermScanTrigger` (helpers `withCallerPerms`/`newOpsV2Ctx` are in `internal/server/handlers/operations_v2_permissions_test.go`; if they are not importable from package `server`, copy the 10-line helper into the new test file) and expects HTTP 403 with no `EnqueueOp` call. If the real registry does not satisfy the handler's registry interface, use `handlersmocks.NewMockOperationsRegistry` returning the survivor's real def from the booted registry.
5. Rows to add: `{loser: maintenance.series-prune, survivor: dedup.series-prune, perms: [library.edit_metadata], minTimeout: 2h}` and `{maintenance.series-normalize, dedup.series-normalize, [library.edit_metadata], 4h}`.
