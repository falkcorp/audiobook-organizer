## Goal
The five `ai_dispatch_*` families are recorded through OTel instruments from `telemetry.Meter("aidispatch")` and no longer through `client_golang`, while `/metrics` shows exactly the same five names, types, label names and histogram buckets as before. This is the proof that a family can move without touching a dashboard, and the template for the later migrations. The `client_golang` constructor count drops from 69 to 64.

## Steps
1. Instruments (names are the OTel names; the Prometheus exporter turns dots into underscores, appends `_total` to counters and the unit suffix to histograms):
   - `ai_dispatch.requests`: `Int64Counter`, unit `{request}`; attributes `capability`, `endpoint`, `outcome` (the value is `class.String()`); exposes `ai_dispatch_requests_total`.
   - `ai_dispatch.inflight`: `Int64UpDownCounter`, unit `{request}`; attribute `endpoint`; `Add(+1)` before `fn`, `Add(-1)` in the existing `defer` (keep the defer; it is what releases the count on a panic); exposes `ai_dispatch_inflight` as a gauge.
   - `ai_dispatch.failover`: `Int64Counter`; attributes `capability`, `endpoint`, `class`; exposes `ai_dispatch_failover_total`.
   - `ai_dispatch.no_capable`: `Int64Counter`; attribute `capability`; exposes `ai_dispatch_no_capable_total`.
   - `ai_dispatch.slot_wait`: `Float64Histogram`, unit `s`; attribute `endpoint`; exposes `ai_dispatch_slot_wait_seconds_{bucket,sum,count}`; buckets come only from the 11-PR1 view, never from `metric.WithExplicitBucketBoundaries` here.
2. The name `ai_dispatch` is the one sanctioned unprefixed exception (D67). Do not add `audiobook_organizer_`.
3. Keep registration lazy. Create the instruments inside the existing `metricsOnce`, called from `ensureMetrics()`. An OTel instrument exports nothing until it records, so with routing off `/metrics` still gains no `ai_dispatch_*` series, which is the property the comment at `metrics.go:15-17` promises. Update that comment to say so.
4. Replace the 7 call sites mechanically. Take care with `inflight`: the legacy `Inc()` / deferred `Dec()` pair becomes `Add(ctx, 1, attrs)` and a deferred `Add(ctx, -1, attrs)`; use `context.WithoutCancel(ctx)` for the decrement so a cancelled context cannot drop it.
5. Do not touch `Classify`, slot logic, health, attribution or any routing behaviour.
6. Run the contract test from 11-PR1; it must pass unchanged. Run it again with the instrument unit changed to `"1"` once, by hand, to see it fail on a `_ratio` suffix, then revert (report this in the hand-back).

## Rollback
Revert the commit. Names are identical in both implementations, so dashboards and alerts are unaffected either way. Because the five names never coexist as `client_golang` and OTel in one build, there is no double-registration window.
