## Goal
Today the seeded `editor` role holds `scan.trigger` (the only route-level guard on `POST /operations/v2`, `internal/server/wire_operations_routes.go:35`) and can therefore start every operation whose `OperationDef` declares no `Permissions`. At HEAD that is 147 of 198 defs (the coordinator's count: every def under `internal/plugins/*`), destructive ones included. After this PR such a def requires `settings.manage`, which only the admin role holds (`internal/auth/seed.go:50-60` lists the editor's eight permissions; `settings.manage` is not among them).
