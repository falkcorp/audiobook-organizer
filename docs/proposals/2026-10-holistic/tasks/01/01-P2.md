## Goal
The five NutsDB activity files and the `nutsdb` dependency are gone. Only three live helpers move to a new file so the Pebble store keeps working byte-for-byte. Tests that used `NutsActivityStore` as a convenient backend are ported to `PebbleActivityStore`. The trial deletion in a scratch copy built green and removes about 1,950 production lines.

## Steps
1. Baseline: `go build ./... && go vet ./... && go test ./internal/database/... ./internal/activity/... ./internal/server/...` on a clean worktree so any pre-existing failure is known.
2. Create `activity_tiers.go` with the three helpers, copied unchanged. Run the build.
3. Delete the five files and fix the two type-switch arms. `go build ./...` must pass.
4. Port tests file by file. Port means: construct a `PebbleActivityStore` (see how `pebble_activity_store_test.go` builds one) instead of `NewNutsActivityStore(dir)`. Where a test asserts Nuts-specific behaviour with no Pebble equivalent (the legacy per-op bucket in `activity_summarize_grouping_test.go:169`), delete that case and say so in the report. Do not delete a test just to make the build pass; every deletion needs one line of reasoning in the report.
5. `go mod tidy`; confirm `grep -n nutsdb go.mod go.sum` is empty and `go build ./...` still passes.
6. `matchesFilter`, `actTiers` and `actCompactableTiers` must be byte-identical to their old bodies (the Pebble query path depends on them): `git diff -M --stat` should show them as moved, and a `diff` of the three function bodies against `origin/main` must be empty.
7. Fragment: removed the retired NutsDB activity code and dependency.
