## Goal
With `create_backups` on, every tag write that goes through `fileops.WriteTagsSafe` leaves the pre-write bytes beside the file as `<name>.bak-<unix>` before the temp file is renamed in. The bulk write-back ops opt out explicitly through the context they already hold (a context value, see Files), because their safety net is the provenance ledger and a sibling per file would double the library footprint until cleanup runs.
