## Goal
The `embed_cover_art` Settings toggle finally controls something. `metafetch.embedCoverInBookFiles` returns early when the flag is off. The default flips from `false` to `true` in the SAME commit, because the cover embed has been running unconditionally on every apply and write-back; gating without flipping would stop embedding in prod on deploy with no error.
