## Goal
`POST /api/v1/maintenance/wipe` (admin-only library-data wipe) is replaced with the existing UOS-14 410 pattern, lifted into one helper `gone(replacement string) gin.HandlerFunc` that every later P81 group PR reuses. The handler `handleWipe`, the `prefixWiper` interface and their tests are deleted. The 410 stub is removed one release later in the series' final follow-up PR (wave 4).
