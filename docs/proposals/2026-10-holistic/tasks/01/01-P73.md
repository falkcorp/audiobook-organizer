## Steps
1. Write `legacy_guard_parity_test.go` first and run it against `origin/main`. It must PASS there (the live path already refuses both cases). 2. For each function in the table confirm with LSP `findReferences` that the only callers are tests or other functions in the cluster. Check `grep -rn "MergeBooks" internal --include=*.go`: many hits are `merge.Service.MergeBooks` or comments; only `dedup.MergeBooks` is yours (package-qualified or inside package `dedup`).
3. Delete bottom-up (callers first), building after each file.
4. Delete or trim the legacy tests. Every test deleted needs a line in the report saying which deleted function it covered.
5. Run `go test -race ./internal/dedup/... ./internal/merge/... ./internal/maintenance/...`.
6. Fragment: removed the unused legacy duplicate-merge code; the live merge path is unchanged and now has tests for its two safety refusals.
