## Steps
1. For each symbol run LSP `findReferences` (or `grep -rn`) and record the callers. A caller in a `_test.go` file is expected for `retireInto` and `preserveExistingFields`; a caller in production code means STOP and report the symbol as live. Also check for reflection or string dispatch (`grep -rn "\"retireInto\"\|MethodByName" internal`).
2. Delete the symbols and files in the table. Run `go build ./...` after each package so the compiler finds orphaned imports and helpers. A helper that becomes unreachable only because of this PR (for example a tag-key constant used solely by `writeM4BCustomTagsWithFFmpeg`) is in scope: delete it and list it in your report.
3. Run the route test that proves `/metrics` still serves: `grep -rn "\"/metrics\"" internal --include=*_test.go` and run those tests.
4. Do NOT touch `internal/ai/telemetry.go`, `EmbedCoverArtSafe`, or `tagger.EmbedCoverArt` (the latter is a tier-2 item in T4b).
5. Fragment: removed dead tag-write helpers and the unused metrics placeholder.
