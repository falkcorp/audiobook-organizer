## Goal
The Settings page stops promising control it does not have. Eleven fields that are loaded and persisted but never read are removed end to end (struct field, viper load and default, persistence case, protected-field entry, settings-import allow-list, Settings UI and the TypeScript config type): `metadata_review_default_view`, `default_user_quota_gb`, `memory_limit_type`, `cache_size`, `memory_limit_percent`, `memory_limit_mb`, `log_format`, `enable_json_logging`, `auth_rate_limit_per_minute`, `language` (the TOP-LEVEL one only) and the empty `APIKeys struct{}`. Old conf files and old settings exports that still carry the keys must keep loading and importing (ignored, not rejected).
