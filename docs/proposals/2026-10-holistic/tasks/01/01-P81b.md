## Steps
1. GROUP NOTES: Alias rule matters here: `GET/POST /books/:id/position`, `GET /books/:id/state`, `PATCH|DELETE /books/:id/status` are second registrations of handlers that are live under `/audiobooks/:id/...` (`web/src/services/readingApi.ts` calls those); only the `/books/` routes go, the handlers stay. `RepairBookStatus` is registered ONLY at `/books/:id/status/repair` and `/audiobooks/:id/status/repair`, both in the triage list: if both are retired, the handler and its service method are dead and are deleted.
2. GATE: this PR may only retire routes the owner has NOT marked as used in appendix C. The coordinator's prompt lists the marked routes; if it does not, STOP and ask. Remove marked routes from your list.
3. Position pair (D71, answered 2026-10-09): the owner confirmed nothing on their Macs syncs position through `/books/:id/position`; retire the `/books/` alias behind the `gone()` stub as listed. `/audiobooks/:id/position` stays live.
4. Re-verify each remaining route has no caller, including dynamically built URLs: for the path text and for every alias path, `grep -rn "<path fragment>" web/src scripts cmd .claude internal --include=*.ts --include=*.tsx --include=*.py --include=*.sh --include=*.go --include=*.md` (ignore the route registration itself and tests). The appendix-C method did not resolve template-literal endpoints built from variables (for example a `const endpoint = ...` later passed to `fetch`), so read any file that builds URLs near the path.
5. Replace the route handler with `gone(...)`. Do not delete the route registration outright: the stub is the client-facing rollback and stays for one release.
6. Delete handlers and tests per the alias rule. Use LSP `findReferences` on each handler before deleting; run `deadcode` (scratch install, see P9) before and after and list functions that became newly unreachable solely because of this PR; delete those too (same problem).
7. Add the 410 route-table test, then run the group's package tests.
8. Fragment: name the retired paths in plain words and say they answer 410 Gone for one release.
