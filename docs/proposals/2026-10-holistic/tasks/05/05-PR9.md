## API

Permissions (D1: a definition with an empty permission list requires `settings.manage`):
- All reads: `PermLibraryView`.
- `POST runs`: the definition's own `Permission`; empty means `settings.manage`.
- `cancel`: the run's definition `Permission`, or the run's starter.
- `approve`: the definition's `Approver` permission **and** a verified auth method (session or API token); a request authenticated only by a forwarded header is refused with 403.

Routes and payloads:
- `GET /api/v3/ops/defs` returns `[{id, title, kind, permission, effects, schedule:{kind,active,next_fire,live}, ready:{ok,reason}, last_run:{id,state,outcome,finished_at}}]`.
- `GET /api/v3/ops/runs?state=&def_id=&limit=&cursor=` returns `{items:[RunView], next_cursor, total}`. `total` is exact (`RunPage.Total` from `ListRunsV3`), never an estimate, and is the same number `counts` reports for that filter.
- `RunView` fields: `id, def_id, state, outcome, mode, started_at, finished_at, progress:{done,total,chunks:{done,total},workers}, zombie, error, started_by`.
- `POST /api/v3/ops/defs/{id}/runs` body `{params, mode}`: validate `params` against the definition's JSON Schema **before queueing**; invalid returns 400 with field paths and nothing is queued; unready definition (D44) returns 409 with the reason; success returns 202 `{run_id}`.
- `GET /api/v3/ops/timeline?from=&to=` returns `{items, complete}`; `complete=false` whenever the window was truncated by the scan cap (never silently drop).
- `GET /api/v3/ops/counts?group_by=state|def|outcome` returns `{groups:[{key,count,href}], total}` where each `href` is a list URL that returns exactly `count` rows.
- `GET /api/v3/ops/events` SSE: `event: run` with `RunView`, heartbeat comment every 15 s, `Last-Event-ID` resume from a bounded ring; progress events carry `progress.chunks` and `progress.workers`.
- `GET /api/v3/ops/runs/{id}/rows?outcome=&limit=&cursor=` paged with exact `total`, backed by `ListItemOutcomesV3`; the payload carries `truncated` when the per-run cap dropped outcomes. Timeline uses `ListDoneRunsSinceV3`; counts use `OpCountsV3`.

## Steps
1. Create the package and handler structs taking narrow interfaces (a `RunReader`, a `Defs` provider, a `Sched` provider, an `Enqueuer`), not `database.Store`; mock in tests.
2. Implement reads, then run/cancel/approve with the permission rules above and the schema validation (use the same JSON Schema library the repo already imports; do not add one).
