## Goal
After this PR there is exactly one definition of every run status and its properties
(terminal, holds a slot, resumable, retryable, discardable, awaiting a person). The Go
helpers `database.isTerminalV2Status`, `registry.isTerminalStatus`, `registry.IsTerminalStatus`,
`registry.IsInterruptedStatus` and the three further op-status classifiers `scheduler.isTerminalOpV2Status`, `childop.IsTerminal` and `operations.isTerminalOpStatus` (handlers/operations/pause.go) delegate to it, and the TypeScript classifiers are generated
from the same table, so a status added later cannot leave a poller spinning. No persisted data
and no status string changes; the v3 ten-state set arrives in PR 4.

## Steps

1. **Create `internal/operations/state/state.go`.** It holds the v2 vocabulary only (the ten v3 states come in 05-PR4). Exact API:

```go
// Package state is the single definition of operation run statuses and what
// each one means. Go helpers and the generated web/src/generated/ops.ts both
// read this table.
package state

// State is a run status string as stored on database.OperationV2Row.Status.
type State string

const (
	Queued              State = "queued"
	WaitingDeps         State = "waiting_deps"
	Running             State = "running"
	Completed           State = "completed"
	Failed              State = "failed"
	Canceled            State = "canceled"
	InterruptedQuiesced State = "interrupted_quiesced"
	InterruptedAsk      State = "interrupted_ask"
	InterruptedDropped  State = "interrupted_dropped"
	// Legacy spellings: still accepted on read (registry.go:1290-1294), never minted.
	InterruptedRestart State = "interrupted_restart"
	Interrupted        State = "interrupted"
)

// Props says what a status means. Terminal: the run will never execute again
// and its completed_at must be stamped. HoldsSlot: it occupies a worker slot
// and its exclusive key. Resumable: the boot sweep may pick it up.
// Retryable/Discardable: the UI buttons. AwaitingDecision: waits for a person.
// Settled: a poller has nothing more to wait for in this session (Terminal or
// any interrupted* status).
type Props struct {
	Terminal         bool
	HoldsSlot        bool
	Resumable        bool
	Retryable        bool
	Discardable      bool
	AwaitingDecision bool
	Settled          bool
	Legacy           bool
}

// Classify returns the properties of a status string. An unknown string is
// treated as live (not terminal, not settled): the safe direction for a cancel,
// as the registry comments at registry.go:1225-1229 explain. Any string with
// the prefix "interrupted_" that is not in the table is an interrupted status
// (Resumable, Retryable, Discardable, Settled) so a future policy is covered the day it is minted.
func Classify(s string) Props

// All returns every known status in a stable order (for the generator and tests).
func All() []State

func IsInterrupted(s string) bool // "interrupted" or prefix "interrupted_"
func IsTerminal(s string) bool    // Classify(s).Terminal
func IsSettled(s string) bool     // Classify(s).Settled
```

   Table to encode (columns: Terminal, HoldsSlot, Resumable, Retryable, Discardable, AwaitingDecision, Settled):
   `queued` no/no/yes/no/no/no/no; `waiting_deps` no/no/yes/no/no/no/no; `running` no/yes/no(boot sweep turns it interrupted)/no/no/no/no; `completed` yes/no/no/no/yes/no/yes; `failed` yes/no/no/yes/yes/no/yes; `canceled` yes/no/no/yes/yes/no/yes; `interrupted_dropped` yes/no/no/yes/yes/no/yes; `interrupted_quiesced` no/no/yes/yes/yes/no/yes; `interrupted_ask` no/no/no/yes/yes/yes/yes; `interrupted_restart` and `interrupted` as `interrupted_quiesced` with `Legacy: true`. Before encoding, verify each row against the code that handles it (`resume.go:39` `resumeAfterStartup`, `registry.go:1631`) and note any row where the code disagrees with this table in the PR body.

2. **Resolve the disagreement explicitly (decision for this PR).** Today `isTerminalV2Status` and `isTerminalStatus` say terminal = completed, failed, canceled, interrupted_dropped. `IsTerminalStatus` (exported) says terminal = completed, failed, canceled plus **every** `interrupted*`, and the TypeScript prefix rule agrees with it. These answer two different questions. Encode both: `Props.Terminal` is the strict "will never run again" (the first definition) and `Props.Settled` is "stop polling" (the second). Do **not** change what any web poller does: every poller keeps stopping on every `interrupted*` status, now spelled `isSettled`, because a poller that kept polling a deploy-quiesced scan would run until the scan resumes. (The upstream implementation brief says pollers "stop on Terminal || AwaitingDecision"; that would make quiesced scans poll indefinitely, so this brief overrides it. List it as a spec correction in the report.)

3. **Per-caller table (required in the PR body).** List every Go and TS call site found by the greps in "Context", and next to each write which property it needs and why. Starting point: `pebble_store_ops_v2.go:1302,1349,1383` and `registry.go:1210` need `Terminal` (strict; they stamp `completed_at` or refuse to cancel a finished run); `diagnostics.go:332` and `legacy_op_status.go:142-169` need `Settled`; `retention_and_hygiene.go:278` needs `Terminal` (do not purge a run that can still resume); `operations_v2.go:679,739` and `retry.go:82` need `IsInterrupted`. Use the `LSP` tool `findReferences` on each function; do not rely on the grep list alone. If a caller's current behaviour does not match the property it needs, stop and report instead of silently changing it.

4. **Make the four Go helpers delegate.** Keep their names and exported signatures (they have outside callers). Delete the duplicated `switch` bodies. Keep the explanatory comments that carry incident history, moved onto the table in `state.go`.

5. **Write `tools/cmd/opsgen/main.go`.** It imports `state`, and emits `web/src/generated/ops.ts` containing: `export type OperationV2Status = ...` (every `state.All()` value), `export const STATUS_PROPS: Record<OperationV2Status, StatusProps>`, and the functions `classifyStatus`, `isTerminal`, `isSettled`, `isInterrupted`, `isActive`, `isRetryable`, `isDiscardable`. Unknown strings follow the same fallback as `state.Classify` (the prefix rule for `interrupted_`). Output is deterministic (sorted by table order) so `-check` can byte-compare.

6. **Edit `web/src/services/api.ts`.** Replace the hand-written union and `isOperationTerminal` with re-exports from the generated file (keep the export names, since `dedupPipeline.ts`, `dedupHelpers.tsx`, `useImportFolderHandlers.ts` and `Diagnostics.tsx` import `api.isOperationTerminal`; its body becomes `isSettled`). Add `waiting_deps`. The union currently has `interrupting` and `interrupted`; keep `interrupted` (legacy, accepted on read), and drop `interrupting` only if `grep -rn "interrupting" internal` shows the backend never mints it (the proposal claims it does not; verify and say what you found). Point `pollOperation` (`:2735`) and `pollOperationV2` (`:4976`) at `isSettled`. Make `web/src/utils/operationPolling.ts` delegate instead of keeping its own list.

7. **Makefile and CI.** Add `generate-ops`; add the `-check` invocation to the `ci` prerequisites at `Makefile:668` as its own small hunk (05-PR7 also edits this target later; keep the hunk one line).
