## Steps
**Decision flag (read first).** Today the checker deliberately treats workflow `go-version:` as a floating `X.Y` ("setup-go takes a floating 'X.Y'", docstring tier 2) and the tests encode that. Source finding F24 asks for the full patch in `ci.yml`. If you only change `ci.yml`, the existing check fails on it (`go-version '1.27.2' != '1.27'`) and the other six workflows stay floating, which defeats the point. This brief therefore applies the rule to **all 14 literals in 8 workflows** and changes tier 2 for workflows to equality with the full pin. `.github/repository-config.yml` `versions.go: ['1.27']` stays a minor (it feeds the shared actions; do not touch it). **Owner decision D72 (2026-10-09): full patch pin everywhere.** Steps 3 and 4 are required; the floating-minor fallback is withdrawn.

1. Verify the reusable workflow accepts a patch: `ci.yml:47` passes `go-version` to `falkcorp/github-common/.github/workflows/reusable-ci-minimal.yml` pinned by SHA (see the `uses:` line above it). Read that file at that SHA (`gh api repos/falkcorp/github-common/contents/.github/workflows/reusable-ci-minimal.yml?ref=<sha>`) and confirm `go-version` is passed straight to `actions/setup-go`. If it is parsed or truncated to `X.Y`, stop and report; do not change `ci.yml:47`.
2. In `check_toolchain_versions.py` add, after the Dockerfile block:
   - For every `.woodpecker/*.yaml`: each `GOTOOLCHAIN: goX.Y.Z` must equal `pin_full`; each `golang:X.Y.Z-<variant>@sha256:<64 hex>` image reference (regex like `GOLANG_REF_RE`) must have version `pin_full` and a digest; digests must agree among Woodpecker references of the same variant (`bookworm`). Do not compare the bookworm digest with the alpine digest (different images). Error format must stay `::error file=<rel>,line=<n>::...`.
   - `scripts/ci_remote.py`: regex `^GO_TOOLCHAIN\s*=\s*"go(\d+\.\d+\.\d+)"` must equal `pin_full`; a missing line is an error (so the check cannot go vacuous).
3. Change the workflow rule: `value != pin_minor` becomes `value != pin_full`, with message `go-version '<v>' != '<pin_full>' (Makefile pin go<pin_full>)`. Keep skipping values containing `${{`. Rewrite the docstring: tier 2 is now "workflow `go-version:` = full pin"; `repository-config.yml` and `go.mod` stay as they were; explain why (a floating minor let runners move to 1.27.2 on 2026-10-08 while every other path stayed on 1.27.1).
4. Edit the 14 workflow lines listed in Files (7 in `ci.yml`, 7 in the others; `grep -n "go-version:" .github/workflows/*.yml | grep "'1.27'" | wc -l` must print 14 first). `frontend-ci.yml` and `nightly.yml` pass the value to a reusable workflow, so repeat the Step 1 check for `reusable-ci.yml` at the SHA on the `uses:` line. Keep the quotes (`'1.27.2'`).
5. Update `setUp` in the test file to copy `.woodpecker/*.yaml` and `scripts/ci_remote.py` into the temp root (mirror how it copies the workflows).
6. Add four tests (names below). Each mutates the temp copy and asserts the checker fails with the file in its message.
7. Add the changelog fragment (`### Changed`, `#### Toolchain drift check covers Woodpecker, ci_remote.py and workflow patch levels`).
