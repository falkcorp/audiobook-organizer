## Goal
A single `runtime/trace.FlightRecorder` runs for the life of the server. When the ops watchdog writes a `stuck` or `never_reported` strike, or `checkSearchIndexStall` reports a stall, the last ~30 seconds of runtime trace are written to `<data dir>/traces/` (rate limited, at most 10 files). An admin can list and download them. The two incident classes that went silent (2026-07-05 and 2026-09-24/25) will leave evidence next time.

## Steps
0. First run `ls internal/operations/registry/watchdog.go && git log -1 --format=%h -- internal/operations/registry/watchdog.go`, and `grep -n "OnWatchdogStrike\|flight" -r internal | head`. If 05 PR 5 (ops v3 liveness checker) has merged and the watchdog moved, put the hook in the v3 liveness checker instead and say so in the report.
1. **Package `internal/diag/flight`.** `type Recorder struct` holding the `*trace.FlightRecorder`, `dir string`, a mutex, `lastByReason map[string]time.Time`, `clock func() time.Time` (injectable), `maxFiles int` (10), `minGap time.Duration` (5 minutes), `snapshotting atomic.Bool`. `Start(cfg Config) (*Recorder, error)`: `Config{Dir string; MinAge time.Duration (30s); MaxBytes uint64 (32<<20); MaxFiles int (10); MinGap time.Duration (5m); Disabled bool}`. If env `ABK_FLIGHT_RECORDER=off` or `Disabled`, return a recorder whose methods are no-ops (never nil panics). Create `Dir` with mode 0o750. Call `fr.Start()`; on error return it (the caller logs a warning and continues: **a failure to start tracing must never stop the server**).
2. `Snapshot(reason string)` is **non-blocking and returns immediately**: it validates `reason` against `^[a-z0-9_-]{1,40}$` (else uses `unknown`), drops the request when the same reason was snapshotted less than `MinGap` ago or when `snapshotting` is already set (the API allows one `WriteTo` at a time), and otherwise starts one goroutine that writes `<Dir>/<UTC yyyymmddThhmmssZ>-<reason>.trace` via a temp name then `os.Rename`, then rotates to `MaxFiles` by deleting the oldest `*.trace` files in `Dir` only. The watchdog goroutine must never wait on disk. Log one `Info` on success and one `Warn` on failure, never panic.
3. `List() ([]FileInfo{Name, Size, ModTime}, error)` newest first; `Open(name string) (fs.File, error)` accepts only a bare filename matching `^[0-9]{8}T[0-9]{6}Z-[a-z0-9_-]+\.trace$` and opens it through `os.DirFS(Dir).Open(name)` (the pattern the CodeQL note says clears `go/path-injection`; do not use `filepath.Join` with user input).
4. `Stop()` stops the recorder and waits for an in-flight snapshot goroutine with a 5 s cap.
5. **Registry hook.** Add `OnWatchdogStrike func(kind string)` to `registry.Options`; in `watchdogCycle` call it (via a nil check) immediately after `r.writeStrike(..., "stuck", ...)` and after the `"never_reported"` one, passing the kind. The registry must not import `internal/diag/flight` or `internal/server`; the server supplies a closure `func(kind string){ s.flight.Snapshot("watchdog-" + kind) }` where it builds the registry options. The kinds are `stuck` and `never_reported`; reason strings use `-` only, so `never_reported` maps to `never-reported`.
6. **Search stall.** In `runSearchIndexWatchdog` change `s.checkSearchIndexStall()` to `if s.checkSearchIndexStall() { s.flight.Snapshot("search-index-stall") }`. `checkSearchIndexStall` itself keeps its signature (tests call it). A nil `s.flight` must be safe (Recorder methods are nil-receiver safe).
7. **Start/stop.** In `server.go` create the recorder where `bgCtx` is created or at the top of `Start`, with `Dir = filepath.Join(filepath.Dir(cfg.DatabasePath), "traces")` (same sibling-directory idea as `ResolveActivityDBPath`; if `DatabasePath` is empty, disable). Stop it where `bgCancel()` runs at shutdown.
8. **Routes.** `GET /api/v1/diagnostics/traces` returns `{ "traces": [ {name,size,modified} ] }`; `GET /api/v1/diagnostics/traces/:name` streams the file with `Content-Type: application/octet-stream` and `Content-Disposition: attachment`. Both use `s.perm(auth.PermSettingsManage)` like the neighbouring diagnostics routes. 404 for an unknown or malformed name (never echo the input in the error).
9. Changelog fragment (`### Added`, `#### Always-on flight recorder with watchdog snapshots`; mention `ABK_FLIGHT_RECORDER=off` and the 32 MiB ring, 10 files).
