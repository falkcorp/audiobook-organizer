## Steps
**Regenerate with `go fix -diff` at the PR base, never rebase an old diff. Run only in freeze window F (roadmap §5; D50), after 01 tier 2 (T1-T7) has merged. `omitzero` is excluded (D40): never apply it, and confirm the final diff has no `omitempty` -> `omitzero` change.**

How to run a go fix batch (applies to every 06 go fix brief):
1. Create the worktree from a fresh `origin/main`; `git log -1 --format=%h` is the base. The appendix (`docs/proposals/2026-10-holistic/06-bleeding-edge/gofix-batches.md`) is a 2026-10-08 census, **not** your input: 01 tier 2 deleted code since.
2. Check the flag syntax on the pinned toolchain: `go help fix` and `go tool fix help` (the census used one `-<analyzer>` flag at a time, `go fix -diff -rangeint ./...`). Use `-diff` first. Run each analyzer of your batch separately and together; the together-run must equal the union.
3. Rerun with the extra build tags so tagged files are included: add `-tags "pprof bench embed_frontend fts5 native_taglib"` (check that `go fix` accepts `-tags`; if it does not, say so in the report).
4. Exclude `internal/writeback/` by policy even though the census found 0 files there: after applying, `git diff --name-only | grep '^internal/writeback/'` must print nothing.
5. Apply for real only after the diff review: run the same command without `-diff`, then `gofmt -l .` (must print nothing) and `git diff --stat`.
6. Do not hand-edit generated mocks (`make mocks-check` must stay green) or generated files.

Scope: only `./internal/ai/... ./internal/aiscan/... ./internal/authority/... ./internal/authorjunk/... ./internal/catalog/... ./internal/metabatch/... ./internal/metadata/... ./internal/metafetch/... ./internal/personname/... ./internal/fingerprint/... ./internal/foldernames/... ./internal/querygrammar/... ./internal/searchcache/...` (metadata, matching and AI packages); nothing outside these paths may change.

7. Produce the real file list: `go fix -diff -rangeint -mapsloop -slicescontains -slicesbackward -stringsseq -embedlit ./internal/ai/... ./internal/aiscan/... ./internal/authority/... ./internal/authorjunk/... ./internal/catalog/... ./internal/metabatch/... ./internal/metadata/... ./internal/metafetch/... ./internal/personname/... ./internal/fingerprint/... ./internal/foldernames/... ./internal/querygrammar/... ./internal/searchcache/... | grep '^+++ ' | sed 's/^+++ //;s/\t.*//' | sort -u > /tmp/P6d-files.txt` (use the scratchpad directory instead of `/tmp` if you have one) and compare its count with the census count 33. A difference is expected (the tree moved); explain large ones (more than 20 percent) in the report.
8. Review every hunk class once with this checklist:
   - `rangeint`: `for i := 0; i < n; i++` becomes `for i := range n`; check `n` is not modified in the body (range evaluates it once) and `i` is not modified in the body or captured in a way that relied on the old shared variable.
   - `mapsloop`: a copy loop becomes `maps.Copy`/`maps.Insert`/`maps.Collect`; check nil-map semantics (writes to a nil destination map still panic) and that iteration-order dependence did not exist.
   - `slicescontains`: a find loop becomes `slices.Contains`/`slices.ContainsFunc`; check comparison is `==` on comparable elements.
   - `slicesbackward`, `stringsseq`, `embedlit`: confirm same element order and same types; `embedlit` rewrites composite literals of embedded struct fields, so compile errors are the guard.
9. Apply: `go fix -rangeint -mapsloop -slicescontains -slicesbackward -stringsseq -embedlit ./internal/ai/... ./internal/aiscan/... ./internal/authority/... ./internal/authorjunk/... ./internal/catalog/... ./internal/metabatch/... ./internal/metadata/... ./internal/metafetch/... ./internal/personname/... ./internal/fingerprint/... ./internal/foldernames/... ./internal/querygrammar/... ./internal/searchcache/...`. Re-run `go fix -diff -rangeint -mapsloop -slicescontains -slicesbackward -stringsseq -embedlit ./internal/ai/... ./internal/aiscan/... ./internal/authority/... ./internal/authorjunk/... ./internal/catalog/... ./internal/metabatch/... ./internal/metadata/... ./internal/metafetch/... ./internal/personname/... ./internal/fingerprint/... ./internal/foldernames/... ./internal/querygrammar/... ./internal/searchcache/...`: it must now print nothing (fixed point). If the second run still produces hunks, apply again until it is empty and note the number of passes.

Slice file list command (to compare against the census): `sed -n '/^## P6/,/^## P7/p' docs/proposals/2026-10-holistic/06-bleeding-edge/gofix-batches.md | grep -E '^- `(internal/ai/|internal/aiscan/|internal/authority/|internal/authorjunk/|internal/catalog/|internal/metabatch/|internal/metadata/|internal/metafetch/|internal/personname/|internal/fingerprint/|internal/foldernames/|internal/querygrammar/|internal/searchcache/)' | sed 's/^- `//;s/`.*//'`.
