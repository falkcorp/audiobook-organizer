## Goal
A normal `make build-linux` (and so every deploy) produces a binary that contains the pprof listener code but serves nothing unless `ABK_PPROF_ADDR` is set. The committed `Makefile` owns the generic flags (tags, `-trimpath`, `-s -w`) in two variables used by `build`, `build-api`, `build-linux`, and `Makefile.local.example` calls `make build-linux` instead of repeating a `go build` line. The listener runs on its own mux, not `http.DefaultServeMux`.

## Steps
1. **Makefile variables.** Add the three variables with a short comment citing D37. `build-linux` becomes: `-tags "embed_frontend fts5 native_taglib $(GO_BUILD_TAGS)" $(GO_BUILD_FLAGS) -ldflags="$(GO_LDFLAGS) -linkmode external -extldflags '-static'"`. `build` and `build-api` use `-tags "embed_frontend $(GO_BUILD_TAGS)"` / `-tags "$(GO_BUILD_TAGS)"`, `$(GO_BUILD_FLAGS)` and `-ldflags="$(GO_LDFLAGS)"`. Leave `LDFLAGS` as is: `build-mtls-bridge*` still use it. Before editing, run `make -n build build-api build-linux` and save the output; after editing, diff it and explain every difference in the PR body (the intended ones: the tag, `-trimpath`, `-s -w` on dev builds). If stripping dev binaries (`-s -w`) is a problem for `make run`, report it instead of keeping it silently.
2. **`pprof_debug.go`.** Replace the blank `net/http/pprof` import with a named import. Build `mux := http.NewServeMux()` and mount `/debug/pprof/` -> `pprof.Index`, `/debug/pprof/cmdline`, `/profile`, `/symbol`, `/trace` explicitly (the named profiles, including Go 1.27's `goroutineleak`, are served by `pprof.Index`). Serve with an `http.Server{Addr, Handler: mux, ReadHeaderTimeout: 10 * time.Second}`; no write timeout (CPU profiles take 30 s+). Put the mux in `func newPprofMux() *http.ServeMux` (in `pprof_debug.go`). Put the address rule in the pure function `func resolvePprofAddr(raw string) string` (empty host such as `:6060` becomes `127.0.0.1:6060`; anything else unchanged; log the rewrite in the caller). `startPprofFromEnv(getenv, serve)` reads `ABK_PPROF_ADDR` through `getenv`, resolves it, and starts the listener only by calling the injected `serve(addr, newPprofMux())` in a goroutine; `init()` passes a `serve` that builds the `http.Server` described here. Tests inject a no-op `serve`, so no test binds a real port. Keep the existing log lines and the HIGH-1 comment; add one sentence saying the `DefaultServeMux` registration by the import is inert because nothing serves it.
3. **Prove nothing serves `DefaultServeMux`.** Run `grep -rnE 'http\.ListenAndServe\(|http\.Handle\(|http\.HandleFunc\(|DefaultServeMux' --include=*.go . | grep -v _test.go` and confirm no hit outside `pprof_debug.go` that passes a nil handler. Paste the output in the PR body. If any hit exists, stop and report.
4. **`Makefile.local.example`.** `deploy` keeps its preflight, scp, `.prev` copy, restart and version check, but its build becomes `@$(MAKE) build-linux` and it ships `dist/audiobook-organizer-linux-amd64`. `deploy-debug` becomes: run `deploy`, then install a systemd drop-in that sets `Environment=ABK_PPROF_ADDR=localhost:6060`, restart, and check the port answers over ssh (`curl -sf http://localhost:6060/debug/pprof/goroutineleak?debug=1 | head -1`). Add a matching `pprof-off` target that removes the drop-in. Keep every `DEPLOY_*` variable, `ssh` and `scp` detail as it is. No `-gcflags`, no `-tags`, no `-ldflags` anywhere in the file.
5. **Owner hand-off (put verbatim in the PR body and the report).** The owner's private `Makefile.local` is gitignored and not in the repo; do not look for it, read it or edit it. After this merges the owner should, in their `Makefile.local`: (a) delete their `build-linux-debug` target; (b) in `deploy` and `deploy-debug`, delete every `go build` line and replace the build step with `$(MAKE) build-linux`, keeping only host, scp/ssh, `.prev` and restart details, and the drop-in that sets `ABK_PPROF_ADDR=localhost:6060`; (c) delete any `-tags ...pprof...`, `-gcflags`, `-ldflags`, `-trimpath` text and any assignment to `GO_BUILD_TAGS`, `GO_BUILD_FLAGS` or `GO_LDFLAGS` (an assignment there is included after the Makefile defines them and silently overrides the committed values); (d) keep `DEPLOY_HOST`, `DEPLOY_BIN`, `DEPLOY_DB`, `DEPLOY_URL`. Source doc 06 F2 says their file today carries the tag at about line 70 and a correct `build-linux-debug`, but this was read only by the analyst: confirm against the real file.
6. `docs/BUILD_TAGS_GUIDE.md`: add the section (tag list row, the env var, loopback only, `ssh -L 6060:localhost:6060`, "a default deploy exposes nothing", the endpoints `profile`, `heap`, `goroutine`, `goroutineleak`).
7. Changelog fragment (`### Changed`, `#### Deploy builds now include the pprof tag (listener still off by default)`).
